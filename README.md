# TUP 算法组

TUP 战队算法组手写的一套课，七门：C++ 基础、C++ 进阶、其他基础、OpenCV、Python、ROS 2、机器学习。纯 HTML，没有构建步骤，**读课不用装任何东西、不用联网**——整个文件夹拷到哪儿都能开

**用途**：队里要教的东西都放在这儿，谁想学自己来翻，不用等人开讲。
**目标**：七门课一门一门写完，从「没写过代码」写到能自己动手做东西

现在写完的是五门课：C++ 基础课（九个部分、四十二课）、C++ 进阶课（九个部分、四十六课）、其他基础（八个部分、四十五课）、OpenCV（十一个部分、五十八课）与 Python（十个部分、五十一课）

## 怎么用

**读课**:打开 `TUP.html` 挑一门课。左边那条目录会跟着告诉你读到哪一小节，
顶栏最右边那个按钮换配色（亮色 / 暗色 / 跟着系统走）

**动手**:这是一门课，不是一份资料——课里的每段代码都自己敲进去、跑一遍
`示例代码/` 里是课里出现过的每一个 `.cpp`，可以自己编译、自己跑：

```
g++ -Wall 0.1-hello.cpp -o hello
./hello
```


**对答案**:练习先自己写，写不出来再展开看答案；每个练习下面都给了
「预期输出」，自己跑出来的要和它逐字符一致。可在每门课的 `示例代码` 文件夹里查看例题与练习题的源码


>想把所有程序一次编译一遍、看看真实输出，在终端里：
>
>```
>cd lessons/cpp_Basics/示例代码
>bash verify.sh
>```
>
>进阶课把路径换成 `lessons/cpp_advanced/示例代码`。

卡住了，或某些概念不清晰：基础课翻 `reference/附录.html`，
进阶课翻 `reference/附录-进阶.html`，OpenCV 翻 `reference/附录-OpenCV.html`

## 写在最后
1. 这套课由人工与ai协同完成。由于本人水平和精力有限，材料里的解释和用法难免有不到位、对新手不够友好的地方。读者在使用过程中如果遇到疑问，或者觉得哪一部分过于烧脑，欢迎交流，一起把这套材料改得更好:D
2. 关于编程学习：只靠课里提供的练习题是远远不够的。写程序本质上是熟能生巧的事——语法基础也好，各种库的调用也好，只有保持手感，才谈得上编程能力。拆解问题、想清楚解法的思路固然更重要，但代码基础与想法落实到代码上的能力也不能丢下
