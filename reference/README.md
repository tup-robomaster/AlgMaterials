# reference/：正文之外、要随时翻的东西

现在有三份，两门 C++ 课各一份，OpenCV 一份。三份都是**回头查**用的，
不跟着课往下讲：

- **`附录.html`**（配 C++ 基础课）
  - **A · 编译报错速查** —— 报错那句话长什么样、英文词一个个对着查、
    拿一条完整的报错从头读到尾、警告和报错不是一回事、实在查不到怎么办。
  - **B · 语法速查表** —— 变量与类型、运算、输入输出、判断、循环、函数、
    数组与 vector、struct/class/继承、指针与引用。一条一句，不展开讲。
  - **C · std 常用** —— 课里没讲、写着写着就要用的现成写法。

- **`附录-OpenCV.html`**（配 OpenCV 课）
  - **A · API 速查** —— 按 `core`、`imgcodecs` 与 `highgui`、`imgproc`、
    `videoio`、`calib3d` 分模块，列出课程用到的类型、函数与方法，
    给签名、一行用途与第一次出现的课。
  - **B · 常见错误** —— 15 类 OpenCV 与链接错误，按现象、原因、处理排列；
    每条给最小复现或判断方法。

- **`附录-进阶.html`**（配 C++ 进阶课）
  - **A · 编译与链接报错速查** —— 先分清是编译器、链接器、cmake 还是 make
    在说话，再一个个词对着查，最后把一条链接报错从头读到尾；
    末尾讲「走 cmake 之后，同样的错换了哪层皮」。
  - **B · cmake 速查表** —— 三份最小模板、常用命令、常用变量、命令行。
  - **C · 容器速查** —— 六个容器各会哪些动作、挑哪一个、常见报错。
  - **D · 新特性速查** —— 智能指针、移动与就地构造、结构化绑定、`std::array`。
  - **E · 串口速查** —— 常用波特率、8N1 要设的项、帧格式、CRC8 与 CRC16、
    常见错误与伪终端用法。

用法和课里的页一样：双击就能开，左边目录能点、能高亮。样式和脚本跟课那几页
共用，从这一层往上走一层去 `assets/` 拿。
