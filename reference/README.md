# reference/：正文之外、要随时翻的东西

现在只有一份：`附录.html`，标题就叫「卡住的时候查」。

它不跟着课往下讲，是**回头查**用的。三部分：

- **A · 编译报错速查** —— 报错那句话长什么样、英文词一个个对着查、
  拿一条完整的报错从头读到尾、警告和报错不是一回事、实在查不到怎么办。
- **B · 语法速查表** —— 变量与类型、运算、输入输出、判断、循环、函数、
  数组与 vector、struct/class/继承、指针与引用。一条一句，不展开讲。
  只收课里讲过的，一条不多。
- **C · std 常用** —— 反过来，收课里**没**讲、但写着写着就会用到的 std 东西：
  数字（min、max、sqrt…）、文字（string 的几个动作）、变长数组（vector 的几个动作）。
  只收「喂它一个值、它还你一个值」那种，不用先学新概念。同样是查，不展开讲。

用法和课里的页一样：双击就能开，左边目录能点、能高亮。样式和脚本跟课里
共用，从这一层往上走一层去 `assets/` 拿。
