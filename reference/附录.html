卡住的时候查

A 是报错速查，B 是课里讲过的语法，C 是课里没讲的 std 常用。 平时不用读——报错了、忘了怎么写、想要个现成的写法，翻到对应那一页。

A编译报错速查

报错的一句话长什么样

编译器每一条报错的第一行，都是同一个骨架。0.3 讲过一遍， 这里再摆一次，因为查表之前得先知道自己在读什么： 

文件名.cpp:4:43: error: too many initializers for ‘int [5]’
这一截什么意思
冒号之前那一串 哪个文件。出错的往往不是你正在看的那一行，先看它说的是哪个文件、第几行
第一个数字 第几行。这个数是给你指路的，不是给你定罪的——真凶常在它上面一行
第二个数字 那一行里的第几个字符。长长的一行里，它帮你缩到具体那一处
error: 这是错误，程序编译不出来。warning: 是警告，还能编译（见下面 A.4）
note: 开头的那几行 补充说明。有时它比 error 还值钱——它会把该怎么改直接写给你
底下那些 | 和 ^ 把出错那行整个印出来，再用 ^ 指到具体位置。0.3 讲过：尖号指哪儿，盯哪儿看

英文词对着查

报错里的英文翻来覆去就那几个词。左边这一列是你在屏幕上会看到的， 找到它，右边两列告诉你说的是什么事、该回去看哪一课。

报错里的词它在说什么你多半写了什么
expected ‘;’ before … 「在……前面，我等着一个分号」 上面那一行的末尾少了 ;。尖号指的那个位置就是要补的地方
expected ‘,’ or ‘;’ before … 同上，逗号也认 还是少分号。它多给你一个选项，是因为有些地方逗号也对
was not declared in this scope 「这个名字，在这儿我不认识」 三种可能：拼错了、名字写在别的花括号里（3.3 作用域）、压根没定义过
did you mean ‘std::cout’? 「你是不是想写这个？」 少了 std::。它常常直接把全名报给你——照着抄就行
is not a member of ‘std’ 「std 里没有这么个东西」 少了 #include。底下那条 note 会告诉你该 include 哪一个
too many initializers for ‘int [5]’ 「盒子只有 5 个，你塞了 6 个」 数组长度写小了。方括号里那个数是上限（4.1）
is private within this context 「这是私有的，你不在这儿，碰不得」 从外面直接动私有成员了。底下那条 note 会写出该用哪个函数（5.3）
is protected within this context 同上，protected 那一档 protected 是留给子类的，外面照样碰不得（5.4）
no matching function for call to … 「你这一嗓子，没有能应上的函数」 参数个数或类型对不上。底下会一条一条列出「有哪些能应的」，看第一条差在哪儿（5.4）
marked ‘override’, but does not override 「标了 override，可它谁也没盖住」 子类那个函数的签名和父类差了一个字母。这个名字对不上，就是两个不相干的函数（5.4）
declared as reference but not initialized 「说是引用，可没绑上」 int& r;。引用一出生就得绑一个盒子（6.2）
cannot bind … to an rvalue 「绑不上」 int& r = 5;。5 是一个数，不是一个盒子，没法给它起名字（6.2）
assignment of read-only reference 「这是只读的，不让改」 往 const int& 里写东西了。前面有 const 就是只读（6.4）
invalid conversion from ‘…’ to ‘…’ 「这两种类型之间，没有这种换法」 典型的 char c = "A";：单引号是一个字符，双引号是一串（1.2）
no match for ‘operator<<’ 「没有能对上的 <<」 方向记反了：std::cin << a; 或者 std::cout >> a;（1.5）
expected primary-expression before … 「这前面缺东西」 常常和上一条一起出现：for 的三段之间该用分号，写成了逗号（2.4）
expected ‘;’ before ‘)’ token 「) 前面该有个分号」 for 少写了第三段，或者前后的括号没配平（2.4）
这一列里最该记住的，是第三条

was not declared in this scope——「我不认识这个名字」。 这一条能顶上小一半的报错，而且它跟前面那些「缺个符号」的毛病不一样： 少一个分号是手滑，名字不认识是脑子里的事—— 要么你以为它在那儿而它不在，要么它在那儿而你以为它在别处。 这两种都得回去看代码，光盯着报错没用。

一条完整的报错，从头读到尾

挑了一条最值钱的：它有 error，还有一条把改法写出来的 note。 这是 5.3 那份「从外面动私有成员」的程序，编译器原话，一个字没动： 

5.3-private-err.cpp:25:7: error: ‘int Student::score’ is private within this context
   25 |     a.score = 100;
      |       ^~~~~
5.3-private-err.cpp:7:9: note: declared private here
    7 |     int score;
      |         ^~~~~
5.3-private-err.cpp:25:7: note: field ‘int Student::score’ can be accessed via ‘int Student::getScore()’
   25 |     a.score = 100;
      |       ^~~~~
      |       getScore()

第一行。25:7，第 25 行第 7 个字符； error；然后一句话： 

‘int Student::score’ is private within this context

拆开看：int Student::score 是它的全名——「 Student 这个类里那个叫 score 的 int」。 这句话要是换成中文，就是：「Student 家的 score 是私有的，你现在这个位置碰不着」。

中间那两行是它顺手把 25 行印出来，尖号戳在 score 上。 底下紧跟着一条 note：「私有，是在这儿声明的」， 还把那行（第 7 行）也印出来了。一头一尾都摆给你看， 你就不用在文件里来回翻了。

最后那三行是这一条里最值钱的： 

note: field ‘int Student::score’ can be accessed via ‘int Student::getScore()’
      |       getScore()

它不光说「不行」，还告诉你「该用这个」。 can be accessed via 翻过来就是「可以用……来访问」， 后面跟着的 getScore()，就是那个 public 的函数（5.3 写过）。 底下那行 | getScore()，是它替你把要改的那半句直接写出来了。

顺带说一句，这条报错里出现了两个尖号、三种缩进、一个竖线——不要被这个架势吓住。 它从头到尾只在说一件事。

编译器读你的代码，比你读它的报错快得多

一份几百行的程序，它一眼扫完，然后挑最靠前的那几处说。 所以报错经常是一串，而不是一条——头一条改完， 后面好几条常常自己就没了。这就是为什么 0.3 说「改最上面那一条，再编一次」， 别一口气改十条：你改的十条里，有九条本来就不是病。

警告是另一回事

警告（warning）的意思是：「这么写能编译，但我看着不对劲。」 编译照样过，程序照样能跑——跑起来对不对是另一回事。 下面这几条是本课里出现过的，都是真编译器的原话：

警告里的词它在说什么
this ‘if’ clause does not guard… 「这个 if 不管着后面那一句」——缩进骗了自己（2.1）
suggest parentheses around assignment used as truth value 「你把 = 当条件了」——想写的是 ==（2.2）
suggest parentheses around ‘&&’ within ‘||’ 「&& 和 || 混在一起了，加括号吧」——你是想加括号的，只是忘了（2.2）
comparisons like ‘X<=Y<=Z’ do not have their mathematical meaning 「1 <= x <= 100 这么写，跟数学里那个不是一回事」（2.2）
comparison of integer expressions of different signedness 「一个能装负数的数，和一个是不能装负数的数，在比大小」——加上 int() 就好（4.6）
‘sizeof’ on array function parameter … will return size of ‘int*’ 「数组名进了函数就不知道自己是多长了，sizeof 量出来的是指针」——所以长度得自己传（6.5）
unknown conversion type character … in format 「format 里有个我不认识的写法」——想打百分号，写了一个 %，得写两个（1.6）

警告分两种。一种是它误会你了（比如 4.6 那个 i < int(v.size())，你从 0 往上走，永远不会是负数）， 这种看懂了就不用管。另一种是它说中了—— 2.2 那两个坑、6.5 那个 sizeof，都是你写错了、它拦了一下、然后放你过去了。 警告值不值得改，看它说的那件事你认不认。 认，就改；不认，看懂了再往下走。别养成「看到黄字就心慌」的习惯，也别养成 「黄字一律无视」的习惯——这两种都让你错过东西。

查不到，怎么办

这张表没覆盖到，按这个顺序来：

  1. 先看尖号在哪儿。不管句子多长多绕， ^ 指着的那一处就是你该动的地方。十次里有八次， 光是看它指哪儿就明白了。
  2. 只读最上面那一条。底下那些多半是它连带的， 头一条改完再编一次，剩下的常常自己就没了。
  3. 找那句话里的「名字」。报错里那些 ‘ ’ 包着的， 都是你代码里的东西（变量名、函数名、类型名）。翻回去找到它， 答案一般就在那儿。
  4. 还不明白，就用 7.1 那套。把程序砍到最小——砍到只剩出问题的那几行， 报错往往自己就露馅了。这一招对的不是报错，是你脑子里那个「我以为」。

最后一句：看不懂的报错，先原样留着，别急着乱改。 乱改一气之后，屏幕上的报错会变成另一种、更看不懂的——那时候你连 「原来错在哪儿」都找不回来了。

B语法速查表

这张表只收本课讲过的语法，一条不多。每条末尾的括号标出它在哪一课出现过—— 忘了就回去翻那一课，这张表只做索引，不替讲课。

写法一栏里，名字、a、n 这些是占位符， 写的时候换成你自己的；花括号里的 … 表示此处省去的语句体， 不是要照着打三个点。本课没有讲过任何可以省略的写法——写进自己的程序时， 每一句都要写全。

表里一律用 C++ 的标准叫法。课里那些比方说的是同一批东西：「盒子」是变量， 「抄件」是按值传递的副本，「本人」是引用所绑定的那个变量，「父类／子类」是 基类／派生类。两边对不上号的时候，以这张表为准。

变量与类型

写法含义
int a = 3;声明整型变量 a，初始化为 3（1.1）
int a;只声明、不初始化：a 的值不确定，是那块内存里留下来的数据（1.1）
a = 5;赋值：把 5 存进 a。= 是赋值运算符，不是相等判断（1.1）
double x = 1.5;双精度浮点变量，用来存小数（1.2）
char c = 'A';字符变量，用单引号；双引号包起来的是一串字符（1.2）
std::string s = "小航";一串字符，用双引号；要写全 std::string，文件开头还要加 #include <string>（1.4）
bool ok = true;布尔变量，取值只有 true 和 false（1.2）
const int n = 5;常量：初始化之后不能再赋值（6.4）

标识符的命名规则：只能用字母、数字、下划线，不能以数字开头， 区分大小写（sum 和 Sum 是两个变量）， 不能用关键字（int、return…）当名字（1.1）。

运算

写法含义
+ - * /加、减、乘、除（1.3）
7 / 2两个整数相除，结果取整为 3，小数部分直接舍弃（1.3）
7.0 / 2只要有一个操作数是小数，结果就是小数 3.5（1.3）
7 % 2取余运算，结果是 1。用来判断能否整除，也能拆出某一位数字（1.3）
a + b * c* 先算。优先级不确定时就加括号：括号不改变运算结果，只是省得读的人去回想（1.3）
a = a + 1;把 a 的值加 1，再存回 a（1.3）

输入输出

写法含义
#include <iostream>使用 std::cout / std::cin 需要这一行（0.2）
std::cout << a << std::endl;把 a 输出到屏幕，std::endl 换行（1.4）
std::cin >> a;从键盘读入一个数存进 a。箭头的方向就是数据的流向（1.5）
"你好"双引号里的内容原样输出，引号外的先算完再输出（1.4）
#include <cstdio>使用 printf 需要这一行（1.6）
printf("%d\n", a);按格式输出：%d 是整数占位，\n 是换行（1.6）
%.2f / %8.2f浮点数：保留两位小数；总宽 8 列、保留两位。那个小数点不能省（1.6）
%3d整数至少占 3 列，不足补空格，这样各列才对得齐（1.6）
%%输出一个百分号本身（1.6）

判断

写法含义
if (a > b) { … }条件成立才执行花括号里这一段（2.1）
else if (…) { … }上一条不成立时，再判断这一条（2.1）
else { … }前面全部不成立时执行（2.1）
== != < > <= >=相等、不等、大小比较。相等判断写两个等号（2.2）
&& || !逻辑与、逻辑或、逻辑非（2.2）
if (a = 5)这不是判断：先把 5 赋给 a，再拿 5 的真假决定走不走（2.2）

循环

写法含义
while (i < n) { … }条件成立就再执行一圈。循环次数事先不确定时用它（2.3）
for (int i = 0; i < n; i++) { … }初值、条件、每轮的变化都写在头部。循环次数确定时用它（2.4）
for (…) { for (…) { … } }两层嵌套：外层控制行，内层控制一行里有几个（2.5）
i++和 i = i + 1 完全等价，写起来短（2.4）
i <= 5 还是 i < 5<= 比 < 多执行一轮循环。不确定就按初值、条件、末轮各数一遍（2.4）

循环头部声明的变量（上面那个 i）作用域只在这个循环内。循环一结束 它就不再存在，外面再引用，编译器会报 was not declared in this scope（2.4）。

函数

写法含义
int add(int a, int b) { return a + b; }有返回值的函数：返回类型写在最前面（这里是 int），函数体里必须有 return（3.2）
void show(int a) { … }没有返回值：返回类型写 void，可以不带 return（3.2）
int add(int a, int b);函数声明：只有签名、没有函数体，用来告诉编译器「有这个函数」。写在调用它的代码之前（3.2）
add(3, 5)函数调用：实参按位置对应形参，名字不必相同（3.2）
void f(int a)按值传递：f 拿到的是实参的副本，函数内改，外面不动（3.4）
void f(int& a)按引用传递：f 拿到的是原变量本身，函数内改，外面跟着变（3.5）

花括号里声明的变量，作用域到花括号结束为止（3.3）。两个函数里的 int a 是各自的 a，重名不冲突。

数组与 vector

写法含义
int a[5];声明 5 个整数的数组，共用一个名字。方括号里是元素个数，5 个元素的下标是 0 到 4（4.1）
int a[5] = {90, 85, 77, 60, 95};声明的同时初始化。初值的个数不能超过方括号里的个数（4.1）
a[0]第一个元素。下标是「离开头第几个」，所以从 0 开始（4.2）
for (int i = 0; i < 5; i++) 里用 a[i]依次访问每个元素，数组的固定写法（4.2）
a[5]（长度是 5 的时候）下标越界，编译器不检查。读到的是相邻内存里的数据，写进去会破坏别处的数据（4.2）
int t = a; a = b; b = t;交换两个变量，必须借助第三个变量（4.4）
#include <vector>使用 std::vector 需要这一行（4.6）
std::vector<int> v;声明一个长度可变的数组，当前元素个数为 0（4.6）
v.push_back(90);在末尾追加一个元素，长度随时可以增加，不必事先确定（4.6）
v.size()当前元素个数。与 int 比较时套一层 int()，可以消掉那类警告（4.6）
v[0] / v[2] = 88;读写方式和数组相同，但下标只能落在已有的元素上（4.6）

struct、class、继承

写法含义
struct P { int x; int y; };把多个变量组合成一个类型。末尾那个分号最容易忘（5.1）
P p; p.x = 1;声明一个 P，成员用点号访问（5.1）
P list[3];结构体数组，每个元素是一整份 P（5.1）
class S { public: … private: … };class 的成员默认私有，所以要显式写一段 public:（5.2、5.3）
void Print() { … } 写在 class 里面成员函数。调用写成 a.Print()（5.2）
S(int n) { score = n; }构造函数：创建对象时自动调用，没有返回类型（5.3）
~S() { … }析构函数：对象销毁时调用，名字前面多个波浪线（5.3）
this->score形参名和成员名相同，用 this-> 指明这里要的是成员（5.3）
class Grad : public Student { … };继承：Grad 派生自 Student，冒号后面写基类（5.4）
Grad(…) : Student(n, i, s) { … }基类部分由谁初始化：写在初始化列表里，交给基类的构造函数（5.4）
virtual void Print() { … }虚函数：允许派生类改写。通过基类引用调用时，执行的是派生类那一版（5.4）
void Print() override { … }标明这是对基类虚函数的覆写，签名对不上编译器会当场报错（5.4）
protected: int score;类外不能访问，派生类可以。介于 public 和 private 之间的一档（5.4）

指针与引用

写法含义
&a取地址：得到 a 的内存地址（6.1）
int& r = a;引用：给 a 起的另一个名字。声明时必须绑定，绑定之后不能改指别的变量（6.2）
int* p = &a;指针：一个变量，里面存的是另一个变量的地址（6.3）
*p解引用：按这个地址找到那个变量本身。读和写都可以（6.3）
int* p = nullptr;空指针：暂时不指向任何变量。对空指针解引用，程序会崩溃（6.3）
const int& x常量引用：只读，不能通过它修改原变量（6.4）
int* p 参数地址传递：函数里改 *p，外面跟着变（6.4）
a[i] 和 *(a + i)两种写法完全等价（6.5）
void f(int a[])数组作参数时会退化成指针，函数内不知道数组有多长，长度得另传一个参数（6.5）

Cstd 常用

B 那张表只收课里讲过的，这一节反过来：收的全是课里没讲、但你写着写着就会想找的东西。 它们都住在 std 里——就是 std::cout 那个 std， 名字前面照样要写 std::，用哪一样还得在文件开头 #include 上对应的那一行 （每张表的第一行就是它）。

收进来的有个共同点：喂它一个值，它还你一个值。不用先学什么新概念， 看完就能写进自己的程序里试。要另外先学一套东西的（排序、查表那些），这节末尾单说。

写法那栏的占位符和 B 一样，a、s、v 换成你自己的。 括号里偶尔写着课号的，是课里提过一句的地方，回去翻那一课； 没写课号的，课里没有出现过，这张表就是它的全部说明。

数字

写法含义
#include <algorithm>用下面那三个 std::min、std::max、std::swap 需要这一行
#include <cmath>用 std::sqrt、std::pow、std::floor、std::abs 这些数学函数需要这一行
std::min(a, b) / std::max(a, b)两个里小的那个／大的那个。两个的类型要一样——std::min(3, 4.5) 编译不过，报错就是 A.2 里那条 no matching function for call to …，两个类型对不上，没有能应的
std::swap(a, b)交换两个盒子里的值。4.4 手写的那三行，这一句就顶了（4.4）
std::abs(a)绝对值，负数给它的相反数，正数原样还回来。整数、小数都能喂
std::sqrt(x)平方根。给的和还的都是小数：std::sqrt(16) 打出来是 4，但它的类型是 double
std::pow(x, y)x 的 y 次方，同样是小数运算：std::pow(2, 10) 打出来是 1024
std::floor(x) / std::ceil(x) / std::round(x)向下取整／向上取整／四舍五入。还回来的是小数，只是小数部分为 0：std::floor(2.7) 打出来是 2。负数别想当然：std::floor(-2.7) 是 -3，是往下走的那个

文字：string

写法含义
s.size()这串文字有几个字节，不是几个字。一个汉字算 3 个：s 是 "小航" 时，s.size() 是 6。拿它数「名字有几个字」会数错。和 int 比大小时照样要套 int()（4.6）
s[i]第 i 个字节，是个 char，下标从 0 起。汉字占 3 格，所以同一个 "小航"，s[0] 拿到的只是半个字，打出来是乱码——要按「字」取，用下面的 substr
s1 + s2两串接成一串，原来的两串都不动
s1 == s2比的是里面的字一样不一样，不是比两个盒子在哪儿。和引号里的字串比也行：s == "abc"
s.substr(起点, 个数)从起点开始抄几个字节出来。第二个参数是「抄几个」，不是「抄到哪儿」：s 是 "abcde" 时，s.substr(1, 3) 是 "bcd"。个数写超了没事，抄到末尾为止；起点越界会当场死掉
s.find("ab")找得到就给它的位置（从 0 数），找不到给 std::string::npos
if (s.find("ab") == std::string::npos)判断「没找到」的标准写法，整句写进 if 里。别拿 -1 去比
s.empty()是不是空串。和 s.size() == 0 一个意思，写起来短
std::getline(std::cin, s);读一整行进来，中间的空格也算这一行的内容。1.5 留下的那句「用到的时候再来看」，指的就是它（1.5）
std::to_string(x)数字转成文字，好拼进 std::cout 里。小数一律给六位：std::to_string(3.5) 是 "3.500000"，std::to_string(42) 是 "42"
std::stoi(s)文字转 int：从开头读数字，读到不是数字为止——"4x2" 得到 4，"-7" 得到 -7。开头就不是数字（"abc"）会当场死掉

变长数组：vector

写法含义
std::vector<int> v = {1, 2, 3};声明的时候直接把初值塞进去，花括号的写法和数组一样（4.1）。push_back、size()、v[i] 那些在 B 表里（4.6）
v.pop_back()删掉末尾那一个，长度减 1。空的时候别调
v.clear()清空，长度变 0。清完还能接着 push_back
v.empty()是不是空的。和 v.size() == 0 一个意思，写起来短
v.front() / v.back()第一个／最后一个，比写 v[0]、v[int(v.size()) - 1] 短。空的时候别调

排序、查表这些不在表里。
