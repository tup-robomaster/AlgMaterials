Python 工具与视觉脚本

这门课面向已经会写 C++ 的读者，用 Python 写日常小工具与视觉脚本。 内容从脚本运行、报错阅读与第一个批量读图工具开始，经过字符串、列表、 字典、控制流与函数，再进入 NumPy、OpenCV、数据图表与工程测试。 每个例子都给出完整程序与真实输出，每课两道练习要求独立写出可运行的脚本。

怎么读这门课

全课 10 个部分、51 课，分三档要求。第 0–1 部分是基础， 建议按顺序读完，并亲手运行、修改例子。第 2–7 部分按需阅读： 每一部分开头先列前置课，读完前置再按当前任务选读。 第 8–9 部分是综合练习，建议在读完第 1–7 部分的相关必读课之后再做。

档次部分读到什么程度
基础 第 0–1 部分 按顺序读；例子必须运行，参数要能改，输出要能解释
按需 第 2–7 部分 先读该部分列出的前置课，再按任务选读；不要求从头到尾
综合 第 8–9 部分 独立完成一条完整脚本流程与一组检测题

具体到每一课，用四个词标注要求。会用指能运行、能改参数、能解释输出； 掌握指能独立写出一段完整脚本并定位常见错误；看懂指能读懂代码与 参数，不要求独立实现；了解指知道概念、流程与适用场景。

全课有四课标为选学：1.7、2.5、3.7 与 8.4。选学课可以跳过， 也不进入任何部分的前置。

每页怎么读

课里的 Python 例子都是完整脚本，代码块后紧跟真实输出；涉及文件的例子 还会给出终端命令与结果文件的内容。练习先自己写，卡住了再展开答案。 运行方法与练习目录见 0.1， 报错的阅读方法见 0.3。 课程假设读者已经会写基本的 C++ 程序：变量、循环、函数与数组， 能用一条命令编译并运行源文件；Python 的语法从第 0 部分开始介绍。

素材说明

课程例子使用的图片与文本都随课程放在本地。 合成素材由课程附带的生成脚本生成，位置、颜色与尺寸固定， 重复运行得到同一组文件。

六张 PNG 分别是：synth_shapes.png 为 640×480 的彩色几何 图形，synth_balls.png 为 640×480 的彩色圆球， synth_grid.png 为 320×240 的灰度棋盘； synth_chess_1.png 到 synth_chess_3.png 是 三张 640×480 的棋盘格标定图，图案为 9×6 内角点，三张姿态不同。 文本素材有四份：synth_notes.txt 是四行“名字,分数”， synth_scores.csv 带表头、空行与坏行， synth_config.json 与 synth_config.yaml 是内容 等价的两份嵌套配置。视频素材有一份：synth_cube.mp4 是 320×240、每秒 12 帧、共 36 帧的合成视频，橙色方块沿水平方向移动。

关于结果文件

0.4 的例子会写出 out_sizes.txt，4.6 会写出 out_points.csv，5.1 到 5.6 会写出 out_*.png、out_video/ 与 out_camera/。这些结果写在课程根目录，不写进素材目录； 删除后重新运行即可再生成。

第 0 部分 · 开始

基础，5 课，无前置。只要求能读懂 C++ 基本语句。 这一部分把练习目录、脚本运行、报错阅读与一个完整工具走通。

  • 0.1 练习目录与代码约定 复制练习目录、运行检查脚本、代码与输出块的阅读约定
  • 0.2 第一个脚本 main 与入口判断；脚本结构；运行与退出码
  • 0.3 报错与调试 读 traceback；文件不存在、缩进、名字与类型四类错误；调试顺序
  • 0.4 第一个完整工具：批量读取图片尺寸 pathlib 遍历、cv2.imread、尺寸与类型、写入结果文件
  • 0.5 从 C++ 到 Python：要改的习惯 名字与别名、切片复制、函数修改列表、真除法与整除、真值判断

第 1 部分 · 语法与容器

基础，7 课，前置 0.1–0.5。这一部分从值与类型开始，讲清字符串、 列表、元组、字典与集合，最后写条件、循环、推导式与函数；1.7 为选学的 命名空间。

  • 1.1 值、变量与类型 常见类型；名字绑定；转换与浮点精度；isinstance 与 is None
  • 1.2 字符串与格式化 下标与切片；strip、split、join；f-string 对齐；逐行读文本
  • 1.3 列表、元组与切片 增删与查找；sort 与 sorted；切片复制；enumerate 与 zip；嵌套容器
  • 1.4 字典与集合 get、setdefault、update；插入顺序；交并差；Counter
  • 1.5 控制流与推导式 if/elif/else；for/else 与 while；列表、字典、集合推导式；key 函数
  • 1.6 函数 定义与调用；位置、关键字与默认参数；多返回值与作用域；可变默认值
  • 1.7 命名空间（选学） 模块、函数、类与对象的命名空间；LEGB 查找与遮蔽；globals、locals、vars；SimpleNamespace

第 2 部分 · 函数、类与模块

按需，5 课，前置 1.1–1.6。这一部分把参数、作用域与闭包讲细， 用类与 dataclass 组织检测结果，再把脚本拆成模块与包； 2.5 为选学的迭代器、生成器与装饰器。

  • 2.1 参数、作用域与闭包 仅位置与仅关键字参数；可变默认值；LEGB 与 nonlocal；计数器闭包；partial
  • 2.2 类与对象 类与实例属性；__init__ 与 __repr__；@dataclass；组合与继承；对象列表排序
  • 2.3 模块、包与导入 模块与包；绝对导入；python3 -m；主程序入口；导入路径排错
  • 2.4 类型标注与文档字符串 参数与返回值标注；容器类型；运行时不检查；__annotations__ 与 inspect.signature
  • 2.5 选学：迭代器、生成器与装饰器 迭代协议；yield 与惰性求值；装饰器与 wraps；分批处理与计数

第 3 部分 · 文件、异常与标准库

按需，7 课，前置 1.1–1.6、2.1、2.3。这一部分处理文件、目录、配置、 命令行与日志，最后选学二进制帧；3.7 为了解内容。

  • 3.1 文件读写与 with open 的读写模式；逐行处理；Path.write_text；编码与换行
  • 3.2 异常与错误处理 常见异常；try/except/else/finally；自定义异常；批处理跳过坏行与退出码
  • 3.3 pathlib 与目录遍历 路径拼接；name、stem、suffix；iterdir 与 glob；创建与改名
  • 3.4 CSV、JSON 与 YAML 配置 DictReader 与 DictWriter；JSON 读写；yaml.safe_load；默认值与校验
  • 3.5 argparse 与命令行工具 位置与可选参数；type、default、choices；main 返回退出码；帮助与错误
  • 3.6 logging 与调试输出 日志级别；记录器与处理器；格式串；延迟格式化；logger.exception
  • 3.7 选学：二进制数据与帧解析 bytes 与 bytearray；struct；CRC8；帧结构；缓冲区与半包

第 4 部分 · NumPy 数组与向量化

按需，6 课，前置 0.4、1.1–1.6。这一部分从 ndarray 的创建与内存讲起， 依次进入索引与视图、形状与广播、统计与直方图、线性代数与随机数； 每个例子都给出完整程序与真实输出。

  • 4.1 ndarray 的创建与内存 创建数组；形状、类型与大小；内存布局与步长；类型转换与溢出
  • 4.2 索引、切片与视图 下标与切片；视图与副本；布尔掩码与 where；花式索引与轴
  • 4.3 形状、广播与向量化 reshape 与转置；拼接与堆叠；广播规则；按轴聚合与归一化
  • 4.4 统计、排序与直方图 均值、标准差与极值；最值与坐标；分位数与直方图；排序、排名与缺失值
  • 4.5 线性代数 矩阵与向量；解线性方程组；逆、行列式与范数；最小二乘与 SVD
  • 4.6 随机数与可复现 生成器与种子；常见分布；随机掩码与抽样；保存与复现

第 5 部分 · OpenCV 图像、视频与标定

按需，7 课，前置 3.1、4.1–4.6。这一部分把数组知识落到图像与视频： 读写与通道、颜色与阈值、形态学与轮廓、视频逐帧处理、摄像头回退、 相机标定，最后比较循环与向量化的耗时。

  • 5.1 图像的读取、通道与保存 读图标志；形状、类型与像素；通道拆分与合并；区域与保存
  • 5.2 颜色空间、阈值与掩码 BGR 与 HSV；inRange 与双区间；掩码统计与连通区域；Otsu 与自适应阈值
  • 5.3 形态学、边缘与轮廓 腐蚀、膨胀与开闭运算；Canny 边缘；轮廓、面积与周长；外接矩形与圆形度
  • 5.4 视频的读取与写出 打开视频与元数据；逐帧读取；写出视频；抽帧与释放
  • 5.5 摄像头与回退视频 打开摄像头；读取失败与回退；显示窗口与按键；无摄像头环境
  • 5.6 相机标定与去畸变 棋盘格与世界坐标；角点检测与细化；标定与重投影误差；去畸变与位姿
  • 5.7 性能与内存 计时方法；循环与向量化；视图与副本；优化顺序

第 6 部分 · 数据与图表
