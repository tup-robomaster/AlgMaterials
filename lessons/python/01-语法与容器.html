读本部分之前，需要先读 0.1（练习目录）、 0.2（第一个脚本）、 0.3（报错与调试）、 0.4（批量读取图片尺寸）与 0.5（从 C++ 到 Python）。

1.1值、变量与类型

Python 的每个值都有类型，但变量本身不声明类型。名字在赋值时绑定到对象， 之后可以重新绑定到另一种类型的对象。这一课先认清常见类型，再讲转换与 判断类型时容易犯的错误。

值与类型

整数 int 的位数不受固定宽度限制，可以表示任意大的整数； 浮点数 float 是双精度二进制数；布尔值 bool 只有 True 与 False 两个对象；空值 None 表示“没有值”；字符串 str 是不可变的 Unicode 文本；列表 list 是可变的有序容器。

type(value) 返回类型对象，type(value).__name__ 取类型名。布尔类型是整数的子类，isinstance(True, int) 为真；因此判断“是不是整数”时，布尔值也会通过。需要排除布尔值时， 再加一条 not isinstance(value, bool)。

变量是名字

赋值语句 a = 1 把名字 a 绑定到整数对象 1。 再写 a = "one"，名字改绑到字符串对象，原来的整数对象 若没有别的名字引用，会被回收。名字没有类型，对象才有类型。

同一行可以给多个名字赋值：x, y = 1, 2。 右边先组成一个元组，再按位置解包给左边。交换两个变量写成 x, y = y, x，不需要临时变量。

转换与精度

int("42") 把十进制字符串转换为整数；int(3.9) 截断小数部分得到 3，不四舍五入。float("3.5") 把字符串 转换为浮点数；str(42) 把数字转换为字符串。 转换失败会抛出 ValueError，例如 int("3.5")。

浮点数用二进制表示，很多十进制小数无法精确存储。 0.1 + 0.2 的结果不是精确的 0.3，而是接近 0.3 的另一个数。 需要精确十进制时使用 decimal.Decimal；一般测量与图像计算 使用浮点数即可，比较时留一个容差。

round(value, digits) 按二进制实际值舍入，遇到正好一半时 取偶数的方向。因此 round(2.675, 2) 得到 2.67， 而不是直觉上的 2.68。需要按十进制规则舍入时，同样使用 Decimal 或先转换成整数处理。

判断类型

多数情况下不需要判断类型，直接使用对象支持的操作即可；传入不支持的类型 会抛出 TypeError。确实需要分支时，用 isinstance(value, (int, float)) 判断一组类型， 比 type(value) == int 更合适：后者会把布尔值与子类排除在外。

None 只与自身相等，判断用 value is None。 is 比较两个名字是否指向同一个对象，== 比较值是否相等；对整数、字符串等不可变对象，两者常常给出相同结果， 但对列表与自定义对象可能不同。

1.2字符串与格式化

字符串是不可变的 Unicode 序列。所有“修改”字符串的方法都返回新字符串， 原字符串保持不变。这一课讲下标、切片、常用方法与 f-string 的对齐， 最后读入一份逗号分隔的文本并打印成表。

下标与切片

下标从 0 开始，负数从末尾数起：text[0] 是第一个字符， text[-1] 是最后一个。切片写作 text[start:stop:step]， 包含 start，不包含 stop；省略 start 从开头开始，省略 stop 一直到末尾。 text[::-1] 得到倒序字符串。

下标越界抛出 IndexError；切片越界不报错，会自动截到边界。 判断字符是否存在用 in，例如 "a" in text。

常用方法

strip() 去掉两端空白，lstrip() 与 rstrip() 只去一边；split(sep) 按分隔符拆成列表， 不给参数时按任意空白拆分；sep.join(items) 把字符串列表 连接成一个字符串；replace(old, new) 返回替换后的新字符串； startswith 与 endswith 判断前后缀； upper 与 lower 转换大小写。

这些方法都返回新对象，不修改原字符串。写成 text.strip() 而不接收返回值，原字符串不会变化；需要保留结果时赋值给新名字。

f-string 与对齐

f-string 以 f 开头，花括号里写表达式，冒号后写格式说明符。 {name:<8} 左对齐占 8 个字符，{score:>4} 右对齐占 4 个字符；{value:.2f} 保留两位小数。 格式说明符只影响显示，不改变变量本身。

宽度按字符数计算，不按显示宽度计算。中文字符在终端里通常占两列， 用 f-string 对齐中文表格时，列可能看起来仍不齐；需要严格对齐时， 先按显示宽度计算填充，或把中文放在最后一列。

逐行处理文本

Path.read_text(encoding="utf-8") 一次读入整个文件， splitlines() 按行拆开并去掉行尾换行。每一行再用 split(",") 拆成字段。若字段两端可能有空格，先对每个字段 调用 strip()。

文件末尾的空行会产生空字符串；读入后先过滤空行，或确认文件格式固定。 写文件时用 write_text 并明确编码，避免平台默认编码不同。

例题 · 读入分数表

题目：读入 素材/synth_notes.txt，每行是“名字,分数”。按分数是否达到 85 标出 A 或 B，对齐打印，再输出平均分、第一行原文、大写形式与一个切片。

完整程序：

from pathlib import Path

lines = Path("素材/synth_notes.txt").read_text(encoding="utf-8").splitlines()
total = 0
rows = []
for line in lines:
    name, text = line.split(",")
    score = int(text)
    total += score
    rows.append((name, score))

for name, score in rows:
    level = "A" if score >= 85 else "B"
    print(f"{name:<8}{score:>4}  {level}")

mean = total / len(rows)
print(f"mean={mean:.2f}")
print("first line:", lines[0])
print("upper:", lines[0].upper())
print("slice:", lines[1][:4])

运行：

beta      78  B
gamma     85  A
delta     66  B
mean=80.25
first line: alpha,92
upper: ALPHA,92
slice: beta

split(",") 把每行拆成两个字段，int(text) 把分数字符串转换为整数。{name:<8} 左对齐名字，{score:>4} 右对齐分数。lines[1][:4] 取第二行的前四个字符，得到 beta。

1.3列表、元组与切片

列表是有序、可变的容器，适合存放一组同类的值；元组有序但不可变， 适合表示一条固定结构的记录。两者都支持下标、切片、解包与遍历。

增删与查找

append(value) 在末尾追加一个元素，extend(items) 把另一个容器的元素逐个追加，insert(index, value) 在指定位置 插入。remove(value) 删除第一个相等的元素，值不存在时抛出 ValueError；pop(index) 删除并返回指定位置的元素， 默认删除最后一个。

index(value) 返回第一个相等元素的下标，count(value) 统计出现次数，value in items 判断是否存在。 len、min、max、sum 是内置函数，直接接收列表。

排序与切片

sorted(items) 返回一个新列表，原列表不变； items.sort() 原地排序并返回 None。 两者都接受 reverse=True 与 key=函数。 对字符串列表，默认按字符编码顺序排序；对数字列表，按数值排序。

切片 items[start:stop:step] 返回新列表，是浅拷贝。 items[-3:] 取最后三个，items[::2] 每隔一个取。 切片赋值可以替换一段元素，例如 items[1:3] = [0, 0]。

解包、enumerate 与 zip

元组与列表都可以解包：name, score = pair。 enumerate(items, start=1) 同时给出下标与元素， 省去手工维护计数器。zip(a, b) 把两个序列按位置配对， 长度不同时以短的一边为准。

遍历时若同时需要下标与值，优先用 enumerate， 不要写 for i in range(len(items)) 再取 items[i]；前者更短，也不容易越界。

嵌套列表与元组

列表可以嵌套，形成二维表。访问时先写外层下标，再写内层下标： table[row][col]。切片与 list() 只复制外层，内层列表仍与原列表共享；需要完全独立时使用 copy.deepcopy。

元组用圆括号或逗号创建，单元素元组必须写尾逗号： (1,)。元组不可变，因此可以作为字典的键与集合的元素； 列表不能。函数返回多个值时，实际返回的是一个元组，调用处可以直接解包。

1.4字典与集合

字典把键映射到值，按键查找的平均时间是常数级；集合只保存不重复的元素， 适合去重与成员判断。两者都使用哈希表实现，键必须是可哈希的不可变对象。

字典的读写

创建字典写成 table = {"alpha": 92, "beta": 78}。 用 table[key] 读取，键不存在时抛出 KeyError； table.get(key, default) 在键不存在时返回默认值，不抛异常。 赋值 table[key] = value 会新增或覆盖。

setdefault(key, default) 在键不存在时写入默认值并返回它， 已存在时直接返回原值，常用于分组与计数。 update(other) 用另一个字典批量覆盖； pop(key, default) 删除并返回值；del table[key] 删除键，键不存在时抛出 KeyError。

遍历与排序

字典保持键的插入顺序。遍历 table 得到键， table.keys()、table.values() 与 table.items() 分别得到键、值与键值对视图。 需要固定顺序时，用 sorted(table) 或 sorted(table.items())。

items() 的每个元素是元组，可以直接解包： for key, value in table.items():。 遍历时不要同时增删字典的键，否则会抛出 RuntimeError；先把要删除的键收集到列表，再逐个删除。

集合运算

集合用花括号创建，空集合必须写 set()，因为 {} 是空字典。集合支持并集 |、交集 &、 差集 - 与对称差 ^；对应的方法 union、intersection、difference 返回新集合，带 _update 后缀的方法原地修改。

集合的元素没有顺序，打印顺序不应当作为程序结果的一部分。 需要稳定输出时，先 sorted(set) 再打印。

计数与 Counter

collections.Counter 是字典的子类，用来计数。 Counter(items) 统计每个元素出现次数； most_common(n) 返回出现最多的 n 项，按次数从高到低排列， 次数相同时保持首次出现的顺序。

手工计数也可以写成 counts[word] = counts.get(word, 0) + 1， 这行代码同时演示了 get 的默认值。数据量大时使用 Counter 更清楚。

1.5控制流与推导式

Python 的条件与循环靠缩进划分代码块，没有圆括号与花括号。 推导式把“对每个元素做变换并筛选”写成一行，适合生成列表、字典与集合。

条件分支

if、elif、else 从上到下判断， 第一个为真的分支执行，其余跳过。条件可以是任意对象，空容器、零与 None 为假。条件表达式 level = "A" if score >= 90 else "B" 适合只有两个结果的场合； 分支多于两个时，用完整的 if/elif/else 更清楚。

比较可以连写：0 <= score < 100 等价于 0 <= score and score < 100，且 score 只求值一次。判断 None 用 is None， 判断布尔值直接写 if flag:，不必写 == True。

循环与 else

for item in items: 依次取出元素；需要下标时配合 enumerate，需要数字序列时用 range(start, stop, step)， 同样不含 stop。while condition: 在条件为真时重复， 循环体里必须有机会改变条件，否则会一直运行。

break 立即结束整个循环，continue 跳过本轮剩余语句。 循环可以带 else：循环正常结束（没有被 break 中断）时执行 else 分支。查找“第一个满足条件的元素”时， 这种写法比额外维护一个标志变量更直接。

推导式

列表推导式写作 [表达式 for 元素 in 序列 if 条件]， 结果是一个新列表。字典推导式用 {键: 值 for ...}， 集合推导式用 {元素 for ...}。生成器表达式把方括号换成圆括号， 不一次性建立列表，适合直接传给 sum、max 等函数。

推导式只适合一层循环加一个条件。嵌套两层以上，或表达式本身很长时， 改回普通循环更易读。推导式里不要调用有副作用的函数，也不要在其中修改 被遍历的容器。

选择写法

同一件事常有三种写法：普通循环、推导式、内置函数。选择的标准是读者能否 一眼看出“输入是什么、输出是什么”。计数用 sum(1 for ...)， 变换用列表推导式，聚合用 sum、max、min； 需要提前退出或打印中间结果时，用普通循环。

1.6函数

函数把一段逻辑命名并隔离作用域。Python 的函数是一等对象，可以赋给名字、 作为参数传递，也可以从函数返回。这一课讲定义、参数、返回值与作用域， 最后说明可变默认值的陷阱。

定义与调用

def name(parameters): 定义函数，函数体缩进。调用时写 name(arguments)，按参数位置传值。函数名后的圆括号不能省； 没有参数也要写 ()。函数定义本身不执行函数体，调用时才执行。

函数的第一条语句可以写文档字符串，用三个引号包围，说明参数、返回值与 副作用。help(name) 与编辑器的提示会读取它。文档字符串不是 注释，它保存在函数的 __doc__ 属性里。

参数形式

位置参数按顺序传入；关键字参数写成 name=value，顺序可以调整。 默认参数在定义时求值，调用时省略则使用默认值。默认参数必须放在 非默认参数之后。

*args 收集多余的位置参数为一个元组，**kwargs 收集多余的关键字参数为一个字典。调用时也可以用 *items 与 **table 把容器展开成参数。参数列表里单独一个 * 表示后面的参数只能按关键字传入。

返回值与作用域

return 结束函数并返回一个值；返回多个值时，实际返回元组， 调用处可以解包。pass 表示空语句。没有 return 的函数返回 None。

函数内部赋值的名字默认是局部变量，函数外不可见；读取外部变量可以直接读， 但要在函数内修改它，需要 global 或 nonlocal 声明。多数情况下应当通过参数传入、通过返回值传出，避免修改全局状态。

可变默认值

默认参数在函数定义时求值一次，之后每次调用共享同一个对象。 若默认值是列表、字典等可变对象，函数内的修改会累积到下一次调用。 正确写法是把默认值设为 None，在函数体内判断并新建容器。

这条规则同样适用于类的实例属性与闭包。只要默认值是可变的，就要检查 它是否被多个调用共享。整数、字符串、元组与 None 不可变， 作为默认值没有问题。

def append_bad(value, bucket=[]):
    bucket.append(value)
    return bucket

1.7命名空间（选学）

Python 的名字不是散放在程序里的。每个名字都写在一个命名空间中； 命名空间是名字到对象的映射。赋值把名字写进当前命名空间，读取名字时 按固定顺序查找。同名变量、导入写法与 global 的行为， 都可以从这一点解释。

名字住在哪里

模块里的代码在模块命名空间中执行。一个 .py 文件被导入或 直接运行时，里面的函数名、变量名与导入的名字都记在这个命名空间里， globals() 返回它的字典。

调用函数时，Python 新建一个局部命名空间；参数和函数内赋值的名字放在 这里。函数返回后，这个命名空间通常被回收，名字不再可见。 locals() 给出当前局部命名空间的快照。

类定义也有自己的命名空间；类属性记在这里，实例属性则记在实例自己的 命名空间中。vars(类) 与 vars(实例) 分别返回 两者的属性字典。内置名字 print、len 在 builtins 模块的命名空间中，程序启动时自动可用。

查找顺序与遮蔽

读取一个名字时，Python 依次查找局部、外层函数、模块全局与内置命名空间， 通常称这个顺序为 LEGB。找到第一个就停止，因此内层同名名字会遮蔽外层。

赋值总是写当前命名空间，不会自动改写外层。函数内给全局名字赋值时， 需要 global 声明；改写外层函数的变量时，需要 nonlocal。多数情况下，通过参数传入、通过返回值传出比 修改外层状态清楚。

模块、类与对象

import math 把整个模块对象绑定到当前命名空间的 math，之后用 math.sqrt 访问模块命名空间里的 sqrt。from math import sqrt 只把函数对象绑定到 当前命名空间的 sqrt；两个名字指向同一个函数，但当前命名 空间里多出的名字不同。

obj.attr 是在对象的命名空间里找名字。实例属性放在实例的 __dict__，类属性放在类的命名空间；读取实例属性时先找实例， 再找类。给实例属性赋值只影响该实例，不会改动类属性。

模块、类与实例都可以看作命名空间的载体。看到 NameError 或属性找不到时，可以先问名字写进了哪个命名空间。

查看命名空间

globals()、locals() 与 vars() 用来查看命名空间的内容，dir() 列出可用名字。它们适合在 交互环境里探索，不建议在正式程序里靠 globals() 动态创建 变量；显式的字典或对象属性更容易读。

types.SimpleNamespace 创建一个只有属性的简单对象，适合把 一组配置放在一起。属性写在对象自己的命名空间中，访问方式与普通对象 一致。

    return "small" if value < threshold else "large"


def local_names(value):
    doubled = value * 2
    return sorted(locals())


class Box:
    kind = "box"

    def __init__(self, name):
        self.name = name


config = SimpleNamespace(threshold=5, label="ball")

import math
from math import sqrt

scale = 2


class Point:
    dimensions = 2

    def __init__(self, x, y):
        self.x = x
        self.y = y


def local_names(value):
    doubled = value * 2
    return sorted(locals())


point = Point(6, 8)
print("sqrt:", sqrt(25))
print("hypot:", round(math.hypot(point.x, point.y), 1))
print("class keys:", sorted(name for name in vars(Point) if not name.startswith("__")))
