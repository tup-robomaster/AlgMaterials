4.1ndarray 的创建与内存

NumPy 的核心是 ndarray（N-dimensional array，N 维数组），它把同一种 数据类型的元素放在一段连续内存里，并记录形状、步长与字节序。Python 列表 可以混放不同类型，逐个元素访问；ndarray 要求类型一致，换来的是整块数据的 批量运算与更小的存储开销。这一课从创建数组开始，依次看形状、类型、步长与 类型转换。

创建数组

np.array(seq, dtype=...) 从列表或嵌套列表构造数组，默认按 元素推断类型。np.zeros(shape) 与 np.ones(shape) 创建全零与全一数组，np.full(shape, value) 用指定值填满。 形状写成元组：(2, 3) 表示两行三列，(3,) 表示 长度为 3 的一维数组。

np.arange(start, stop, step) 与 Python 的 range 一样不含终点，步长可以是小数；np.linspace(start, stop, num) 按个数等分，默认包含终点。需要固定类型时显式写 dtype， 例如图像用 uint8，坐标用 float32。 

a = np.array([[1, 2, 3], [4, 5, 6]])
z = np.zeros((2, 4), dtype=np.uint8)
o = np.ones((3,), dtype=np.float32)
f = np.full((2, 2), 7)
r = np.arange(0, 10, 3)
l = np.linspace(0.0, 1.0, 5)

np.array 默认复制输入数据；np.asarray 在输入已经 是 ndarray 且类型相同时直接返回原对象，不复制。创建之后数组的大小固定， 不能像列表那样追加元素；需要更多空间时新建一个更大的数组，再把旧数据写进去。

形状、类型与大小

shape 是各维长度的元组，ndim 是维数， size 是元素总数，等于 shape 各分量相乘。 dtype 是元素类型，itemsize 是每个元素占的字节数， nbytes 是整块数据占的字节数，等于 size * itemsize。

彩色图像从 OpenCV 读入后形状是 (高, 宽, 3)，三个通道按蓝、 绿、红排列；灰度图是 (高, 宽)。一张 640×480 的彩色图有 640×480×3=921600 个 uint8 元素，占 921600 字节。 len(array) 只返回第一维的长度，不等于元素总数，统计大小时用 size。

内存布局与步长

步长（stride）是沿某一维走一步所跨的字节数，单位是字节而不是元素。 C 顺序（C order）把最后一维排得最密，行与行之间相隔一整行；Fortran 顺序 （Fortran order）相反，第一维最密。创建时写 order="F" 得到 列优先的数组，flags["C_CONTIGUOUS"] 与 flags["F_CONTIGUOUS"] 分别报告两种连续性。 

a = np.arange(6, dtype=np.int16).reshape(2, 3)
a.T
view = a[0]
view[0] = 9

a 是两行三列的 int16，每个元素 2 字节，行步长 为 3×2=6，列步长为 2。转置只交换两个轴的步长，没有搬动数据，所以 a.T 的步长是 (2, 6)，它不再是 C 连续。 a[0] 是原数组第一行的视图，改 view[0] 就是改 a[0, 0]，a[0] 因此变成 [9, 1, 2]。

OpenCV 读入的图像是 C 连续的。转置、切片与 transpose 得到的 数组可能不连续；有些函数要求连续内存，遇到这类报错时先调用 np.ascontiguousarray(array) 复制成 C 连续，再传入。

类型转换与溢出

astype(dtype) 返回转换后的新数组，默认复制；浮点转整数时 小数部分被截断，向零取整。整数类型有固定范围：uint8 是 0 到 255，int8 是 −128 到 127，int16 是 −32768 到 32767。超出范围时按模运算回绕，不报错。

回绕是图像处理的常见错误：两个 uint8 相加，250+10 得到 4 而不是 260。需要保留范围时先转成更宽的类型，例如 astype(np.int16) 或 astype(np.float32)，算完再 裁剪并转回。np.clip(array, 0, 255) 把越界值压到边界， 避免回绕。

浮点数不能用 == 直接比较，0.1 + 0.2 与 0.3 的二进制表示不同，比较结果为 False。 判断两个浮点数组是否相等用 np.allclose(a, b) 或 np.isclose(a, b)，它们按相对与绝对容差比较。

4.2索引、切片与视图

索引决定取哪几个元素，切片决定取哪一块；NumPy 的切片通常返回视图， 与父数组共用同一段内存。视图与副本的区别直接决定修改会不会影响原图， 也是用 OpenCV 裁剪区域时必须留意的第一件事。

下标与切片

多维数组用逗号分隔各维下标：a[i, j] 取第 i 行第 j 列， a[i] 取一整行，a[:, j] 取一整列。每一维都可以 写切片 start:stop:step，起点包含、终点不包含，省略起点表示 从头开始，省略终点表示到最后。负下标从末尾数起，a[::-1] 把第一维倒序。 

a = np.arange(12).reshape(3, 4)
a[1, 2]
a[1]
a[:, 1]
a[::2, 1:3]

a[1, 2] 是第 2 行第 3 列的元素，值为 6。行切片 a[1] 得到长度 4 的一维数组；列切片 a[:, 1] 同样是一维数组，元素来自每一行的第 2 列。a[::2, 1:3] 取第 0、2 行与第 1、2 列，结果形状是 (2, 2)。

切片写错时不会报越界，而是安静地返回空数组或较短的结果。例如 a[5:8] 在长度为 3 的轴上返回空数组，a[1:100] 只取到末尾。读完切片结果后先打印 shape，确认取到的范围与 预期一致。

视图与副本

基本切片返回视图（view），视图与原数组共用数据，只记录自己的形状与步长。 修改视图的元素，原数组对应位置一起改变；反过来修改原数组，视图也看得到。 copy() 返回副本（copy），副本拥有独立内存，修改副本不影响 原数组。判断两个数组是否共用内存用 np.shares_memory(a, b)。

视图省内存，也带来副作用。从图像中裁出一块区域做处理时，如果希望原图 保持不变，裁剪后立刻调用 copy()；如果希望把处理结果写回原图， 直接使用视图即可。OpenCV 的绘图函数会修改传入的数组，把视图传进去， 原图上的对应区域也会被画上。

花式索引与布尔索引返回副本，不是视图。用整数数组取出的行、用掩码筛出的 元素都不与原数组共享内存；修改这些结果不会写回原数组。需要写回时，用 视图做切片赋值：a[mask] = value 直接改原数组。

布尔掩码与 where

比较运算逐元素进行，返回同形状的布尔数组，称为掩码（mask）。 mask.sum() 统计为真的元素个数，mask.mean() 得到为真的比例。a[mask] 把为真的元素取成一维数组， 顺序按行优先，先第一行从左到右，再第二行。 

a = np.array([5, 1, 4, 2, 3])
mask = a > 2
mask.sum()
mask.mean()
a[mask]
np.where(mask, a, 0)

对 a = [5, 1, 4, 2, 3]，掩码为 [True, False, True, False, True]，a[mask] 得到 [5, 4, 3]，where 填零后得到 [5, 0, 4, 0, 3]。

np.where(condition, x, y) 按条件逐元素选择：条件为真取 x，为假取 y，两个分支可以是标量，也可以是与 条件同形状的数组。只传条件时，np.where(mask) 返回为真元素的 坐标元组，图像中常用它定位亮点的行列。

多个条件组合要用位运算符 &、|、 ~，每个条件加括号：(gray > 50) & (gray < 200)。 Python 的 and 与 or 只接受单个真假值，不能逐元素 运算，写进数组条件会抛出“truth value of an array is ambiguous”。

花式索引与轴

花式索引（fancy indexing）用整数数组作为下标。写一个整数数组 a[[0, 2]] 取第 0、2 行；写两个等长整数数组 a[[0, 1], [1, 2]] 按位置配对，取 (0,1) 与 (1,2) 两个元素， 结果是一维数组。花式索引的结果是副本，形状由下标数组的形状决定。

np.take(a, indices, axis=0) 沿指定轴取元素，语义与整数数组 下标相同，适合把索引放在变量里。轴（axis）是数组的维度编号，从 0 开始； 对二维数组，axis=0 沿行方向减少行数，axis=1 沿列方向减少列数。

np.newaxis（也可写 None）在索引中增加一个长度 为 1 的轴：a[:, np.newaxis] 把形状 (n,) 变成 (n, 1)，a[np.newaxis, :] 变成 (1, n)。增加轴不复制数据，只改变形状与步长，常用于让两个 数组在广播时对齐。

4.3形状、广播与向量化

数组的形状决定索引方式，广播（broadcasting）决定两个不同形状的数组 怎样逐元素运算。把循环写成数组运算称为向量化（vectorization）：表达式 更短，循环交给底层编译好的代码执行，通常也更快。这一课从改变形状开始， 再讲拼接、广播与按轴聚合。

reshape 与转置

reshape(shape) 在不改变元素顺序的前提下重新解释形状，元素 总数必须一致；某一维写 −1 表示由其余维自动推算。能返回视图时返回视图， 否则复制一份。transpose(axes) 按给定顺序重排各轴， a.T 等价于把轴的顺序完全颠倒；转置只改步长，不搬动数据。

np.squeeze(a) 去掉长度为 1 的轴，np.expand_dims(a, axis) 在指定位置增加一个长度为 1 的轴。两者都不复制数据。处理单张图像时， 模型或函数常要求输入带批次维，形状从 (高, 宽, 3) 变成 (1, 高, 宽, 3)，用 expand_dims(image, axis=0) 即可。

拼接与堆叠

np.concatenate([a, b], axis=0) 沿已有轴把多个数组接起来， 除拼接轴外其余各维长度必须相同。np.stack([a, b], axis=0) 新建一个轴，把两个同形状数组叠成更高一维的数组。前者把两张 240×640 的 图接成 480×640，后者叠成 2×240×640。

二维场景常用 np.vstack 与 np.hstack： vstack 沿第 0 轴、hstack 沿第 1 轴拼接； np.column_stack([x, y]) 把两个一维数组按列拼成设计矩阵。 拼接会复制数据，得到新数组；在循环里反复拼接会让耗时按平方增长， 需要累积时先放进列表，最后一次性拼接。

广播规则

两个数组形状不同时，NumPy 从最后一维开始向前对齐，逐维比较：长度相等， 或其中一个为 1，就可以广播；缺少的前导维按 1 处理。结果为每一维取较大 的长度。长度为 1 的维在运算时被复制到与另一侧相同，但不会真的分配那么多 内存。 

a = np.arange(6).reshape(2, 3)
a + np.array([10, 20, 30])
a.mean(axis=0)
a.mean(axis=1)

a 是两行三列，每行加上 [10, 20, 30] 得到 [[10, 21, 32], [13, 24, 35]]；按列与按行的平均值分别为 [1.5, 2.5, 3.5] 与 [1.0, 4.0]。

形状 (2, 3) 与 (3,) 相加时，一维数组被当成 (1, 3)，沿行方向复制到两行，因此每一列加上同一个数。 axis=0 沿行方向求平均，得到每一列的平均值，形状 (3,)；axis=1 沿列方向求平均，得到每一行的 平均值，形状 (2,)。

增加轴可以控制广播的方向。形状 (2, 3, 1) 与 (2,) 运算时，(2,) 先补成 (1, 1, 2)， 再广播到 (2, 3, 2)。若两个数组在某一维长度既不相等也都不是 1，NumPy 抛出“operands could not be broadcast together”，报错里会写出 两边的形状，按从右往左的顺序核对。

按轴聚合与归一化

mean、sum、max 等聚合函数默认把 整个数组压成一个标量；给 axis 就只压掉指定的轴，其余轴保留。 keepdims=True 让被压掉的轴保留为长度 1，结果的维数不变， 可以直接参与广播。

图像归一化常写成 (gray - gray.mean()) / gray.std()：先转成 浮点，减去均值再除以标准差，得到均值 0、标准差 1 的数组。对彩色图按通道 处理时，image.mean(axis=(0, 1)) 得到三个通道各自的均值， 形状 (3,)，可以直接与 (高, 宽, 3) 的图像广播。 归一化结果可能超出 0 到 255，显示前用 np.clip 裁剪并转回 uint8。

4.4统计、排序与直方图

检测结果常要汇总成一个数：区域的平均灰度、通道的最大值、最亮点的坐标、 灰度分布的分位数。NumPy 把这些计算写成数组方法或函数，指定轴就能按行、 按列或按通道分别统计。这一课从均值与标准差开始，再讲最值、分位数、 直方图与缺失值。

均值、标准差与极值

mean 返回算术平均，std 返回标准差， min 与 max 返回最小与最大值。默认对整个数组 计算；给 axis 就沿指定轴计算，轴被压掉。对彩色图写 axis=(0, 1)，同时压掉高与宽两个轴，得到每个通道一个值。

std 默认除以元素个数，得到总体标准差；样本标准差要写 ddof=1，分母改为元素个数减一。元素较少时两者差别明显， 报告数据时要写明用的是哪一种。uint8 数组求均值会返回浮点数， 不会回绕；求最大值仍返回 uint8 标量。

最值与坐标

argmax 与 argmin 返回最值在展平后的一维下标， 不是坐标。多维数组要先用 np.unravel_index(index, shape) 把一维下标换成各维下标。存在并列最值时，返回按行优先扫描遇到的第一个。 

values = np.array([[4, 7, 2], [9, 1, 5]])
values.mean()
values.max()
values.min()
values.mean(axis=0)
index = np.argmax(values)
np.unravel_index(index, values.shape)

均值为 4.667，最小值为 1。最大值 9 位于第 1 行第 0 列，展平下标是 3， unravel_index 换回 (1, 0)。按列求平均得到 [6.5, 4.0, 3.5]， 分别对应三列。图像中定位最亮像素时，返回值是 (y, x)， 打印给读者看时要按横、纵坐标的顺序说明，避免把行列写反。

分位数与直方图

np.percentile(a, q) 返回第 q 百分位数，q 可以是单个数字或 列表；中位数就是第 50 百分位数。默认用线性插值，结果可能是小数； 需要整数灰度时再转换。np.median(a) 是求中位数的简写。 

values = np.array([3, 1, 2, 3, 5, 1])
np.sort(values)
np.argsort(values)
np.percentile(values, [25, 75])

对 [3, 1, 2, 3, 5, 1]，排序结果为 [1, 1, 2, 3, 3, 5]，argsort 的下标为 [1, 5, 2, 0, 3, 4]，四分位数为 1.25 与 3.0。

np.histogram(a, bins=..., range=...) 统计落在每个区间的元素 个数，返回计数与区间边界；边界个数比区间数多一。灰度图通常写 bins=256, range=(0, 256)，每个灰度一个区间；区间数少时， 计数之和仍等于像素总数，可以用来核对。

np.sort 返回排好序的副本，原数组不变；array.sort() 原地排序。降序写成 np.sort(a)[::-1]。argsort 返回排序后的下标，用它可以按分数排出名字，而不只是排出分数。默认排序 不保证并列值的先后，需要稳定顺序时写 kind="stable"。

排序、排名与缺失值

np.unique(a, return_counts=True) 返回去重后的值及每个值出现 的次数，值按升序排列；加 return_index 还能得到每个唯一值 第一次出现的位置。统计灰度分布、标签类别与重复坐标时常用这一组返回值。

数据中的缺失值用 np.nan 表示。普通 mean 遇到 nan 会把它传播到结果，整个均值变成 nan； np.nanmean、np.nanstd、np.nanmax 会跳过缺失值再计算。排序时 nan 被放到末尾。不是每个函数都有 nan 版本，拿不准时先打印结果，确认没有静默变成 nan。

4.5线性代数

相机投影、坐标变换与直线拟合都能写成矩阵运算。NumPy 的 numpy.linalg 提供解方程、求逆、行列式、范数、最小二乘与 奇异值分解。这一课用一个小型方程组与一条带误差的直线，走完求解、验算与 拟合的流程。

矩阵与向量

一维数组表示向量，形状 (n,)；二维数组表示矩阵，形状 (m, n)。A @ b 是矩阵乘法，结果的第 i 个分量是 A 的第 i 行与 b 的点积；A * B 是 逐元素相乘，两者含义不同。矩阵乘法要求左侧的列数等于右侧的行数。

设计矩阵把每个样本的特征排成一行：线性拟合 y = k t + b 用两列，第一列是 t，第二列全是 1。构造写成 np.column_stack([t, np.ones_like(t)])，形状 (样本数, 2)。求出的系数是一个长度为 2 的向量，顺序与列一致。

解线性方程组

np.linalg.solve(A, b) 解 A x = b，要求 A 是方阵且满秩。它内部做分解，不显式求逆，速度与数值稳定性 都优于先算 inv(A) 再乘。A 奇异时抛出 np.linalg.LinAlgError，消息为“Singular matrix”。 

A = np.array([[2.0, 1.0], [1.0, 3.0]])
b = np.array([5.0, 10.0])
x = np.linalg.solve(A, b)
np.linalg.det(A)

解出 x = [1, 3]（行列式为 5.0）后要代回原方程验算：第一行 2×1+1×3=5， 第二行 1×1+3×3=10，与右端一致。程序里用 np.linalg.norm(A @ x - b) 计算残差，接近 0 说明解正确。 残差明显不为 0 时，检查矩阵是否抄错、是否病态，而不是直接接受结果。

逆、行列式与范数

np.linalg.inv(A) 返回逆矩阵，np.linalg.det(A) 返回行列式。方阵可逆的判据是行列式不为 0；行列式接近 0 时矩阵病态， 求逆与解方程的结果对输入误差很敏感。A @ inv(A) 应当接近 单位阵，判断时用 np.allclose，不要用 ==。

np.linalg.norm(x) 默认计算向量的 2 范数，即各分量平方和 的平方根；对矩阵默认计算 Frobenius 范数。第二个参数 ord 可以指定 1 范数、无穷范数等。范数把误差与系数量化成单个非负数，便于比较 不同方案。

最小二乘与 SVD

方程个数多于未知数时通常没有精确解，最小二乘（least squares）找使 ‖A x − b‖² 最小的 x。 np.linalg.lstsq(A, b, rcond=None) 返回四个值：系数、残差 平方和、矩阵的秩与奇异值。拟合直线时，系数依次是斜率与截距。 

x = np.array([0.0, 1.0, 2.0, 3.0])
y = np.array([1.0, 3.0, 5.0, 7.0])
design = np.column_stack([x, np.ones_like(x)])
coef, residuals, rank, singular = np.linalg.lstsq(design, y, rcond=None)

这组数据的系数为 [2.0, 1.0]，秩为 2。

奇异值分解（singular value decomposition，SVD）把矩阵写成 U S Vᵀ，S 的对角线是奇异值，按从大到小排列。 np.linalg.svd(A, full_matrices=False) 只保留与秩相关的部分， 适合大矩阵。奇异值的个数与大小可以看出矩阵的有效秩；最小奇异值接近 0 说明矩阵接近奇异。

4.6随机数与可复现

模拟噪声、生成测试数据、随机划分训练集都离不开随机数。计算机给出的是 伪随机数（pseudo-random number），由确定性的算法从一个初始值生成； 初始值称为种子（seed），种子相同，序列就相同。这一课用 numpy.random 的新式生成器演示如何得到可复现的结果。

生成器与种子

np.random.default_rng(seed) 返回一个生成器对象，之后所有 随机数都从它取得。同一个种子创建的两个生成器产生完全相同的序列； 不传种子时使用系统提供的随机初始值，每次运行结果不同。生成器之间互相 独立，不会因为调用顺序不同而互相干扰。 

rng = np.random.default_rng(5)
first = rng.integers(0, 10, size=4)
second = np.random.default_rng(5).integers(0, 10, size=4)

两个生成器用同一个种子 5，各自第一次取四个 0 到 9 的整数，结果逐位相同。 老式写法 np.random.seed 设置的是全局状态，任何库调用都可能 改变后续序列；新代码统一使用 default_rng，把生成器作为参数 传入函数，调用者能控制自己的随机源。

常见分布

normal(loc, scale, size) 生成均值为 loc、 标准差为 scale 的正态分布样本； uniform(low, high, size) 在左闭右开区间内均匀取值； integers(low, high, size) 生成整数，右端不包含； random(size) 生成 0 到 1 之间的浮点数。

样本均值与标准差只是对分布参数的估计，样本越少，偏差越明显。需要精确 复现某个统计量时，固定种子与样本量，并记录库的版本；不同版本的生成器 算法可能变化，不能保证逐位相同。需要长期复现的实验，把生成的数据一并 保存。

随机掩码与抽样

rng.random(shape) < p 生成布尔掩码，每个位置为真的概率 是 p。掩码可以统计覆盖率，也可以作为索引取出子集。 rng.choice(values, size, replace=False) 做无放回抽样， replace=True 做有放回抽样；无放回时样本数不能超过总体。 

rng = np.random.default_rng(5)
rng.choice(["a", "b", "c"], size=2, replace=False)
values = np.arange(5)
rng.shuffle(values)

种子 5 下，choice 取出 ['c', 'b']， shuffle 后的 values 为 [1, 4, 2, 3, 0]。 shuffle(values) 原地打乱数组，返回 None； permutation(values) 返回打乱后的副本，原数组不变。按样本 划分训练集与验证集时，先对下标做 permutation，再按比例切片， 两份数据不会重叠。

保存与复现

np.savetxt(path, array, delimiter=",", fmt="%.3f", header="x,y", comments="") 把二维数组写成文本表格：delimiter 是列分隔符， fmt 控制每个数的格式，header 写表头， comments="" 让表头前面不带 #。 np.loadtxt 按同样的分隔符读回。

保存浮点结果时要确定小数位数。默认格式会写出很多位，文件变大，肉眼也 难核对；固定三位小数足以记录坐标与拟合结果。复现实验时同时保存种子、 样本量与生成参数，读回数据后先用均值、行数等摘要核对，再进入后续计算。
