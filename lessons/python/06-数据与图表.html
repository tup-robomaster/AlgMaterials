6.1画布、坐标轴与折线图

Matplotlib 是 Python 的绘图库，常用的入口是 matplotlib.pyplot。 一次绘图可以分成两层：画布（Figure）表示整张图，坐标轴（Axes）表示带 坐标范围、刻度与线条的绘图区。一个画布可以放一个或多个坐标轴；本部分的 折线图、散点图与直方图都画在坐标轴上。

课程中的脚本在终端运行，因此先选择无窗口后端，再导入 pyplot。 这样绘图结果直接写入文件，不需要桌面窗口，也不会等待人工关闭窗口。

画布与坐标轴

fig, ax = plt.subplots(figsize=(5, 3), dpi=100) 同时建立一张 画布和一个坐标轴。figsize 的单位是英寸，dpi 是 每英寸点数（dots per inch，DPI），两者相乘得到默认像素尺寸：5×100 与 3×100，即宽 500 像素、高 300 像素。省略 figsize 时使用默认 尺寸；省略 dpi 时使用默认分辨率。

matplotlib.use("Agg") 必须在导入 pyplot 之前调用。 Agg 是无窗口的渲染后端（backend），适合服务器、批处理与自动检查。若先 导入 pyplot，后端已经选定，再调用 use 可能没有 效果，甚至报错。

折线与数据

ax.plot(x, y) 按点的顺序画折线，x 与 y 的长度必须相同。两个参数都可以是列表或 NumPy 数组； 数组的逐元素运算可以直接生成纵坐标，例如 y = x ** 2。 折线图（line plot）适合表示随顺序变化的量，横轴通常是时间、序号或 另一个连续变量。

plot 返回一个列表，里面是 Line2D 对象。 只画一条线时写 line, = ax.plot(...)，把唯一元素解包出来， 后面可以用 line.get_xdata() 与 line.get_ydata() 读回数据。颜色、标记与线型通过 color、marker、 linestyle、linewidth 设置；颜色 "tab:blue" 来自默认色板 tab10，是其中的第一种 颜色。

标题、标签与图例

ax.set_title 设置坐标轴标题，set_xlabel 与 set_ylabel 设置两个坐标轴的标签。set_xlim 与 set_ylim 固定显示范围；不设置时，Matplotlib 按数据自动留出 边距。固定范围可以保证多张图使用同一尺度，便于比较。

在 plot 时给 label 赋值，再调用 ax.legend()，图例（legend）就会列出每条线的说明。没有 label 的线不会出现在图例里。图例位置默认自动选择，数据 密集时可以用 loc 指定角落。图中的文字使用英文，是为了避免 默认字体缺少中文字形时显示成方块。

保存与关闭

fig.savefig(path) 把画布写入文件，格式由扩展名决定： .png 无损并支持透明通道，.jpg 有损。 savefig 默认使用画布建立时的 DPI，也可以在调用时用 dpi 覆盖。保存完成后调用 plt.close(fig) 释放 画布；循环里创建很多图而不关闭，会持续占用内存。

终端环境不使用 plt.show()。如果脚本同时需要显示与保存， 可以在保存之后再显示；自动运行的脚本只保存文件，避免等待窗口关闭。

6.2多条曲线、样式与子图

实际比较往往不止一条曲线。可以在同一个坐标轴上重复调用 plot， 用颜色与线型区分；也可以建立并排子图（subplot），让每个坐标轴独立设置 标题与范围。这一课先看样式与图例，再看子图布局，最后从图表对象读回 线条、标题与网格状态。

多条曲线与样式

同一个 ax 上每次 plot 都会新增一条线，线条按 调用顺序叠放。颜色可以用名称、十六进制字符串或色板名；线型用 "-" 实线、"--" 虚线、":" 点线； 标记用 "o" 圆点、"s" 方块等。线宽用 linewidth 设置，单位是点。

多条线使用同一横轴时，把 x 与每组 y 分别传给 plot。如果各条线的数据长度不同，分别调用即可，Matplotlib 不要求不同曲线共享同一个数组。为每条线设置 label，图例才能 区分它们；颜色与线型也应与标签一起考虑，避免只靠颜色传达信息。

图例、网格与参考线

ax.grid(True) 打开主网格，刻度线与网格线对齐，便于读数值。 ax.axhline(y) 画一条水平参考线，ax.axvline(x) 画一条垂直参考线；它们都返回 Line2D，并计入 ax.lines。ax.text(x, y, text) 在数据坐标的 指定位置写文字，常用于标注阈值或特殊点。

参考线使用数据坐标：水平线的位置是纵轴数值，垂直线的位置是横轴数值。 线条颜色与线宽要与数据线区分，通常选灰色、细线或点线。图例只收录带 label 的线；参考线如果没有标签，不会进入图例。

子图布局

fig, (left, right) = plt.subplots(1, 2, figsize=(7, 3)) 建立 一行两列的坐标轴，按从左到右的顺序解包。行列数可以换成 2, 2 等；行列数都大于 1 时，返回的 axes 是 二维数组，按 axes[行, 列] 访问。每个子图有自己的标题、 坐标范围与图例。

fig.tight_layout() 自动调整子图间距，减少标题与标签重叠。 它应在设置标题、标签之后、保存之前调用。子图很多时，间距仍可能不足， 可以配合 fig.subplots_adjust 手动留边；课程例子先使用 tight_layout，让默认布局保持整齐。

读回图表对象

画完图后可以从对象读回状态，用于检查程序是否按预期建立结构： len(fig.axes) 是坐标轴数量，len(ax.lines) 是 该坐标轴的线条数量，ax.get_title() 返回标题， ax.get_legend().get_texts() 返回图例文字列表。 ax.get_xgridlines()[0].get_visible() 返回横轴主网格是否可见。

这些读取操作不改变图形，适合在自动检查与调试中使用。注意参考线也会 增加 ax.lines 的长度：一个数据序列加一条水平线与一条垂直 参考线，合计三条线。读回数量时要按实际画过的对象计算，不能只统计 数据序列。

6.3散点图与直方图

折线图强调顺序，散点图（scatter plot）强调两个变量的对应关系， 直方图（histogram）强调一个变量的分布。这一课用固定随机种子生成 一组学习时长与分数，先画散点，再画直方图，最后检查分箱范围与计数。

散点图

ax.scatter(x, y) 为每组数据画一个点，x 与 y 长度相同。点的大小由 s 设置，颜色由 c 设置；c 可以是一组数值，配合 cmap 把数值映射成颜色。alpha 设置透明度， 点密集时能看出重叠程度。

fig.colorbar(points, ax=left) 为散点添加颜色条，说明数值与 颜色的对应关系。颜色条会占用画布上的一块区域，因此 len(fig.axes) 可能大于数据子图的数量。散点对象存放在 ax.collections 里，通常一组散点占一个集合。

直方图

counts, edges, patches = ax.hist(values, bins=8, range=(40, 100)) 把数据分成 8 个等宽区间。返回值里 counts 是每个区间的计数， edges 是区间边界，长度比计数多 1；patches 是 画出的矩形。区间左闭右开，最后一个区间包含右端点。

range 之外的数据不进入任何区间，也不计入计数总和。因此 counts.sum() 可能小于输入数据的总数，差值是落在范围外的 样本数。画图前先检查数据的实际最小与最大值，避免用错范围而漏掉样本。

分布与分箱

散点图看趋势与离群点，直方图看集中位置与分散程度。分箱数量影响形状： 区间太少会掩盖细节，太多会让每个区间只剩少量样本、图形起伏明显。 常见做法是先按数据范围与样本量选一个适中数量，再观察形状是否稳定。

ax.hist 默认画计数；设置 density=True 后纵轴变成 概率密度，所有矩形面积之和为 1，适合比较样本量不同的两组数据。例子 使用计数，因为可以直接看到每个区间有多少个样本。

可复现的随机数据

rng = np.random.default_rng(7) 建立带种子的随机数生成器， 之后每次调用 rng.uniform 或 rng.normal 都按顺序 从该生成器的序列中取值。固定种子后，同一环境下重复运行得到相同的数组， 图表与打印结果才能逐字核对。

rng.uniform(low, high, size) 生成区间内均匀分布的数， rng.normal(mean, std, size) 生成正态分布的数。例子把学习 时长设为 0 到 10 的均匀分布，把分数设为随时长上升的线性关系再加一点 正态扰动，因此散点图呈现上升趋势，直方图的大部分样本集中在 55 到 100 分之间。

6.4尺寸、分辨率与保存

图表最终要进入报告、网页或论文，文件尺寸与清晰度需要提前控制。这一课 说明英寸、DPI 与像素的关系，比较固定边界与紧凑边界保存的差异，检查 背景颜色与 PNG 通道，最后保存一张包含四个子图的报告图。

英寸与像素

画布的物理尺寸用英寸表示，figsize=(6, 4) 表示宽 6 英寸、 高 4 英寸。dpi 是每英寸点数，像素数等于英寸数乘以 DPI： 6×120 与 4×120 得到宽 720、高 480。屏幕显示时 DPI 影响观感，保存文件时 savefig(dpi=...) 决定输出像素，可以与画布建立时的 DPI 不同。

提高 DPI 会增加像素数，也会增加文件大小与绘制时间，但不会改变线条的 数据位置与画布比例。需要打印的图通常用 150 到 300 DPI；网页预览用 72 到 120 DPI 已经足够。先确定用途，再选择尺寸与 DPI，避免最后再缩放 位图。

紧凑边界

fig.savefig(path, bbox_inches="tight") 把画布裁剪到实际内容 的边界，去掉标题、标签之外的空白。裁剪后的像素尺寸不再严格等于 figsize × dpi，通常会小一些；默认还会在外围保留 0.1 英寸 的边距，可以用 pad_inches 调整。

紧凑边界适合单张报告图与网页插图，因为内容占满画面、空白较少。若多张 图需要严格对齐，固定边界更容易控制像素尺寸；两种方式各有用途，保存后 读回图像数组可以确认实际尺寸。

背景与格式

facecolor 设置画布背景，保存时也可以单独指定； transparent=True 让背景透明，但只有支持透明通道的格式能 保留。PNG 可以保存 RGBA 四通道，JPEG 不支持透明通道，透明区域会被填成 白色或黑色。

matplotlib.image.imread(path) 把图片读成浮点数组，数值范围 是 0 到 1，形状是 (高, 宽, 通道数)。PNG 常见四通道： 红、绿、蓝与透明度。读回数组可以检查尺寸、通道与最大值，适合自动核对 保存结果。

多子图保存

plt.subplots(2, 2, figsize=(6, 4)) 建立 2×2 的坐标轴数组， 按行列索引访问。先给每个子图设置标题与数据，再调用 fig.tight_layout() 调整间距，最后保存整张画布。子图标题、 坐标标签与图例都属于画布内容，保存时会一起写入。

同一张画布可以保存多次：例如先保存紧凑版本，再保存固定边界版本， 比较两者的像素尺寸。每次 savefig 使用调用时给出的参数， 不会改动画布本身；全部保存完成后关闭画布。
