5.1图像的读取、通道与保存

OpenCV 把图像读成 NumPy 数组，彩色图是三通道 uint8，灰度图 是单通道 uint8。这一课从读图标志开始，依次看形状、像素访问、 通道拆分与合并，最后裁出一块区域并保存。读图与保存都返回布尔值或数组， 失败时不会抛出异常，需要主动检查。

读图标志

cv2.imread(path, flag) 的第二个参数决定读成什么： cv2.IMREAD_COLOR 按三通道读入，忽略透明通道，也是默认值； cv2.IMREAD_GRAYSCALE 读成单通道灰度； cv2.IMREAD_UNCHANGED 保留文件里的通道数，带透明通道的图会 读成四通道。路径写错或文件损坏时返回 None，后续访问 shape 会抛出 AttributeError，因此读入后先判断 返回值。

cv2.imread 不展开用户目录，也不搜索额外路径；相对路径按当前 工作目录解析。课程里的命令都在 lessons/python 目录执行， 素材路径写成 素材/synth_shapes.png 就能找到。换到别的目录 运行脚本时，要么先切换到课程目录，要么把路径写成绝对路径。

形状、类型与像素

彩色图的形状是 (高, 宽, 3)，灰度图是 (高, 宽)， 元素类型是 uint8，取值范围 0 到 255。访问像素写 image[y, x]：第一个下标是行号，第二个是列号，与图像坐标 (x, y) 的顺序相反。彩色像素返回长度为 3 的数组，顺序是蓝、 绿、红；灰度像素返回一个标量。

像素值可以直接修改：image[y, x] = [0, 0, 255] 把该点写成 红色。整块赋值用切片：image[0:50, 0:50] = 255 把左上角 50×50 的区域写成白色。切片得到的是视图，修改它会改动原图，这一点与 第 4 部分一致。

通道拆分与合并

cv2.split(image) 把三通道拆成三个单通道数组，顺序是 B、G、R； cv2.merge([b, g, r]) 按给定顺序合并。按原顺序合并得到与原图 逐位相同的数组；把顺序换成 [r, g, b]，蓝红两个通道互换， 图像颜色改变。拆分与合并都会复制数据，得到新数组。

也可以直接用 NumPy 切片取通道：image[:, :, 0] 是蓝色通道， image[:, :, 1] 是绿色，image[:, :, 2] 是红色。 这种写法得到视图，不复制数据；只读统计时更省内存。需要把某个通道单独 保存成灰度图时，先 copy() 或用 cv2.split， 避免把视图传给会修改数据的函数。

区域与保存

区域（region of interest，ROI）用切片取出： image[100:220, 80:260] 取第 100 到 219 行、第 80 到 259 列， 形状是 120×180×3。ROI 是视图，在原图上画框、写字会同时改到 ROI； 希望保留原图时先 copy()。

cv2.imwrite(path, image) 把数组写成图片文件，成功返回 True，失败返回 False。格式由扩展名决定， .png 无损，.jpg 有损。写出前确认数组类型是 uint8 或 uint16；浮点数组先按显示范围缩放并 转换成 uint8，数值范围不对时画面会发黑或发白。

5.2颜色空间、阈值与掩码

颜色分割的第一步是把感兴趣的颜色从背景里分离出来。OpenCV 默认使用 BGR 顺序，光照变化会同时改变三个分量；转换到 HSV 空间后，色调与亮度 分开，按色调筛选更稳定。这一课用红色圆球与棋盘图演示颜色掩码、连通区域 与两种阈值方法。

BGR 与 HSV

BGR 的三个分量分别表示蓝、绿、红的强度，适合显示与保存，不适合直接 按颜色筛选。HSV 把颜色拆成色调（Hue）、饱和度（Saturation）与明度 （Value）：色调表示颜色种类，饱和度表示颜色纯度，明度表示亮度。OpenCV 的 8 位图像把色调映射到 0 到 179，饱和度与明度映射到 0 到 255。

cv2.cvtColor(image, cv2.COLOR_BGR2HSV) 完成转换， cv2.COLOR_HSV2BGR 转回。红色在色调轴上分布在两端：0 到 10 与 170 到 179 都属于红色，因此红色掩码要用两个区间再合并，不能只取 一个区间。

inRange 与双区间

cv2.inRange(hsv, low, high) 逐像素比较三个分量，全部落在 闭区间内时写 255，否则写 0，返回单通道 uint8 掩码。上下界 用 np.array([...], np.uint8) 构造，顺序与 HSV 一致。两个区间 的掩码用按位或 | 合并。

cv2.bitwise_and(image, image, mask=mask) 只保留掩码为 255 的 像素，其余变黑。掩码本身可以保存成 PNG 检查；统计掩码像素数用 mask.sum() // 255，覆盖率用 mask.mean() / 255， 两者都利用 255 是 1 的 255 倍这一关系。

掩码统计与连通区域

cv2.connectedComponentsWithStats(mask) 找出掩码中互相连通的 白色区域，返回四个值：区域数量（包含背景）、标签图、统计矩阵与质心矩阵。 标签 0 是背景，从 1 开始是各个前景区域。统计矩阵每行五个数：外接矩形 左上角的 x、y，宽 w，高 h，以及像素面积。

质心矩阵每行两个浮点数，是区域的中心坐标。按面积排序可以找出最大的目标； 面积很小的区域通常是噪声，按阈值过滤。连通区域的数量与顺序取决于扫描 顺序，打印前先按面积或位置排序，结果才稳定。

Otsu 与自适应阈值

cv2.threshold(gray, thresh, maxval, type) 做全局阈值：灰度 大于阈值的写 maxval，其余写 0。类型写 cv2.THRESH_BINARY 得到白前景黑背景，写 cv2.THRESH_BINARY_INV 则相反。阈值固定为 0 并加上 cv2.THRESH_OTSU 时，OpenCV 自动选择使类间方差最大的阈值， 返回实际使用的阈值。

cv2.adaptiveThreshold 按每个像素周围的窗口计算局部阈值， 适合光照不均的图。窗口大小取奇数，常数 C 从局部均值或 加权均值中减去。棋盘图只有两种灰度，Otsu 的结果接近理想；自适应阈值在 边界附近会把更多像素算作白色，计数因此偏大。

例题 · 红色目标与阈值

题目：在 HSV 空间用两个红色区间生成掩码，统计红色像素与覆盖率；用连通区域打印每个红球的外接矩形与质心；用掩码取出红色像素并打印均值；保存掩码；最后在棋盘灰度图上比较 Otsu 与自适应阈值的白色像素数。

完整程序：

import cv2
import numpy as np


image = cv2.imread("素材/synth_balls.png")
hsv = cv2.cvtColor(image, cv2.COLOR_BGR2HSV)
low1 = np.array([0, 120, 80], np.uint8)
high1 = np.array([10, 255, 255], np.uint8)
low2 = np.array([170, 120, 80], np.uint8)
high2 = np.array([179, 255, 255], np.uint8)
mask = cv2.inRange(hsv, low1, high1) | cv2.inRange(hsv, low2, high2)

pixels = int(mask.sum() // 255)
print("red pixels:", pixels)
print("coverage:", round(float(mask.mean() / 255.0), 4))

count, labels, stats, centers = cv2.connectedComponentsWithStats(mask)
print("components:", count - 1)
for index in range(1, count):
    x, y, w, h, area = stats[index]
    cx, cy = centers[index]
    print("region:", int(area), (int(x), int(y), int(w), int(h)),
          (int(cx), int(cy)))

red = cv2.bitwise_and(image, image, mask=mask)
print("masked mean:", np.round(red[mask > 0].mean(axis=0), 2).tolist())
print("mask saved:", bool(cv2.imwrite("out_red_mask.png", mask)))

grid = cv2.imread("素材/synth_grid.png", cv2.IMREAD_GRAYSCALE)
value, binary = cv2.threshold(grid, 0, 255,
                              cv2.THRESH_BINARY + cv2.THRESH_OTSU)
print("otsu value:", int(value), "white:", int(binary.sum() // 255))
adaptive = cv2.adaptiveThreshold(grid, 255, cv2.ADAPTIVE_THRESH_MEAN_C,
                                 cv2.THRESH_BINARY, 11, 2)
print("adaptive white:", int(adaptive.sum() // 255))

5.3形态学、边缘与轮廓

阈值与掩码得到的二值图常有噪点、缺口与粘连。形态学运算改变白色区域的 形状，边缘检测找出灰度变化剧烈的位置，轮廓提取把连通的边界整理成点序列。 这一课从 3×3 核开始，经过 Canny，最后按面积与形状筛选轮廓并画出标注。

腐蚀、膨胀与开闭运算

腐蚀（erosion）让白色区域变瘦，膨胀（dilation）让它变胖，结构元素决定 邻域形状与大小，常用 3×3 全 1 的 uint8 数组。开运算先腐蚀 再膨胀，去掉小噪点而保留大块区域；闭运算先膨胀再腐蚀，填补小孔与窄缝。

cv2.erode、cv2.dilate 与 cv2.morphologyEx(image, cv2.MORPH_OPEN, kernel) 完成这些 运算。核越大，效果越强，细小的目标也越容易被抹掉。处理前先确认图像是 单通道二值图，彩色图要先转灰度并阈值化。

Canny 边缘

cv2.Canny(gray, low, high) 先计算图像梯度，再做非极大值 抑制与双阈值连接：高于 high 的强边缘保留，介于两者之间的 弱边缘只在连接到强边缘时保留。梯度对噪声敏感，噪声明显时先用 cv2.GaussianBlur 平滑。输出是单通道二值图，边缘为 255。

两个阈值通常按 1:2 或 1:3 取，50 与 150 适合 对比明显的合成图。阈值过低会把纹理与噪声都算成边缘，过高会断开轮廓。 调整时先固定一个，再调另一个，观察边缘数量与连续性。

轮廓、面积与周长

cv2.findContours(binary, mode, method) 在二值图中找轮廓， 返回轮廓列表与层级信息。模式 cv2.RETR_EXTERNAL 只取最外层 轮廓，适合数目标个数；cv2.RETR_TREE 保留嵌套关系。 方法 cv2.CHAIN_APPROX_SIMPLE 压缩直线段，只保留端点。

每个轮廓是 (n, 1, 2) 的整数坐标数组。cv2.contourArea 返回面积，cv2.arcLength(contour, True) 返回闭合周长。轮廓 的排列顺序由实现决定，没有固定的大小顺序；需要稳定输出时按面积或外接 矩形排序。面积小于几十像素的轮廓通常是噪声，先过滤再处理。

外接矩形与圆形度

cv2.boundingRect(contour) 返回与坐标轴平行的外接矩形 (x, y, w, h)；cv2.minAreaRect(contour) 返回 可旋转的最小外接矩形，包含中心、宽高与角度。画框用 cv2.rectangle，画轮廓用 cv2.drawContours， 线宽与颜色按 BGR 给出。

圆形度定义为 4πA/P²，A 是面积，P 是周长。圆接近 1，细长 形状接近 0。按圆形度筛选可以区分圆球与矩形。筛选条件通常组合面积、 宽高比与圆形度，单看一个指标容易把噪声算进来。

5.4视频的读取与写出

视频是一串按时间排列的图像帧。OpenCV 用 VideoCapture 逐帧 读取，用 VideoWriter 逐帧写出；处理逻辑与单张图相同，只是 外面多一层循环。这一课用课程视频演示元数据读取、逐帧处理、写出视频与 抽取关键帧。

打开视频与元数据

cv2.VideoCapture(path) 打开视频文件，参数也可以写成整数 设备号。打开后先调用 isOpened() 检查，再读取 cv2.CAP_PROP_FRAME_WIDTH、CAP_PROP_FRAME_HEIGHT 与 CAP_PROP_FPS。帧率是浮点数，尺寸是整数，写 VideoWriter 时要用这两个值。

打开失败时后续 read 一直返回 False，不会抛出 异常。路径错误、编码器不支持、文件损坏都会导致失败，先在 isOpened() 处停下并打印原因，比在循环里反复读空帧更容易 定位。

逐帧读取

cap.read() 返回两个值：是否读到帧与帧数组。读到末尾时第一 个值为 False，帧为空。while True 循环里先判断 返回值，再处理帧；循环结束后调用 cap.release() 释放文件 句柄。

帧的形状是 (高, 宽, 3)，与单张彩色图一致。逐帧处理时不要 在循环里反复创建大数组或打开文件；需要累计的统计量先算成标量或小数组， 循环结束后再汇总。

写出视频

cv2.VideoWriter(path, fourcc, fps, (width, height)) 创建写出 对象，编码用 cv2.VideoWriter_fourcc(*"mp4v")，帧率与尺寸 必须与写入的帧一致。创建后检查 isOpened()，每帧调用 write，结束后调用 release。

写出的视频不含音频，只保留图像帧。尺寸写反会导致写出失败或画面错位： VideoWriter 的参数顺序是宽、高，而 frame.shape 的顺序是高、宽、通道。需要缩小视频时先 cv2.resize，再把 新尺寸传给写出对象。

抽帧与释放

抽帧是按固定间隔保存帧，例如每 6 帧保存一张。帧号从 0 开始，用 frames % 6 == 0 判断。保存的图片可以用于检查检测结果， 也可以作为后续标定的输入。

循环结束后同时释放 VideoCapture 与 VideoWriter， 否则文件可能没有写完。统计帧数、保存数与首末帧位置，作为处理是否完整的 摘要；首末位置还能看出目标是否移出画面。

5.5摄像头与回退视频

摄像头是实时的图像源，接口与视频文件相同，只是设备号代替了路径。开发 机器不一定有摄像头，远程环境通常也没有显示窗口，因此程序要能回退到 课程视频，并把无摄像头的分支做成可直接运行的参数。这一课用 --no-camera 演示回退流程。

打开摄像头

cv2.VideoCapture(0) 打开第一个摄像头，1 表示 第二个。打开后用 cap.set 请求分辨率与帧率： cv2.CAP_PROP_FRAME_WIDTH、CAP_PROP_FRAME_HEIGHT 与 CAP_PROP_FPS。驱动不一定接受请求值，读取时应以 cap.get 返回的实际值为准。

摄像头的首次读取常比后续慢，前几帧可能偏暗或为空。需要稳定画面时先丢弃 前几帧，或等待自动曝光稳定。摄像头被其他程序占用时打开会失败，释放占用 后再试，或在程序里直接走回退分支。

读取失败与回退

回退逻辑分两层：带 --no-camera 时直接打开课程视频；不带参数 时先尝试摄像头，isOpened() 为假就释放并改开视频。用一个 source 变量记录实际来源，打印出来，后续分支据此决定是否 创建显示窗口。

回退不是隐藏错误，而是让程序在没有硬件时仍能完成处理流程。回退后仍然 检查 isOpened()，视频也打不开就打印原因并退出，避免对空帧 继续计算。

显示窗口与按键

cv2.imshow(name, frame) 创建窗口并显示一帧， cv2.waitKey(1) 等待 1 毫秒并返回按键码；按 Esc（码值 27） 时退出循环。循环结束后 cv2.destroyAllWindows() 关闭窗口。 没有显示服务的环境调用 imshow 会报错，因此摄像头分支才 创建窗口，视频回退分支不创建。

waitKey 同时驱动窗口事件循环，不调用它窗口不会刷新。参数 单位是毫秒，写 1 表示尽量快地处理下一帧；写 0 表示一直等待按键。实时 显示时不要在其他地方长时间阻塞，否则画面会卡住。

无摄像头环境

在远程机器或没有摄像头的开发机上，给运行命令加上 --no-camera 参数，程序直接打开课程视频，处理前 12 帧 并保存第一帧。统计均值前先确认 frames 大于 0，否则除数为 0；保存快照的条件同样先判断是否 读到帧。

摄像头分支的代码仍然保留，换到有摄像头的机器上不加参数就能使用。两种 来源共用同一套读取、统计与保存逻辑，差别只在打开方式与是否显示窗口， 这样回退路径与真实路径的行为一致。

5.6相机标定与去畸变

镜头会把直线弯成曲线，靠近画面边缘的位置偏差更大。标定（calibration） 用已知尺寸的棋盘格求相机的内参矩阵与畸变系数，再用它们校正图像。这一课 用三张不同姿态的棋盘图完成标定，检查重投影误差，并演示去畸变、重映射 与位姿求解。

棋盘格与世界坐标

标定板用黑白相间的棋盘格，内角点是两个黑格与两个白格交汇的位置。图案 尺寸写成 (列数, 行数)，例如 9×6 表示每行 9 个、每列 6 个 内角点，共 54 个。方格边长用毫米或米，所有点的世界坐标按这个单位构造。

世界坐标取棋盘平面为 z=0，角点按行列排成 (0, 0, 0)、(1, 0, 0) 直到 (8, 5, 0)，再乘以方格边长。三张图共用同一组世界坐标， 相机在不同位置拍摄，得到三组图像坐标。

角点检测与细化

cv2.findChessboardCorners(gray, pattern, flags=...) 返回是否 找到与角点数组。CALIB_CB_ADAPTIVE_THRESH 用自适应阈值， CALIB_CB_NORMALIZE_IMAGE 先做归一化，适合光照不均的图。 找不到完整棋盘时返回 False，不要继续细化。

cv2.cornerSubPix 在粗角点周围搜索亚像素位置，参数是搜索 窗口、死区与终止条件。窗口通常取 (11, 11)，死区 (-1, -1) 表示不设死区。细化后的角点顺序与粗检测一致， 可以直接与世界坐标一一对应。

标定与重投影误差

cv2.calibrateCamera(objects, images, image_size, None, None) 返回重投影误差、相机矩阵、畸变系数、每张图的旋转向量与平移向量。 相机矩阵是 3×3，fx 与 fy 是焦距（像素单位）， cx 与 cy 是主点。畸变系数通常取前五个。

重投影误差（root mean square，均方根，RMS）把世界坐标按求得的参数投影 回图像，与检测到的角点比较，单位是像素。数值越小越好，合成图常在 0.1 像素以下；真实相机在 0.5 像素以内通常可用。误差偏大时先检查角点顺序、 方格边长与图案尺寸。

去畸变与位姿

cv2.undistort(image, camera, dist) 一次完成去畸变，适合单张 图；cv2.initUndistortRectifyMap 生成映射表， cv2.remap 按表重映射，适合视频逐帧处理，映射表只算一次。 去畸变后画面边缘会被裁掉或拉伸，属于正常现象。

cv2.solvePnP(object_points, image_points, camera, dist) 用 已知的世界坐标与图像坐标求相机位姿，返回旋转向量与平移向量。平移向量的 第三个分量约等于标定板到相机沿光轴的距离，单位与方格边长一致。位姿求解 要求至少四个不共线的点，棋盘角点远多于这个下限。

5.7性能与内存

图像处理的时间常花在逐像素循环与不必要的复制上。同样的统计，用 NumPy 向量化可以快两到三个数量级；同样的区域，用视图可以避免复制整块数据。 这一课先讲怎样计时，再比较循环与向量化，最后看视图与副本对内存的影响。

计时方法

time.perf_counter() 返回单调递增的高精度计时值，适合测短 代码段。开始前取一次，结束后再取一次，相减得到秒数；乘 1000 换成毫秒。 单次测量受系统调度影响，重复多次取中位数或最小值更稳定。

timeit.repeat 自动重复计时，返回每次的耗时列表；取最小值 可以避开偶发的调度延迟。测量前先运行一次，让缓存与自适应优化进入稳定 状态。报告结果时写明单位、重复次数与机器环境，不同机器上的绝对数值 不能直接比较。

循环与向量化

逐像素循环在 Python 层执行，每次比较与累加都要经过解释器，几十万像素就 需要几十万次迭代。向量化写法 (array > limit).sum() 先做 一次布尔比较，再由 NumPy 在底层求和，循环交给编译好的代码，速度快得多。

两种写法必须得到相同结果，优化才有意义。先用小数组或抽样数据核对计数， 再替换实现；只比较耗时而不核对结果，容易把逻辑错误当成性能提升。图像 处理中的阈值、掩码、通道运算都可以写成向量化形式。

视图与副本

NumPy 切片返回视图，与父数组共享内存；copy() 分配新内存。 np.shares_memory(a, b) 判断两个数组是否共享数据。 视图省内存，但修改会写回父数组；副本安全，但复制大图会增加内存占用与 耗时。

ROI 视图是否连续取决于切片方式。整行切片可能仍是 C 连续，只取中间一段 列时行尾跨过父图剩余像素，视图不连续。需要把不连续数组传给要求连续 内存的函数时，先 np.ascontiguousarray 或 copy()。

优化顺序

先测量再优化：用计时找出最慢的一段，确认它占总时间的比例，再决定是否 改写。常见热点是逐像素循环、重复读取文件、在循环里反复分配大数组与不必 要的 copy。把循环换成数组运算通常收益最大，其次是减少复制 与复用映射表。

优化后重新计时并核对结果，确认速度提升不是靠跳过计算换来的。可读性也要 保留：一行向量化表达式如果难以理解，加注释说明输入形状与输出含义。性能 数字随机器变化，课程只比较两种写法的相对快慢，不把某次耗时当作固定值。

例题 · 同一统计的两种写法

题目：读取形状图并缩小到 160×120；分别用双重循环与 NumPy 布尔求和统计大于 120 的像素；用 perf_counter 重复 5 次取中位数，用 timeit.repeat 再测一次；最后比较 ROI 视图与副本是否与父图共享内存。

完整程序：

import time
import timeit

import cv2
import numpy as np


image = cv2.imread("素材/synth_shapes.png", cv2.IMREAD_GRAYSCALE)
small = cv2.resize(image, (160, 120), interpolation=cv2.INTER_NEAREST)
limit = 120


def count_loop(array):
    total = 0
    for row in array:
        for value in row:
            if value > limit:
                total += 1
    return total


def count_numpy(array):
    return int((array > limit).sum())


def median_time(function, repeats=5):
    times = []
    for _ in range(repeats):
        start = time.perf_counter()
        function(small)
        times.append(time.perf_counter() - start)
    return sorted(times)[len(times) // 2]


loop_count = count_loop(small)
numpy_count = count_numpy(small)
print("count:", loop_count)
print("same:", loop_count == numpy_count)
print("loop ms:", round(median_time(count_loop) * 1000.0, 1))
print("numpy ms:", round(median_time(count_numpy) * 1000.0, 2))
print("timeit loop ms:", round(min(timeit.repeat(
    lambda: count_loop(small), repeat=3, number=1)) * 1000.0, 1))
print("timeit numpy ms:", round(min(timeit.repeat(
    lambda: count_numpy(small), repeat=3, number=1)) * 1000.0, 2))

roi = small[20:80, 40:120]
copied = roi.copy()
print("view shares:", bool(np.shares_memory(roi, small)))
print("copy shares:", bool(np.shares_memory(copied, small)))
