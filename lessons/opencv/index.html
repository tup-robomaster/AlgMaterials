OpenCV 视觉基础

这门课讲怎样用 C++ 与 OpenCV 处理图像和视频。内容从 Mat、 颜色空间与绘制开始，经过阈值、轮廓与颜色目标检测，走到视频采集、 相机标定和卡尔曼滤波。每个例子都给出完整代码、编译命令、真实输出与结果图。

怎么读这门课

全课 11 个部分、58 课，分三档要求。第 0–1 部分是基础， 建议按顺序读完，并亲手运行、修改例子。第 2–9 部分按需阅读： 每一部分开头先列前置课，读完前置再按当前任务选读。第 10 部分是综合练习， 建议在读完第 1–5 部分以及 7.1、7.6、8.1–8.2 之后再做。

档次部分读到什么程度
基础 第 0–1 部分 按顺序读；例子必须运行，参数要能改，输出要能解释
按需 第 2–9 部分 先读该部分列出的前置课，再按任务选读；不要求从头到尾
综合 第 10 部分 独立完成一条完整流程与一组检测题

具体到每一课，用四个词标注要求。会用指能运行、能改参数、能解释输出； 掌握指能独立写出一段完整流程并定位常见错误；看懂指能读懂代码、 公式与参数，不要求独立实现；了解指知道概念、流程与适用场景。

全课有三课标为选学：2.7 图像金字塔；3.6 距离变换、分水岭与 漫水填充；8.5 扩展卡尔曼与自适应噪声。选学课可以跳过，也不进入任何 部分的前置。

每页怎么读

课里的 C++ 例子都是完整程序，代码块后紧跟真实输出，含窗口交互的例子另给结果图。 正文中的图片可以双击放大，滚轮继续缩放，按住拖动平移，按 Esc 或再次双击还原。 运行方法见 0.2，练习目录与代码输出的阅读约定见 0.1。课程假设读者已经会写基本的 C++ 程序： 变量、循环、函数、std::vector 与结构体，能用 g++ 编译一个源文件；课程不重复讲这些语法，需要时先读 C++ 基础课。

环境与链接

课程假设运行环境为 Ubuntu、OpenCV 4.x（测试机验证版本为 4.9.0）； g++ 支持 C++17，VS Code 已安装 C/C++ 插件。例子直接 使用这套环境编译运行。

编译命令、pkg-config 的检查方法与链接失败的常见原因，见 0.2 环境与链接；VS Code 中头文件红线的 处理与 IntelliSense 配置，见 0.3。

素材说明

课程例子使用的图片与视频都随课程放在本地，页面不引用外部地址。 合成素材由课程脚本生成，位置、颜色与尺寸固定，重复运行得到同一张图。

第 0、1 部分的图片是合成图 synth_balls.png：浅色渐变背景上 分布 22 个绿色圆球，由课程脚本生成。 真实素材另有苹果照片 apple.jpg 与一段视频 cube.mp4。 视频只作为普通素材使用；没有摄像头时，摄像头一课自动回退到视频文件， 不要求硬件。第 9 部分另有一段实拍观察视频 real_armor.mp4， 用于 9.6 的属性读取与抽帧对照；页面不提供这段视频的检测程序。

第 1 部分 · 图像与 Mat

基础，5 课，前置 0.2–0.5。这一部分从 OpenCV 的基本容器 Mat 开始，讲清内存、像素、视图与颜色空间，最后把结果画到图上。

  • 1.1 Mat 的内存模型 头部与数据；行、列、通道、深度、类型、步长；浅拷贝与深拷贝；连续内存
  • 1.2 读、写、显示与错误处理 三个读取标志；empty 检查；显示与保存；路径与工作目录；常见错误
  • 1.3 像素、ROI 与克隆 先行后列的坐标；at 读写；ROI 是视图；clone 后独立；ROI 边界
  • 1.4 颜色空间：BGR、灰度、HSV BGR 顺序；灰度转换；H、S、V 的范围；为什么颜色分割常用 HSV
  • 1.5 绘制、掩码与标注 掩码与形态学；line、rectangle、circle、putText；画轮廓、框、重心与编号

第 2 部分 · 图像处理

按需，7 课，前置 1.1–1.4。这一部分处理颜色检测之前最常见的图像处理 步骤：抑制噪声、分开目标与背景、清理掩码、提取边缘、判断曝光， 最后做缩放、旋转与透视校正。2.1–2.6 需要掌握，2.7 为选学。

  • 2.1 平滑与去噪 四种滤波器的分工；噪声类型与选择；加噪比较；速度、参数与副作用
  • 2.2 阈值：固定、Otsu、自适应 五种阈值类型；Otsu 与自适应阈值；五种类型与光照不均；参数与常见错误
  • 2.3 形态学：腐蚀、膨胀、开、闭 结构元、腐蚀与膨胀；开、闭与派生运算；清理噪声掩码；核大小与运算顺序
  • 2.4 边缘：Sobel、Laplacian、Canny Sobel 与梯度；Laplacian 与 Canny；四种边缘图；阈值与后续处理
  • 2.5 直方图与曝光 calcHist 与直方图；equalizeHist 与 CLAHE；低对比度增强；彩色图与归一化
  • 2.6 几何变换：缩放、旋转、透视 resize 与插值；旋转与仿射；透视变换与四点顺序；缩放、旋转与卡片矫正
  • 2.7 图像金字塔（选学） pyrDown 与 pyrUp；尺度空间与多尺度匹配；三层金字塔与两档匹配；匹配的边界

第 3 部分 · 轮廓与形状

按需，6 课，前置 1.1–1.3、2.2–2.3。这一部分从二值掩码出发： 先把目标边界提取成轮廓，再计算面积、周长、外接矩形、旋转矩形、 重心与圆形度，最后组合这些特征筛选候选并去重。3.1–3.5 需要掌握， 3.6 为选学。

  • 3.1 轮廓提取：findContours 从掩码到轮廓；检索模式与层级；绿色掩码的外轮廓与孔洞；绘制与输入错误
  • 3.2 面积、周长与外接矩形 面积、周长与有向性；外接矩形与填充率；面积与外接矩形筛选；尺寸、分辨率与阈值换算
  • 3.3 旋转矩形、外接圆与多边形逼近 minAreaRect 与 boxPoints；外接圆与 approxPolyDP；直角、边长比与判据
  • 3.4 矩、重心与形状特征 矩与重心；圆形度、填充率与凸性；绿球的重心与圆形度；哪些特征稳定
  • 3.5 轮廓筛选与去重 组合特征与阈值表；排序、IoU 与非极大值抑制；四张图上的候选与去重；调试顺序与参数维护
  • 3.6 距离变换、分水岭与漫水填充（选学） 距离变换；连通分量与分水岭；把接触的球分开；漫水填充与适用边界
