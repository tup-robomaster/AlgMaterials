9.1任务拆解与数据

装甲板检测的目标是：在一帧图像中找到两块平行的灯条，确认它们构成 一块装甲板，再读出板面的颜色与数字。传统流程把任务拆成若干可检查的 阶段，每个阶段都能单独保存中间图；出错时可以先定位到具体阶段，而不是 面对一个端到端的黑箱结果。本课先约定输入、输出与评价方式，后面的 课程逐段实现。

两阶段流程

单阶段检测直接用一张图回归目标框与类别；两阶段检测先产生候选区域， 再对候选做分类或识别。这里的“两阶段”指传统流程中的两级筛选：第一级 从图像中找灯条，第二级把灯条配成装甲板并读取板面信息。灯条是局部 特征，数量少、几何约束强；装甲板是组合特征，必须由两条灯条共同 确认。先找局部再组合，比直接搜索整块装甲板更容易控制误检。

完整数据流为：读取视频帧 → 限定车辆 ROI → 灰度或通道差 → 阈值与 形态学 → 轮廓 → 灯条筛选 → 两两配对 → 四点透视矫正 → 颜色判别 → 数字 ROI → 模板匹配 → 状态机 → 标注视频与日志。每一段都接收明确的 输入，输出可以保存为图像或表格；参数集中在结构体中，便于逐项调整。

输入、输出与评价

课程素材是 素材/synth_armor.mp4：640×480、30 帧每秒、 300 帧、共 10 秒。画面中的装甲板会平移、轻微旋转与缩放；第 130–169 帧目标 离开画面，用来观察丢失与重捕；板面颜色在红色与蓝色之间切换，数字在 1、2、3、5 之间切换。另有一根固定亮条作为干扰，它尺寸不足，不能与 装甲板灯条配对。

中间结果统一写到 素材/：首帧 out_armor_first.png，四帧拼图 out_armor_story.png，灯条候选 out_armor_bars.png，配对与矫正 out_armor_pair.png，数字识别 out_armor_digit.png，状态机视频 out_armor_state.mp4 与单帧 out_armor_state.png，实拍对比 out_armor_real.png，ROI 示意 out_armor_roi.png。命名固定，便于按阶段回看。

评价不引入复杂指标，只记录三类数字：每帧灯条候选数、每帧配对候选数、 状态日志中的确认与丢失次数。候选数突然升高，通常是阈值过低或干扰 增多；候选数长期为零，通常是阈值过高、灯条断裂或 ROI 取错。把候选 数与中间图一起看，才能判断是检测失败还是配对失败。

程序打开视频，打印宽、高、帧率、总帧数与时长，保存首帧，并抽取 第 0、40、150、240 帧拼成一张四格图。第 150 帧目标不在画面中， 其余三帧分别对应红色与蓝色板面。

void label(cv::Mat& frame, const std::string& text) {
    cv::rectangle(frame, cv::Rect(0, 0, frame.cols, 34),
                  cv::Scalar(20, 20, 20), cv::FILLED);
    cv::putText(frame, text, cv::Point(10, 24), cv::FONT_HERSHEY_SIMPLEX,
                0.65, cv::Scalar(245, 245, 245), 1, cv::LINE_AA);

}  // namespace

int main() {
    const std::string path = "../素材/synth_armor.mp4";
    cv::VideoCapture cap(path);
    if (!cap.isOpened()) {
        std::cout << "无法打开 " << path << '\n';
        return 1;
    }

    const int width = cvRound(cap.get(cv::CAP_PROP_FRAME_WIDTH));
    const int height = cvRound(cap.get(cv::CAP_PROP_FRAME_HEIGHT));
    const double fps = cap.get(cv::CAP_PROP_FPS);
    const int frames = cvRound(cap.get(cv::CAP_PROP_FRAME_COUNT));

    cap.set(cv::CAP_PROP_POS_FRAMES, 0);

        cv::hconcat(std::vector<cv::Mat>{tiles[2], tiles[3]}, bottom);
        cv::vconcat(top, bottom, storyboard);

    const bool story_saved = !storyboard.empty() &&
                             cv::imwrite("../素材/out_armor_story.png",
                                        storyboard);

    std::cout << std::fixed << std::setprecision(3);
    std::cout << "width = " << width << " height = " << height << '\n';
    std::cout << "fps = " << fps << " frames = " << frames << '\n';
    std::cout << "duration_s = " << frames / fps << '\n';
    std::cout << "first_saved = " << (first_saved ? "yes" : "no") << '\n';
    std::cout << "story_frames = " << tiles.size() << '\n';
    std::cout << "story_saved = " << (story_saved ? "yes" : "no");
    if (!storyboard.empty()) {
        std::cout << " " << storyboard.cols << "x" << storyboard.rows;
    }
    std::cout << '\n';
    return 0;
}

9.2预处理与灯条提取

灯条是装甲板上最稳定的亮结构。它们在图像中表现为细长的亮矩形，宽度 小、高度大、填充率高，倾斜角接近竖直。预处理的目标是把这些结构从 背景、车身与反光中分离出来，再用几何条件筛掉不符合灯条形状的轮廓。 本课在合成视频的一帧上完成这条链路，并保存每一步的中间结果。

灰度、阈值与形态学

合成灯条接近白色，灰度值在 230 以上，背景与车身低于 100，因此先用灰度阈值 190 就能分开。真实 场景中，灯条可能偏蓝或偏红，背景可能有同色高光；常用做法是先算通道 差，例如蓝色通道减红色通道，再做阈值。通道差能压低暖色背景，保留 冷色灯条。本课保留灰度版本，是因为合成数据的颜色关系简单，后续的 轮廓与配对步骤不受影响；换到真实数据时，只需替换这一段的掩码来源。

阈值后做一次 3×3 开运算，去掉孤立亮斑与毛刺；再做一次 闭运算，把灯条内部因压缩产生的小孔连起来。核不宜过大：核增大能连接 断裂，也会把相邻灯条或灯条与反光粘在一起，后续轮廓数量反而下降。 形态学后的掩码应保存，参数变化时先看掩码，不要只看最终候选。

灯条筛选

程序对每个外部轮廓计算面积、外接矩形、填充率与主轴角。面积范围取 500–10000，排除固定亮条与数字笔画；宽高比取 2.5–12，排除接近方形的色块；填充率取 0.45 以上，排除弯曲或破碎的亮边；主轴与竖直方向的偏差 不超过 30°，排除横条与斜放的装饰。

主轴方向用主成分分析求：把轮廓点排成矩阵，取第一主成分作为长轴方向， 再把它归一到 [-90°, 90°]。与 minAreaRect 相比，主成分对轮廓上的毛刺更稳定；minAreaRect 仍用来 画旋转矩形框，二者用途不同。轮廓按中心 x 排序，后面的 配对可以直接把左边的灯条放在前面。

例题 · 一帧灯条

程序读取第 40 帧，转灰度、阈值、开闭运算，提取外部轮廓，按面积、 宽高比、填充率与倾角筛选灯条，打印候选表，并把候选框与阈值掩码 并排保存。固定亮条面积不足 500，不会进入候选。

完整程序：

#include <algorithm>
#include <cmath>
#include <iomanip>
#include <iostream>
#include <vector>

#include <opencv2/core.hpp>
#include <opencv2/imgcodecs.hpp>
#include <opencv2/imgproc.hpp>
#include <opencv2/videoio.hpp>

namespace {

struct Bar {
    int cx = 0;
    int cy = 0;
    double area = 0.0;
    double width = 0.0;
    double height = 0.0;
    double fill = 0.0;
    double angle = 0.0;
    cv::RotatedRect rect;
};

double axisAngle(const std::vector<cv::Point>& contour) {
    cv::Mat samples(static_cast<int>(contour.size()), 2, CV_64F);
    for (int i = 0; i < samples.rows; ++i) {
        samples.at<double>(i, 0) = contour[i].x;
        samples.at<double>(i, 1) = contour[i].y;
    }
    cv::PCA pca(samples, cv::Mat(), cv::PCA::DATA_AS_ROW);
    const double ax = pca.eigenvectors.at<double>(0, 0);
    const double ay = pca.eigenvectors.at<double>(0, 1);
    double angle = std::atan2(ay, ax) * 180.0 / CV_PI;
    if (angle > 90.0) {
        angle -= 180.0;
    }
    if (angle <= -90.0) {
        angle += 180.0;
    }
    return angle;
}

cv::Mat buildMask(const cv::Mat& gray) {
    cv::Mat mask;
    cv::threshold(gray, mask, 190, 255, cv::THRESH_BINARY);
    const cv::Mat kernel = cv::getStructuringElement(cv::MORPH_RECT,
                                                     cv::Size(3, 3));
    cv::morphologyEx(mask, mask, cv::MORPH_OPEN, kernel);
    cv::morphologyEx(mask, mask, cv::MORPH_CLOSE, kernel);
    return mask;
}

std::vector<Bar> findBars(const cv::Mat& mask) {
    std::vector<std::vector<cv::Point>> contours;
    cv::findContours(mask.clone(), contours, cv::RETR_EXTERNAL,
                     cv::CHAIN_APPROX_SIMPLE);
    std::vector<Bar> bars;
    for (const auto& contour : contours) {
        const double area = cv::contourArea(contour);
        if (area < 500.0 || area > 10000.0) {
            continue;
        }
        const cv::Rect box = cv::boundingRect(contour);
        if (box.width == 0 || box.height == 0) {
            continue;
        }
        const double aspect = static_cast<double>(box.height) / box.width;
        const double fill = area / (box.width * box.height);
        const double angle = axisAngle(contour);
        if (aspect < 2.5 || aspect > 12.0 || fill < 0.45 ||
            std::fabs(std::fabs(angle) - 90.0) > 30.0) {
            continue;
        }
        Bar bar;
        bar.cx = cvRound(box.x + box.width / 2.0);
        bar.cy = cvRound(box.y + box.height / 2.0);
        bar.area = area;
        bar.width = box.width;
        bar.height = box.height;
        bar.fill = fill;
        bar.angle = angle;
        bar.rect = cv::minAreaRect(contour);
        bars.push_back(bar);
    }
    std::sort(bars.begin(), bars.end(),
              [](const Bar& a, const Bar& b) { return a.cx < b.cx; });
    return bars;
}

}  // namespace

int main() {
    cv::VideoCapture cap("../素材/synth_armor.mp4");
    if (!cap.isOpened()) {
        std::cout << "无法打开 synth_armor.mp4\n";
        return 1;
    }
    const int frame_index = 40;
    cap.set(cv::CAP_PROP_POS_FRAMES, frame_index);
    cv::Mat frame;
    cap >> frame;
    if (frame.empty()) {
        std::cout << "无法读取第 " << frame_index << " 帧\n";
        return 1;
    }

    cv::Mat gray;
    cv::cvtColor(frame, gray, cv::COLOR_BGR2GRAY);
    const cv::Mat mask = buildMask(gray);
    const std::vector<Bar> bars = findBars(mask);

    cv::Mat annotated = frame.clone();
    std::cout << std::fixed << std::setprecision(3);
    std::cout << "frame = " << frame_index << '\n';
    std::cout << "bars = " << bars.size() << '\n';
    std::cout << " idx     cx     cy     area   width  height   fill  angle\n";
    for (std::size_t i = 0; i < bars.size(); ++i) {
        const Bar& bar = bars[i];
        cv::Point2f corners[4];
        bar.rect.points(corners);
        for (int k = 0; k < 4; ++k) {
            cv::line(annotated, cv::Point(cvRound(corners[k].x),
                                          cvRound(corners[k].y)),
                     cv::Point(cvRound(corners[(k + 1) % 4].x),
                               cvRound(corners[(k + 1) % 4].y)),
                     cv::Scalar(40, 220, 40), 2, cv::LINE_AA);
        }
        cv::putText(annotated, std::to_string(i),
                    cv::Point(bar.cx + 8, bar.cy - 8),
                    cv::FONT_HERSHEY_SIMPLEX, 0.6, cv::Scalar(40, 220, 40),
                    2, cv::LINE_AA);
        std::cout << std::setw(4) << i << std::setw(7) << bar.cx
                  << std::setw(7) << bar.cy << std::setw(9) << bar.area
                  << std::setw(8) << bar.width << std::setw(8) << bar.height
                  << std::setw(7) << bar.fill << std::setw(7) << bar.angle
                  << '\n';
    }

    cv::Mat mask_bgr;
    cv::cvtColor(mask, mask_bgr, cv::COLOR_GRAY2BGR);
    cv::Mat panel;
    cv::hconcat(annotated, mask_bgr, panel);
    cv::putText(panel, "light bar candidates", cv::Point(16, 32),
                cv::FONT_HERSHEY_SIMPLEX, 0.75, cv::Scalar(40, 220, 40), 2,
                cv::LINE_AA);
    cv::putText(panel, "threshold mask", cv::Point(656, 32),
                cv::FONT_HERSHEY_SIMPLEX, 0.75, cv::Scalar(40, 220, 40), 2,
                cv::LINE_AA);
    const bool saved = cv::imwrite("../素材/out_armor_bars.png", panel);
    std::cout << "saved out_armor_bars.png " << panel.cols << "x" << panel.rows
              << ": " << (saved ? "yes" : "no") << '\n';
    return 0;
}

double axisAngle(const std::vector<cv::Point>& contour) {
    cv::Mat samples(static_cast<int>(contour.size()), 2, CV_64F);
    for (int i = 0; i < samples.rows; ++i) {
        samples.at<double>(i, 0) = contour[i].x;

    const double ax = pca.eigenvectors.at<double>(0, 0);
    const double ay = pca.eigenvectors.at<double>(0, 1);
    double angle = std::atan2(ay, ax) * 180.0 / CV_PI;
    if (angle > 90.0) {
        angle -= 180.0;
    }
    if (angle <= -90.0) {
        angle += 180.0;
    }
    return angle;
}

常见错误

高光导致灯条断裂。灯条表面过曝时，中心可能饱和成一片白，边缘 反而变暗，阈值后断成两段。断开的两段各自面积变小、宽高比改变，可能 全部被筛掉。先看掩码是否连续，再决定是否增大闭运算核或降低阈值。

运动模糊。目标快速移动时，灯条在曝光期间被拉长，宽度增大、 峰值亮度下降。固定阈值会把边缘切掉，宽高比也随之变化。可以用更低的 阈值保留边缘，或按帧间位移自适应调整；不要只调宽高比下限。

阈值随光照漂移。同一组阈值在暗场有效，到了强光下可能把背景 一起选入。固定阈值适合光照稳定的场景；光照变化明显时，应改用通道差、 局部阈值或按帧统计亮度后归一化。

宽高比范围过窄。灯条倾斜后，外接矩形的宽高比会变化；透视也会 让左右灯条的长度不同。范围过窄会把倾斜的正常灯条筛掉，表现为目标 一转就丢失。范围应覆盖实际姿态变化，再用配对约束进一步筛选。

9.3配对、透视矫正与颜色

单根灯条不足以确认装甲板。两块灯条必须平行、长度接近、中心高度接近， 间距落在合理范围内，才可能属于同一块板。配对后，用四条内边缘点做 透视变换，把倾斜的板面拉正，再在板面中心区域判断颜色。本课在一帧上 完成配对、矫正与颜色判别，并给出可排序的候选分数。

配对约束与评分

程序对任意两根灯条计算以下量：主轴夹角、中心差在长轴方向的投影 dy、中心差在法线方向的投影 dx、长度比。 夹角不超过 8°；dx 要在灯条全长的 0.8–2.5 倍之间；|dy| 不超过全长的 0.25 倍；较短灯条与较长灯条的长度比不低于 0.8。这些条件把“同一块板的两根灯条”和“画面中偶然平行 的两根亮条”区分开。

满足条件的配对计算分数： score = 夹角误差/8 + 中心误差/0.25 + (1-长度比)/0.2。 三项都做了归一化，分数越低越好；夹角误差单位是度，中心误差是 |dy| 除以全长。分数用于排序，不替代硬性条件：先筛掉 不满足约束的配对，再在剩下的候选里选分数最低的一对。

同一根灯条可能同时满足多个配对。程序目前只保留所有合法配对并排序， 在 9.5 的整段处理中只取分数最低的一对；若画面里有多块装甲板，需要 在配对阶段加入“一根灯条只能使用一次”的标记，再按分数依次占用。 否则同一根灯条会出现在多个候选框里，统计数量被高估。

矫正与颜色判别

取左灯条的右边缘上、下两点，右灯条的左边缘上、下两点，按左上、右上、 右下、左下顺序送入 getPerspectiveTransform，目标尺寸 140×80。四点顺序必须与目标顺序一致；顺序错了会得到 镜像或扭曲的板面，数字也被拉坏。矫正后的板面把灯条内边缘对齐到 矩形左右边，板面中心落在图像中央。

颜色在矫正后的中心区域统计。程序取 (20,15) 起、100×50 的矩形，转 HSV，只统计 饱和度 S≥100、亮度 V≥60 的像素；红色取 H<10 或 H>170，蓝色取 100<H<130，哪一类像素多就判为哪一类。白色数字的 饱和度低，不参与投票；装甲板边框与灯条也不在中心区域内。

struct Bar {
    cv::Point2f center;
    cv::Point2f axis;
    cv::Point2f normal;
    float half_len = 0.0f;
    float half_wid = 0.0f;
    double area = 0.0;
    double angle = 0.0;
};

struct Pair {
    int left = -1;
    int right = -1;
    double score = 0.0;
    double angle_error = 0.0;
    double center_error = 0.0;
    double length_ratio = 1.0;
    cv::Point2f corners[4];
    cv::Mat plate;
    std::string color;
    int red_pixels = 0;
    int blue_pixels = 0;
};

float dot(const cv::Point2f& a, const cv::Point2f& b) {
    return a.x * b.x + a.y * b.y;
}

cv::Point2f normalize(const cv::Point2f& v) {
    const float n = std::sqrt(v.x * v.x + v.y * v.y);
    if (n < 1e-6f) {
        return cv::Point2f(0.0f, 1.0f);
    }
    return cv::Point2f(v.x / n, v.y / n);
}

Bar makeBar(const std::vector<cv::Point>& contour) {
    cv::Mat samples(static_cast<int>(contour.size()), 2, CV_64F);
    for (int i = 0; i < samples.rows; ++i) {
        samples.at<double>(i, 0) = contour[i].x;
        samples.at<double>(i, 1) = contour[i].y;
    }
    cv::PCA pca(samples, cv::Mat(), cv::PCA::DATA_AS_ROW);
    Bar bar;
    bar.center = cv::Point2f(
        static_cast<float>(pca.mean.at<double>(0, 0)),
        static_cast<float>(pca.mean.at<double>(0, 1)));
    bar.axis = normalize(cv::Point2f(
        static_cast<float>(pca.eigenvectors.at<double>(0, 0)),
        static_cast<float>(pca.eigenvectors.at<double>(0, 1))));
    if (bar.axis.y < 0.0f) {
        bar.axis.x = -bar.axis.x;
        bar.axis.y = -bar.axis.y;
    }
    bar.normal = cv::Point2f(bar.axis.y, -bar.axis.x);
    float min_a = 1e9f;
    float max_a = -1e9f;
    float min_n = 1e9f;
    float max_n = -1e9f;
    for (const auto& p : contour) {
        const cv::Point2f q = cv::Point2f(p) - bar.center;
        const float a = dot(q, bar.axis);
        const float n = dot(q, bar.normal);
        min_a = std::min(min_a, a);
        max_a = std::max(max_a, a);
        min_n = std::min(min_n, n);
        max_n = std::max(max_n, n);
    }
    bar.half_len = 0.5f * (max_a - min_a);
    bar.half_wid = 0.5f * (max_n - min_n);
    bar.area = cv::contourArea(contour);
    bar.angle = std::atan2(bar.axis.y, bar.axis.x) * 180.0 / CV_PI;
    return bar;
}

std::vector<Bar> findBars(const cv::Mat& gray) {
    cv::Mat mask;
    cv::threshold(gray, mask, 190, 255, cv::THRESH_BINARY);
    const cv::Mat kernel = cv::getStructuringElement(cv::MORPH_RECT,
                                                     cv::Size(3, 3));
    cv::morphologyEx(mask, mask, cv::MORPH_OPEN, kernel);
    cv::morphologyEx(mask, mask, cv::MORPH_CLOSE, kernel);

    std::vector<std::vector<cv::Point>> contours;
    cv::findContours(mask.clone(), contours, cv::RETR_EXTERNAL,
                     cv::CHAIN_APPROX_SIMPLE);
    std::vector<Bar> bars;
    for (const auto& contour : contours) {
        const double area = cv::contourArea(contour);
        if (area < 500.0 || area > 10000.0) {
            continue;
        }
        const Bar bar = makeBar(contour);
        if (bar.half_wid < 1.0f) {
            continue;
        }
        const double aspect = bar.half_len / bar.half_wid;
        const double fill = area / (4.0 * bar.half_len * bar.half_wid);
        if (aspect < 2.5 || aspect > 12.0 || fill < 0.45 ||
            std::fabs(std::fabs(bar.angle) - 90.0) > 30.0) {
            continue;
        }
        bars.push_back(bar);
    }
    std::sort(bars.begin(), bars.end(), [](const Bar& a, const Bar& b) {
        return a.center.x < b.center.x;
    });
    return bars;
}

void classifyColor(Pair& pair) {
    cv::Mat hsv;
    cv::cvtColor(pair.plate, hsv, cv::COLOR_BGR2HSV);
    const cv::Rect roi(20, 15, 100, 50);
    for (int y = roi.y; y < roi.y + roi.height; ++y) {
        const cv::Vec3b* row = hsv.ptr<cv::Vec3b>(y);
        for (int x = roi.x; x < roi.x + roi.width; ++x) {
            const int h = row[x][0];
            const int s = row[x][1];
            const int v = row[x][2];
            if (s < 100 || v < 60) {
                continue;
            }
            if (h < 10 || h > 170) {
                ++pair.red_pixels;
            } else if (h > 100 && h < 130) {
                ++pair.blue_pixels;
            }
        }
    }
    pair.color = pair.red_pixels >= pair.blue_pixels ? "red" : "blue";
}

bool buildPair(const std::vector<Bar>& bars, int i, int j, Pair& pair) {
    const Bar& a = bars[i];
    const Bar& b = bars[j];
    const float dir = dot(a.axis, b.axis);
    if (dir < 0.0f) {
        return false;
    }
    const double angle_error = std::acos(std::min(1.0f, std::max(-1.0f, dir))) *
                               180.0 / CV_PI;
    if (angle_error > 8.0) {
        return false;
    }
    const cv::Point2f axis = normalize(a.axis + b.axis);
    const cv::Point2f normal(axis.y, -axis.x);
    const float dx = dot(b.center - a.center, normal);
    const float dy = dot(b.center - a.center, axis);
    const float mean_len = 0.5f * (a.half_len + b.half_len);
    const float full_len = 2.0f * mean_len;
    if (dx <= 0.0f || dx < 0.8f * full_len || dx > 2.5f * full_len) {
        return false;
    }
    if (std::fabs(dy) > 0.25f * full_len) {
        return false;
    }
    const double length_ratio = std::min(a.half_len, b.half_len) /
                                std::max(a.half_len, b.half_len);
    if (length_ratio < 0.8) {
        return false;
    }

    pair.left = i;
    pair.right = j;
    pair.angle_error = angle_error;
    pair.center_error = std::fabs(dy) / full_len;
    pair.length_ratio = length_ratio;
    pair.score = angle_error / 8.0 + pair.center_error / 0.25 +
                 (1.0 - length_ratio) / 0.2;

    pair.corners[0] = a.center - axis * a.half_len + normal * a.half_wid;
    pair.corners[1] = b.center - axis * b.half_len - normal * b.half_wid;
    pair.corners[2] = b.center + axis * b.half_len - normal * b.half_wid;
    pair.corners[3] = a.center + axis * a.half_len + normal * a.half_wid;
    return true;
}

cv::Mat warpPair(const cv::Mat& frame, const Pair& pair) {
    const cv::Point2f dst[4] = {
        cv::Point2f(0.0f, 0.0f), cv::Point2f(139.0f, 0.0f),
        cv::Point2f(139.0f, 79.0f), cv::Point2f(0.0f, 79.0f)};
    const cv::Mat transform = cv::getPerspectiveTransform(pair.corners, dst);
    cv::Mat plate;
    cv::warpPerspective(frame, plate, transform, cv::Size(140, 80),
                        cv::INTER_LINEAR);
    return plate;
}

#include <iomanip>
#include <iostream>

namespace {

struct Candidate {
    char name;
    double angle_error;
    double center_error;
    double length_ratio;
};

bool accepted(const Candidate& c) {
    return c.angle_error <= 8.0 && c.center_error <= 0.25 &&
           c.length_ratio >= 0.8;
}

double score(const Candidate& c) {
    return c.angle_error / 8.0 + c.center_error / 0.25 +
           (1.0 - c.length_ratio) / 0.2;
}

}  // namespace

常见错误

同一灯条重复配对。只排序不占用，会让一根灯条出现在多个候选 中，候选数虚高。整段处理时应维护已使用标记，或按分数从低到高贪心 选择并跳过已占用的灯条。

透视后宽高比失真。目标矩形的宽高比与实际板面差得太多，数字 会被横向或纵向拉伸，模板匹配分数下降。目标尺寸应按实际板面比例设置， 并保持四点顺序一致；不要为了“看起来大”随意改尺寸。

颜色阈值受曝光影响。曝光升高时红色可能偏黄，色相靠近 10 的边界；蓝色可能偏青，落到 100 以下。 固定色相区间适合光照稳定的场景，变化明显时应按帧统计或改用归一化 色差。

中心区域取偏。矫正后的板面如果仍有几度倾斜，固定的中心矩形 可能包含灯条边缘或边框，颜色投票被污染。先检查矫正图，再调整中心 矩形的位置与大小；不要只看颜色输出。

9.4数字区域与模板匹配

板面颜色确认后，下一步是读数字。数字位于板面中心，颜色接近白色， 与红、蓝底色区分明显。传统做法是提取数字的二值掩码，归一化到固定 尺寸，再与一组模板逐一比对，取分数最高的类别。模板匹配不需要训练； 本课使用 1–5 五个模板，说明模板匹配的调用、分数与失败条件。

数字 ROI

程序直接在矫正后的 140×80 板面上取中心区域 (22,12) 起、96×56 的矩形，避开左右灯条 与外侧边框。转 HSV 后，用 S≤85、V≥170 选白色像素；红色与蓝色底色的饱和度都高于 85，不会进入掩码。对掩码 取最大外部轮廓，得到数字的包围盒；包围盒过小则视为没有数字。

数字笔画可能因透视与压缩出现缺口，但最大轮廓仍覆盖主要笔画。程序把 包围盒内的掩码缩放到 40×56，再放到 72×88 黑底画布中央。缩放会改变笔画粗细比例，因此模板 也必须走同一条归一化路径，不能用原始字体图像直接比较。

模板与分数

模板由 cv::putText 生成：在 90×120 画布上 用 Hershey 字体写数字，阈值二值化，取包围盒，缩放到 40×56，居中到同样大小的画布。五个模板分别对应 1–5。 对每个模板调用 cv::matchTemplate(glyph, templ, result, cv::TM_CCOEFF_NORMED)； 两者尺寸相同，结果只有一个数，即归一化相关系数，范围约 [-1,1]，越接近 1 越相似。

分数不能只看绝对值。合成数据中数字 3 的分数为 0.8724， 第二位数字 5 为 0.7193，差距 0.1531；绝对值 不到 0.9，是因为模板字体与目标字体的笔画粗细、边缘抗锯齿不同。实际 使用时可以同时设绝对下限与相对差距：最高分低于下限，或与第二名的 差距太小，都输出“不确定”，交给后续帧或人工检查。

namespace {

struct Bar {
    cv::Point2f center;
    cv::Point2f axis;
    cv::Point2f normal;
    float half_len = 0.0f;
    float half_wid = 0.0f;
    double area = 0.0;
    double angle = 0.0;
};

struct Pair {
    int left = -1;
    int right = -1;
    double score = 0.0;
    double angle_error = 0.0;
    double center_error = 0.0;
    double length_ratio = 1.0;
    cv::Point2f corners[4];
    cv::Mat plate;
    std::string color;
    int red_pixels = 0;
    int blue_pixels = 0;
};

float dot(const cv::Point2f& a, const cv::Point2f& b) {
    return a.x * b.x + a.y * b.y;
}

cv::Point2f normalize(const cv::Point2f& v) {
    const float n = std::sqrt(v.x * v.x + v.y * v.y);
    if (n < 1e-6f) {
        return cv::Point2f(0.0f, 1.0f);
    }
    return cv::Point2f(v.x / n, v.y / n);
}

Bar makeBar(const std::vector<cv::Point>& contour) {
    cv::Mat samples(static_cast<int>(contour.size()), 2, CV_64F);
    for (int i = 0; i < samples.rows; ++i) {
        samples.at<double>(i, 0) = contour[i].x;
        samples.at<double>(i, 1) = contour[i].y;
    }
    cv::PCA pca(samples, cv::Mat(), cv::PCA::DATA_AS_ROW);
    Bar bar;
    bar.center = cv::Point2f(
        static_cast<float>(pca.mean.at<double>(0, 0)),
        static_cast<float>(pca.mean.at<double>(0, 1)));
    bar.axis = normalize(cv::Point2f(
        static_cast<float>(pca.eigenvectors.at<double>(0, 0)),
        static_cast<float>(pca.eigenvectors.at<double>(0, 1))));
    if (bar.axis.y < 0.0f) {
        bar.axis.x = -bar.axis.x;
        bar.axis.y = -bar.axis.y;
    }
    bar.normal = cv::Point2f(bar.axis.y, -bar.axis.x);
    float min_a = 1e9f;
    float max_a = -1e9f;
    float min_n = 1e9f;
    float max_n = -1e9f;
    for (const auto& p : contour) {
        const cv::Point2f q = cv::Point2f(p) - bar.center;
        const float a = dot(q, bar.axis);
        const float n = dot(q, bar.normal);
        min_a = std::min(min_a, a);
        max_a = std::max(max_a, a);
        min_n = std::min(min_n, n);
        max_n = std::max(max_n, n);
    }
    bar.half_len = 0.5f * (max_a - min_a);
    bar.half_wid = 0.5f * (max_n - min_n);
    bar.area = cv::contourArea(contour);
    bar.angle = std::atan2(bar.axis.y, bar.axis.x) * 180.0 / CV_PI;
    return bar;
}

std::vector<Bar> findBars(const cv::Mat& gray) {
    cv::Mat mask;
    cv::threshold(gray, mask, 190, 255, cv::THRESH_BINARY);
    const cv::Mat kernel = cv::getStructuringElement(cv::MORPH_RECT,
                                                     cv::Size(3, 3));
    cv::morphologyEx(mask, mask, cv::MORPH_OPEN, kernel);
    cv::morphologyEx(mask, mask, cv::MORPH_CLOSE, kernel);

    std::vector<std::vector<cv::Point>> contours;
    cv::findContours(mask.clone(), contours, cv::RETR_EXTERNAL,
                     cv::CHAIN_APPROX_SIMPLE);
    std::vector<Bar> bars;
    for (const auto& contour : contours) {
        const double area = cv::contourArea(contour);
        if (area < 500.0 || area > 10000.0) {
            continue;
        }
        const Bar bar = makeBar(contour);
        if (bar.half_wid < 1.0f) {
            continue;
        }
        const double aspect = bar.half_len / bar.half_wid;
        const double fill = area / (4.0 * bar.half_len * bar.half_wid);
        if (aspect < 2.5 || aspect > 12.0 || fill < 0.45 ||
            std::fabs(std::fabs(bar.angle) - 90.0) > 30.0) {
            continue;
        }
        bars.push_back(bar);
    }
    std::sort(bars.begin(), bars.end(), [](const Bar& a, const Bar& b) {
        return a.center.x < b.center.x;
    });
    return bars;
}

void classifyColor(Pair& pair) {
    cv::Mat hsv;
    cv::cvtColor(pair.plate, hsv, cv::COLOR_BGR2HSV);
    const cv::Rect roi(20, 15, 100, 50);
    for (int y = roi.y; y < roi.y + roi.height; ++y) {
        const cv::Vec3b* row = hsv.ptr<cv::Vec3b>(y);
        for (int x = roi.x; x < roi.x + roi.width; ++x) {
            const int h = row[x][0];
            const int s = row[x][1];
            const int v = row[x][2];
            if (s < 100 || v < 60) {
                continue;
            }
            if (h < 10 || h > 170) {
                ++pair.red_pixels;
            } else if (h > 100 && h < 130) {
                ++pair.blue_pixels;
            }
        }
    }
    pair.color = pair.red_pixels >= pair.blue_pixels ? "red" : "blue";
}

bool buildPair(const std::vector<Bar>& bars, int i, int j, Pair& pair) {
    const Bar& a = bars[i];
    const Bar& b = bars[j];
    const float dir = dot(a.axis, b.axis);
    if (dir < 0.0f) {
        return false;
    }
    const double angle_error = std::acos(std::min(1.0f, std::max(-1.0f, dir))) *
                               180.0 / CV_PI;
    if (angle_error > 8.0) {
        return false;
    }
    const cv::Point2f axis = normalize(a.axis + b.axis);
    const cv::Point2f normal(axis.y, -axis.x);
    const float dx = dot(b.center - a.center, normal);
    const float dy = dot(b.center - a.center, axis);
    const float mean_len = 0.5f * (a.half_len + b.half_len);
    const float full_len = 2.0f * mean_len;
    if (dx <= 0.0f || dx < 0.8f * full_len || dx > 2.5f * full_len) {
        return false;
    }
    if (std::fabs(dy) > 0.25f * full_len) {
        return false;
    }
    const double length_ratio = std::min(a.half_len, b.half_len) /
                                std::max(a.half_len, b.half_len);
    if (length_ratio < 0.8) {
        return false;
    }

    pair.left = i;
    pair.right = j;
    pair.angle_error = angle_error;
    pair.center_error = std::fabs(dy) / full_len;
    pair.length_ratio = length_ratio;
    pair.score = angle_error / 8.0 + pair.center_error / 0.25 +
                 (1.0 - length_ratio) / 0.2;

    pair.corners[0] = a.center - axis * a.half_len + normal * a.half_wid;
    pair.corners[1] = b.center - axis * b.half_len - normal * b.half_wid;
    pair.corners[2] = b.center + axis * b.half_len - normal * b.half_wid;
    pair.corners[3] = a.center + axis * a.half_len + normal * a.half_wid;
    return true;
}

cv::Mat warpPair(const cv::Mat& frame, const Pair& pair) {
    const cv::Point2f dst[4] = {
        cv::Point2f(0.0f, 0.0f), cv::Point2f(139.0f, 0.0f),
        cv::Point2f(139.0f, 79.0f), cv::Point2f(0.0f, 79.0f)};
    const cv::Mat transform = cv::getPerspectiveTransform(pair.corners, dst);
    cv::Mat plate;
    cv::warpPerspective(frame, plate, transform, cv::Size(140, 80),
                        cv::INTER_LINEAR);
    return plate;
}


cv::Mat glyphTemplate(char digit) {
    cv::Mat canvas(120, 90, CV_8UC1, cv::Scalar(0));
    const std::string text(1, digit);
    cv::putText(canvas, text, cv::Point(12, 92), cv::FONT_HERSHEY_SIMPLEX,
                2.0, cv::Scalar(255), 5, cv::LINE_AA);
    cv::Mat binary;
    cv::threshold(canvas, binary, 128, 255, cv::THRESH_BINARY);
    std::vector<std::vector<cv::Point>> contours;
    cv::findContours(binary.clone(), contours, cv::RETR_EXTERNAL,
                     cv::CHAIN_APPROX_SIMPLE);
    if (contours.empty()) {
        return cv::Mat();
    }
    const cv::Rect box = cv::boundingRect(contours.front());
    cv::Mat glyph = binary(box).clone();
    cv::Mat normalized;
    cv::resize(glyph, normalized, cv::Size(40, 56), 0.0, 0.0,
               cv::INTER_NEAREST);
    cv::Mat centered(88, 72, CV_8UC1, cv::Scalar(0));
    normalized.copyTo(centered(cv::Rect(16, 16, 40, 56)));
    return centered;
}

cv::Mat extractDigit(const cv::Mat& plate, cv::Mat& mask_out) {
    cv::Mat hsv;
    cv::cvtColor(plate, hsv, cv::COLOR_BGR2HSV);
    cv::Mat mask;
    cv::inRange(hsv, cv::Scalar(0, 0, 170), cv::Scalar(180, 85, 255), mask);
    const cv::Rect center_roi(22, 12, 96, 56);
    cv::Mat center = mask(center_roi).clone();
    std::vector<std::vector<cv::Point>> contours;
    cv::findContours(center.clone(), contours, cv::RETR_EXTERNAL,
                     cv::CHAIN_APPROX_SIMPLE);
    if (contours.empty()) {
        mask_out = center;
        return cv::Mat();
    }
    std::size_t best = 0;
    double best_area = 0.0;
    for (std::size_t i = 0; i < contours.size(); ++i) {
        const double area = cv::contourArea(contours[i]);
        if (area > best_area) {
            best_area = area;
            best = i;
        }
    }
    const cv::Rect box = cv::boundingRect(contours[best]);
    if (box.width < 4 || box.height < 10) {
        mask_out = center;
        return cv::Mat();
    }
    cv::Mat glyph = center(box).clone();
    cv::Mat normalized;
    cv::resize(glyph, normalized, cv::Size(40, 56), 0.0, 0.0,
               cv::INTER_NEAREST);
    cv::Mat centered(88, 72, CV_8UC1, cv::Scalar(0));
    normalized.copyTo(centered(cv::Rect(16, 16, 40, 56)));
    mask_out = center;
    return centered;
}

常见错误

模板与目标尺寸不一致。matchTemplate 只在固定 尺度上逐像素滑动，不会因为模板比目标大或小就自动适应；尺寸不一致 时，最高分位置偏移，分数也不可比。尺度变化时先缩放图像或建立 金字塔，模板与目标再经过同一条归一化流程，缩放到同一画布尺寸。

二值化阈值过严。V 下限太高会切掉数字边缘，笔画 变细；S 上限太低会把偏色的数字排除。先看掩码是否保留 完整笔画，再调阈值；不要只根据最终类别调参数。

把颜色当成数字特征。红色与蓝色板面上的同一种数字，笔画掩码 应当相似；若把颜色通道直接送进模板匹配，颜色变化会被误认为字形变化。 数字匹配只用白色掩码，颜色由 9.3 单独判断。

样本不足。五个模板只覆盖 1–5，遇到 6–9 或不同字体时，最高分 仍会给出一个类别，但结果没有意义。应同时检查绝对分数与差距，并在 模板集中加入实际字体的样本。

9.5视频状态机与跟踪

单帧检测会抖动：某一帧漏检不代表目标消失，某一帧误检也不代表目标 出现。状态机用连续帧计数把单帧结果变成稳定状态。本课在整段 300 帧 视频上运行检测、配对与颜色判别，维护“候选、确认、丢失”三个状态， 写出标注视频并打印状态切换日志。

状态与帧计数

初始状态为候选。每检测到一块装甲板，命中计数加一；连续命中达到 3 帧，进入确认状态。确认后若连续 5 帧没有 检测，进入丢失状态。丢失期间不立即相信单帧检测，要求连续 3 帧重新检测到，才回到确认状态并记为一次重捕。任何一次 漏检都会把命中计数清零，任何一次检测都会把丢失计数清零。

三个阈值对应三种取舍：确认帧数越大，误检越难进入确认，但真实目标 出现得更晚；丢失帧数越大，短暂遮挡越不容易打断跟踪，但目标真正离开 后状态切换更慢；重捕帧数越大，重捕越可靠，但恢复更慢。阈值应由 帧率、目标停留时间与允许延迟共同决定，不能只看一段视频调死。

本课没有把卡尔曼滤波接进状态机。检测框中心已经足够画框与判断状态； 若需要预测丢失期间的位置，可以在确认状态后对中心或角度加一层第 8 部分 的滤波，丢失时只预测，重捕时重置。先让状态机在原始检测上稳定，再 加滤波，问题更容易定位。

namespace {

struct Bar {
    cv::Point2f center;
    cv::Point2f axis;
    cv::Point2f normal;
    float half_len = 0.0f;
    float half_wid = 0.0f;
    double area = 0.0;
    double angle = 0.0;
};

struct Pair {
    int left = -1;
    int right = -1;
    double score = 0.0;
    double angle_error = 0.0;
    double center_error = 0.0;
    double length_ratio = 1.0;
    cv::Point2f corners[4];
    cv::Mat plate;
    std::string color;
    int red_pixels = 0;
    int blue_pixels = 0;
};

float dot(const cv::Point2f& a, const cv::Point2f& b) {
    return a.x * b.x + a.y * b.y;
}

cv::Point2f normalize(const cv::Point2f& v) {
    const float n = std::sqrt(v.x * v.x + v.y * v.y);
    if (n < 1e-6f) {
        return cv::Point2f(0.0f, 1.0f);
    }
    return cv::Point2f(v.x / n, v.y / n);
}

Bar makeBar(const std::vector<cv::Point>& contour) {
    cv::Mat samples(static_cast<int>(contour.size()), 2, CV_64F);
    for (int i = 0; i < samples.rows; ++i) {
        samples.at<double>(i, 0) = contour[i].x;
        samples.at<double>(i, 1) = contour[i].y;
    }
    cv::PCA pca(samples, cv::Mat(), cv::PCA::DATA_AS_ROW);
    Bar bar;
    bar.center = cv::Point2f(
        static_cast<float>(pca.mean.at<double>(0, 0)),
        static_cast<float>(pca.mean.at<double>(0, 1)));
    bar.axis = normalize(cv::Point2f(
        static_cast<float>(pca.eigenvectors.at<double>(0, 0)),
        static_cast<float>(pca.eigenvectors.at<double>(0, 1))));
    if (bar.axis.y < 0.0f) {
        bar.axis.x = -bar.axis.x;
        bar.axis.y = -bar.axis.y;
    }
    bar.normal = cv::Point2f(bar.axis.y, -bar.axis.x);
    float min_a = 1e9f;
    float max_a = -1e9f;
    float min_n = 1e9f;
    float max_n = -1e9f;
    for (const auto& p : contour) {
        const cv::Point2f q = cv::Point2f(p) - bar.center;
        const float a = dot(q, bar.axis);
        const float n = dot(q, bar.normal);
        min_a = std::min(min_a, a);
        max_a = std::max(max_a, a);
        min_n = std::min(min_n, n);
        max_n = std::max(max_n, n);
    }
    bar.half_len = 0.5f * (max_a - min_a);
    bar.half_wid = 0.5f * (max_n - min_n);
    bar.area = cv::contourArea(contour);
    bar.angle = std::atan2(bar.axis.y, bar.axis.x) * 180.0 / CV_PI;
    return bar;
}

std::vector<Bar> findBars(const cv::Mat& gray) {
    cv::Mat mask;
    cv::threshold(gray, mask, 190, 255, cv::THRESH_BINARY);
    const cv::Mat kernel = cv::getStructuringElement(cv::MORPH_RECT,
                                                     cv::Size(3, 3));
    cv::morphologyEx(mask, mask, cv::MORPH_OPEN, kernel);
    cv::morphologyEx(mask, mask, cv::MORPH_CLOSE, kernel);

    std::vector<std::vector<cv::Point>> contours;
    cv::findContours(mask.clone(), contours, cv::RETR_EXTERNAL,
                     cv::CHAIN_APPROX_SIMPLE);
    std::vector<Bar> bars;
    for (const auto& contour : contours) {
        const double area = cv::contourArea(contour);
        if (area < 500.0 || area > 10000.0) {
            continue;
        }
        const Bar bar = makeBar(contour);
        if (bar.half_wid < 1.0f) {
            continue;
        }
        const double aspect = bar.half_len / bar.half_wid;
        const double fill = area / (4.0 * bar.half_len * bar.half_wid);
        if (aspect < 2.5 || aspect > 12.0 || fill < 0.45 ||
            std::fabs(std::fabs(bar.angle) - 90.0) > 30.0) {
            continue;
        }
        bars.push_back(bar);
    }
    std::sort(bars.begin(), bars.end(), [](const Bar& a, const Bar& b) {
        return a.center.x < b.center.x;
    });
    return bars;
}

void classifyColor(Pair& pair) {
    cv::Mat hsv;
    cv::cvtColor(pair.plate, hsv, cv::COLOR_BGR2HSV);
    const cv::Rect roi(20, 15, 100, 50);
    for (int y = roi.y; y < roi.y + roi.height; ++y) {
        const cv::Vec3b* row = hsv.ptr<cv::Vec3b>(y);
        for (int x = roi.x; x < roi.x + roi.width; ++x) {
            const int h = row[x][0];
            const int s = row[x][1];
            const int v = row[x][2];
            if (s < 100 || v < 60) {
                continue;
            }
            if (h < 10 || h > 170) {
                ++pair.red_pixels;
            } else if (h > 100 && h < 130) {
                ++pair.blue_pixels;
            }
        }
    }
    pair.color = pair.red_pixels >= pair.blue_pixels ? "red" : "blue";
}

bool buildPair(const std::vector<Bar>& bars, int i, int j, Pair& pair) {
    const Bar& a = bars[i];
    const Bar& b = bars[j];
    const float dir = dot(a.axis, b.axis);
    if (dir < 0.0f) {
        return false;
    }
    const double angle_error = std::acos(std::min(1.0f, std::max(-1.0f, dir))) *
                               180.0 / CV_PI;
    if (angle_error > 8.0) {
        return false;
    }
    const cv::Point2f axis = normalize(a.axis + b.axis);
    const cv::Point2f normal(axis.y, -axis.x);
    const float dx = dot(b.center - a.center, normal);
    const float dy = dot(b.center - a.center, axis);
    const float mean_len = 0.5f * (a.half_len + b.half_len);
    const float full_len = 2.0f * mean_len;
    if (dx <= 0.0f || dx < 0.8f * full_len || dx > 2.5f * full_len) {
        return false;
    }
    if (std::fabs(dy) > 0.25f * full_len) {
        return false;
    }
    const double length_ratio = std::min(a.half_len, b.half_len) /
                                std::max(a.half_len, b.half_len);
    if (length_ratio < 0.8) {
        return false;
    }

    pair.left = i;
    pair.right = j;
    pair.angle_error = angle_error;
    pair.center_error = std::fabs(dy) / full_len;
    pair.length_ratio = length_ratio;
    pair.score = angle_error / 8.0 + pair.center_error / 0.25 +
                 (1.0 - length_ratio) / 0.2;

    pair.corners[0] = a.center - axis * a.half_len + normal * a.half_wid;
    pair.corners[1] = b.center - axis * b.half_len - normal * b.half_wid;
    pair.corners[2] = b.center + axis * b.half_len - normal * b.half_wid;
    pair.corners[3] = a.center + axis * a.half_len + normal * a.half_wid;
    return true;
}

cv::Mat warpPair(const cv::Mat& frame, const Pair& pair) {
    const cv::Point2f dst[4] = {
        cv::Point2f(0.0f, 0.0f), cv::Point2f(139.0f, 0.0f),
        cv::Point2f(139.0f, 79.0f), cv::Point2f(0.0f, 79.0f)};
    const cv::Mat transform = cv::getPerspectiveTransform(pair.corners, dst);
    cv::Mat plate;
    cv::warpPerspective(frame, plate, transform, cv::Size(140, 80),
                        cv::INTER_LINEAR);
    return plate;
}

int main() {
    cv::VideoCapture cap("../素材/synth_armor.mp4");
    if (!cap.isOpened()) {
        std::cout << "无法打开 synth_armor.mp4\n";
        return 1;
    }
    const int width = cvRound(cap.get(cv::CAP_PROP_FRAME_WIDTH));
    const int height = cvRound(cap.get(cv::CAP_PROP_FRAME_HEIGHT));
    const double fps = cap.get(cv::CAP_PROP_FPS);

    cv::VideoWriter writer("../素材/out_armor_state.mp4",
                           cv::VideoWriter::fourcc('m', 'p', '4', 'v'), fps,
                           cv::Size(width, height));
    if (!writer.isOpened()) {
        std::cout << "无法创建 out_armor_state.mp4\n";
        return 1;
    }

    enum State { kCandidate, kConfirmed, kLost };
    State state = kCandidate;
    int hits = 0;
    int recapture_hits = 0;
    int misses = 0;
    int frame_index = 0;
    int detections = 0;
    int confirmed_frames = 0;
    int lost_events = 0;
    int recaptures = 0;
    std::string last_color = "-";

    cv::Mat frame;
    while (cap.read(frame)) {
        if (frame.empty()) {
            break;
        }
        cv::Mat gray;
        cv::cvtColor(frame, gray, cv::COLOR_BGR2GRAY);
        const std::vector<Bar> bars = findBars(gray);
        std::vector<Pair> pairs;
        for (std::size_t i = 0; i < bars.size(); ++i) {
            for (std::size_t j = i + 1; j < bars.size(); ++j) {
                Pair pair;
                if (buildPair(bars, static_cast<int>(i),
                              static_cast<int>(j), pair)) {
                    pair.plate = warpPair(frame, pair);
                    classifyColor(pair);
                    pairs.push_back(pair);
                }
            }
        }
        std::sort(pairs.begin(), pairs.end(),
                  [](const Pair& a, const Pair& b) {
                      return a.score < b.score;
                  });
        const bool detected = !pairs.empty();

        if (detected) {
            ++detections;
            const Pair& best = pairs.front();
            if (state == kLost) {
                ++recapture_hits;
                if (recapture_hits >= 3) {
                    state = kConfirmed;
                    hits = 3;
                    recapture_hits = 0;
                    ++recaptures;
                    std::cout << "frame=" << frame_index
                              << " state=lost->confirmed color=" << best.color
                              << '\n';
                }
            } else {
                ++hits;
                if (state == kCandidate && hits >= 3) {
                    state = kConfirmed;
                    std::cout << "frame=" << frame_index
                              << " state=candidate->confirmed color="
                              << best.color << '\n';
                }
            }
            if (best.color != last_color) {
                std::cout << "frame=" << frame_index << " color=" << last_color
                          << "->" << best.color << '\n';
                last_color = best.color;
            }
            misses = 0;
        } else {
            hits = 0;
            recapture_hits = 0;
            if (state == kConfirmed) {
                ++misses;
                if (misses >= 5) {
                    state = kLost;
                    recapture_hits = 0;
                    ++lost_events;
                    std::cout << "frame=" << frame_index
                              << " state=confirmed->lost\n";
                }
            }
        }

        if (state == kConfirmed) {
            ++confirmed_frames;
        }

        cv::Mat shown = frame.clone();
        if (detected) {
            const Pair& best = pairs.front();
            for (int k = 0; k < 4; ++k) {
                cv::line(shown,
                         cv::Point(cvRound(best.corners[k].x),
                                   cvRound(best.corners[k].y)),
                         cv::Point(cvRound(best.corners[(k + 1) % 4].x),
                                   cvRound(best.corners[(k + 1) % 4].y)),
                         cv::Scalar(40, 220, 40), 2, cv::LINE_AA);
            }
            cv::putText(shown, best.color, cv::Point(20, 32),
                        cv::FONT_HERSHEY_SIMPLEX, 0.75,
                        cv::Scalar(40, 220, 40), 2, cv::LINE_AA);
        }
        const char* state_text = "candidate";
        if (state == kConfirmed) {
            state_text = "confirmed";
        } else if (state == kLost) {
            state_text = "lost";
        }
        cv::putText(shown, state_text, cv::Point(20, 64),
                    cv::FONT_HERSHEY_SIMPLEX, 0.75, cv::Scalar(40, 220, 255),
                    2, cv::LINE_AA);
        cv::putText(shown, cv::format("frame %d", frame_index),
                    cv::Point(20, 96), cv::FONT_HERSHEY_SIMPLEX, 0.6,
                    cv::Scalar(230, 230, 230), 1, cv::LINE_AA);
        if (frame_index == 200) {
            cv::imwrite("../素材/out_armor_state.png", shown);
        }
        writer.write(shown);
        ++frame_index;
    }
    writer.release();

    cv::VideoCapture reader("../素材/out_armor_state.mp4");
    const int readback = reader.isOpened()
                             ? cvRound(reader.get(cv::CAP_PROP_FRAME_COUNT))
                             : 0;
    std::cout << "frames = " << frame_index << '\n';
    std::cout << "detections = " << detections
              << " confirmed_frames = " << confirmed_frames << '\n';
    std::cout << "lost_events = " << lost_events
              << " recaptures = " << recaptures << '\n';
    std::cout << "saved out_armor_state.mp4 " << width << "x" << height
              << " frames=" << readback << ": "
              << (readback == frame_index ? "yes" : "no") << '\n';
    return 0;
}

日志与视频输出

日志只打印状态切换与颜色变化，不逐帧打印候选表。状态切换包括 candidate->confirmed、confirmed->lost、 lost->confirmed；颜色变化单独记录。日志行带帧号， 可以直接跳到对应帧检查画面。若每帧都打印，输出会被大量重复行占满， 反而看不到关键事件。

VideoWriter 的尺寸必须与写入帧一致。程序从 VideoCapture 读取宽高与帧率，再用同一组参数构造写入器； 标注画在 frame.clone() 上，不修改原始帧。写完后释放 VideoWriter，再用 VideoCapture 回读帧数， 确认文件完整。

常见错误

单帧抖动导致状态频繁切换。确认与丢失阈值都取 1 帧时，任何 一次漏检或误检都会改变状态，日志被大量切换占满。应保留连续帧计数， 让状态对单帧异常不敏感。

丢失后没有重捕条件。丢失状态若一检测到就立即确认，误检会直接 变成目标；若永远不回到确认，真实目标回来也无法恢复。重捕需要独立的 连续命中计数，并与首次确认分开统计。

写入尺寸不一致。把检测结果画到缩放后的图上，却用原始尺寸构造 VideoWriter，写入会失败或得到花屏。标注前后保持同一 尺寸；若必须缩放，写入器也要使用缩放后的尺寸。

丢失期间继续使用旧框。目标已经离开，仍按上一帧中心画框，会 让画面看起来“还在跟踪”。丢失状态应明确标注，或只画预测位置并注明 是预测；不要把旧检测框当成当前检测。

9.6性能、调试与参数

流程能运行通过之后，下一步是知道时间花在哪里、参数在哪里改、坐标在哪一层 换算。本课对每三段取一帧，共 100 个样本，分别统计灰度、掩码、轮廓与 配对四段的平均耗时；把阈值与几何条件收进 Params；并在 车辆 ROI 内检测，再把局部坐标加回全图坐标。最后用一段实拍视频做 观察对照，比较合成画面与真实相机画面的差异。示例只要求看懂结构与 输出，不要求从零实现。

分段计时

cv::getTickCount() 返回当前 tick 数， cv::getTickFrequency() 返回每秒 tick 数。两数相减再除以 频率，就是秒数；乘 1000 得到毫秒。计时点放在每段处理 前后，累计后除以样本数，得到平均耗时。示例把耗时行写成 time 名称=数值 ms，名称只用小写字母与下划线，便于脚本 识别。

计时要包含真正要比较的工作，不能把读视频、解码与等待也算进算法段。 示例先 cap.set 与 cap >> frame，再用 getTickCount 开始计时；解码时间不计入四段。若比较不同 实现，应固定采样帧、ROI 与编译选项，只改被测代码。开启 -O2 后，简单的灰度与阈值通常只需零点几毫秒；关闭优化 可能相差数倍，所以比较前要确认编译命令一致。

输出中的毫秒数随机器负载变化，页面上的数值是某一台机器的一次运行， 不应逐字照抄到结论里。看比例：若配对段远大于其他段，应先优化候选 数量或减少重复的透视变换；若掩码段占比高，再检查图像尺寸与形态学核 大小。绝对数值只有在同一台机器、同一编译选项下才有比较意义。

参数结构与 ROI

Params 集中保存阈值、面积范围、宽高比、填充率、倾角、 配对夹角、间距比例、中心偏移与长度比。每项都有默认值，改动时只改 结构体，不在函数里散落数字。打印参数表可以让日志与结果对应；同一段 视频换参数后，先比较候选数与状态日志，再比较最终画面。

车辆 ROI 是整帧中的一个矩形。程序在 ROI 上检测，得到的中心、角点与 轮廓坐标都是 ROI 局部坐标；画到全图或与全图坐标比较前，必须加上 ROI 的左上角偏移。示例的 ROI 为 (60,120,520,300)，第 39 帧局部中心 (368.578,157.865)，加偏移后全图中心 (428.578,277.865)。忘记加偏移，框会整体左上错位，且 误差恰好等于 ROI 原点。

程序每 3 帧取一帧，在车辆 ROI 内完成灰度、掩码、轮廓筛选、配对与 颜色判别，累计四段耗时；对第 39 帧额外打印局部中心与全图中心，并 保存带 ROI 边框与候选框的画面。

#include <algorithm>
#include <cmath>
#include <iomanip>
#include <iostream>
#include <string>
#include <vector>

#include <opencv2/core.hpp>
#include <opencv2/imgcodecs.hpp>

namespace {

struct Bar {
    cv::Point2f center;
    cv::Point2f axis;
    cv::Point2f normal;
    float half_len = 0.0f;
    float half_wid = 0.0f;
    double area = 0.0;
    double angle = 0.0;
};


struct Params {
    double threshold = 190.0;
    double min_area = 500.0;
    double max_area = 10000.0;
    double min_aspect = 2.5;
    double max_aspect = 12.0;
    double min_fill = 0.45;
    double max_tilt = 30.0;
    double max_pair_angle = 8.0;
    double min_gap_ratio = 0.8;
    double max_gap_ratio = 2.5;
    double max_center_offset = 0.25;
    double min_length_ratio = 0.8;
};

struct Pair {
    int left = -1;
    int right = -1;
    double score = 0.0;
    double angle_error = 0.0;
    double center_error = 0.0;
    double length_ratio = 1.0;
    cv::Point2f corners[4];
    cv::Mat plate;
    std::string color;
    int red_pixels = 0;
    int blue_pixels = 0;
};

float dot(const cv::Point2f& a, const cv::Point2f& b) {
    return a.x * b.x + a.y * b.y;
}

cv::Point2f normalize(const cv::Point2f& v) {
    const float n = std::sqrt(v.x * v.x + v.y * v.y);
    if (n < 1e-6f) {
        return cv::Point2f(0.0f, 1.0f);
    }
    return cv::Point2f(v.x / n, v.y / n);
}

Bar makeBar(const std::vector<cv::Point>& contour) {
    cv::Mat samples(static_cast<int>(contour.size()), 2, CV_64F);
    for (int i = 0; i < samples.rows; ++i) {
        samples.at<double>(i, 0) = contour[i].x;
        samples.at<double>(i, 1) = contour[i].y;
    }
    cv::PCA pca(samples, cv::Mat(), cv::PCA::DATA_AS_ROW);
    Bar bar;
    bar.center = cv::Point2f(
        static_cast<float>(pca.mean.at<double>(0, 0)),
        static_cast<float>(pca.mean.at<double>(0, 1)));
    bar.axis = normalize(cv::Point2f(
        static_cast<float>(pca.eigenvectors.at<double>(0, 0)),
        static_cast<float>(pca.eigenvectors.at<double>(0, 1))));
    if (bar.axis.y < 0.0f) {
        bar.axis.x = -bar.axis.x;
        bar.axis.y = -bar.axis.y;
    }
    bar.normal = cv::Point2f(bar.axis.y, -bar.axis.x);
    float min_a = 1e9f;
    float max_a = -1e9f;
    float min_n = 1e9f;
    float max_n = -1e9f;
    for (const auto& p : contour) {
        const cv::Point2f q = cv::Point2f(p) - bar.center;
        const float a = dot(q, bar.axis);
        const float n = dot(q, bar.normal);
        min_a = std::min(min_a, a);
        max_a = std::max(max_a, a);
        min_n = std::min(min_n, n);
        max_n = std::max(max_n, n);
    }
    bar.half_len = 0.5f * (max_a - min_a);
    bar.half_wid = 0.5f * (max_n - min_n);
    bar.area = cv::contourArea(contour);
    bar.angle = std::atan2(bar.axis.y, bar.axis.x) * 180.0 / CV_PI;
    return bar;
}

void classifyColor(Pair& pair) {
    cv::Mat hsv;
    cv::cvtColor(pair.plate, hsv, cv::COLOR_BGR2HSV);
    const cv::Rect roi(20, 15, 100, 50);
    for (int y = roi.y; y < roi.y + roi.height; ++y) {
        const cv::Vec3b* row = hsv.ptr<cv::Vec3b>(y);
        for (int x = roi.x; x < roi.x + roi.width; ++x) {
            const int h = row[x][0];
            const int s = row[x][1];
            const int v = row[x][2];
            if (s < 100 || v < 60) {
                continue;
            }
            if (h < 10 || h > 170) {
                ++pair.red_pixels;
            } else if (h > 100 && h < 130) {
                ++pair.blue_pixels;
            }
        }
    }
    pair.color = pair.red_pixels >= pair.blue_pixels ? "red" : "blue";
}

bool buildPair(const std::vector<Bar>& bars, int i, int j,
               const Params& p, Pair& pair) {
    const Bar& a = bars[i];
    const Bar& b = bars[j];
    const float dir = dot(a.axis, b.axis);
    if (dir < 0.0f) {
        return false;
    }
    const double angle_error = std::acos(std::min(1.0f, std::max(-1.0f, dir))) *
                               180.0 / CV_PI;
    if (angle_error > p.max_pair_angle) {
        return false;
    }
    const cv::Point2f axis = normalize(a.axis + b.axis);
    const cv::Point2f normal(axis.y, -axis.x);
    const float dx = dot(b.center - a.center, normal);
    const float dy = dot(b.center - a.center, axis);
    const float mean_len = 0.5f * (a.half_len + b.half_len);
    const float full_len = 2.0f * mean_len;
    if (dx <= 0.0f || dx < p.min_gap_ratio * full_len ||
        dx > p.max_gap_ratio * full_len) {
        return false;
    }
    if (std::fabs(dy) > p.max_center_offset * full_len) {
        return false;
    }
    const double length_ratio = std::min(a.half_len, b.half_len) /
                                std::max(a.half_len, b.half_len);
    if (length_ratio < p.min_length_ratio) {
        return false;
    }

    pair.left = i;
    pair.right = j;
    pair.angle_error = angle_error;
    pair.center_error = std::fabs(dy) / full_len;
    pair.length_ratio = length_ratio;
    pair.score = angle_error / p.max_pair_angle +
                 pair.center_error / p.max_center_offset +
                 (1.0 - length_ratio) / (1.0 - p.min_length_ratio);

    pair.corners[0] = a.center - axis * a.half_len + normal * a.half_wid;
    pair.corners[1] = b.center - axis * b.half_len - normal * b.half_wid;
    pair.corners[2] = b.center + axis * b.half_len - normal * b.half_wid;
    pair.corners[3] = a.center + axis * a.half_len + normal * a.half_wid;
    return true;
}

cv::Mat warpPair(const cv::Mat& frame, const Pair& pair) {
    const cv::Point2f dst[4] = {
        cv::Point2f(0.0f, 0.0f), cv::Point2f(139.0f, 0.0f),
        cv::Point2f(139.0f, 79.0f), cv::Point2f(0.0f, 79.0f)};
    const cv::Mat transform = cv::getPerspectiveTransform(pair.corners, dst);
    cv::Mat plate;
    cv::warpPerspective(frame, plate, transform, cv::Size(140, 80),
                        cv::INTER_LINEAR);
    return plate;
}

}  // namespace

cv::Point2f pairCenter(const Pair& pair) {
    cv::Point2f center(0.0f, 0.0f);
    for (int k = 0; k < 4; ++k) {
        center += pair.corners[k];
    }
    return center * 0.25f;
}

int main() {
    cv::VideoCapture cap("../素材/synth_armor.mp4");
    if (!cap.isOpened()) {
        std::cout << "无法打开 synth_armor.mp4\n";
        return 1;
    }
    const int total = cvRound(cap.get(cv::CAP_PROP_FRAME_COUNT));
    const Params params;
    const cv::Rect vehicle_roi(60, 120, 520, 300);

    double gray_ms = 0.0;
    double mask_ms = 0.0;
    double contour_ms = 0.0;
    double pair_ms = 0.0;
    double total_ms = 0.0;
    int samples = 0;
    int detections = 0;
    cv::Mat sample_frame;
    cv::Point2f sample_local;
    cv::Point2f sample_full;
    int sample_index = -1;

    for (int index = 0; index < total; index += 3) {
        cap.set(cv::CAP_PROP_POS_FRAMES, index);
        cv::Mat frame;
        cap >> frame;
        if (frame.empty()) {
            continue;
        }
        const cv::Mat roi = frame(vehicle_roi);
        const int64 start = cv::getTickCount();

        cv::Mat gray;
        cv::cvtColor(roi, gray, cv::COLOR_BGR2GRAY);
        const int64 after_gray = cv::getTickCount();

        cv::Mat mask;
        cv::threshold(gray, mask, params.threshold, 255, cv::THRESH_BINARY);
        const cv::Mat kernel = cv::getStructuringElement(
            cv::MORPH_RECT, cv::Size(3, 3));
        cv::morphologyEx(mask, mask, cv::MORPH_OPEN, kernel);
        cv::morphologyEx(mask, mask, cv::MORPH_CLOSE, kernel);
        const int64 after_mask = cv::getTickCount();

        std::vector<std::vector<cv::Point>> contours;
        cv::findContours(mask.clone(), contours, cv::RETR_EXTERNAL,
                         cv::CHAIN_APPROX_SIMPLE);
        std::vector<Bar> bars;
        for (const auto& contour : contours) {
            const double area = cv::contourArea(contour);
            if (area < params.min_area || area > params.max_area) {
                continue;
            }
            const Bar bar = makeBar(contour);
            if (bar.half_wid < 1.0f) {
                continue;
            }
            const double aspect = bar.half_len / bar.half_wid;
            const double fill =
                area / (4.0 * bar.half_len * bar.half_wid);
            if (aspect < params.min_aspect ||
                aspect > params.max_aspect || fill < params.min_fill ||
                std::fabs(std::fabs(bar.angle) - 90.0) > params.max_tilt) {
                continue;
            }
            bars.push_back(bar);
        }
        std::sort(bars.begin(), bars.end(), [](const Bar& a, const Bar& b) {
            return a.center.x < b.center.x;
        });
        const int64 after_contour = cv::getTickCount();

        std::vector<Pair> pairs;
        for (std::size_t i = 0; i < bars.size(); ++i) {
            for (std::size_t j = i + 1; j < bars.size(); ++j) {
                Pair pair;
                if (buildPair(bars, static_cast<int>(i), static_cast<int>(j),
                              params, pair)) {
                    pair.plate = warpPair(roi, pair);
                    classifyColor(pair);
                    pairs.push_back(pair);
                }
            }
        }
        std::sort(pairs.begin(), pairs.end(),
                  [](const Pair& a, const Pair& b) {
                      return a.score < b.score;
                  });
        const int64 after_pair = cv::getTickCount();
        if (!pairs.empty()) {
            ++detections;
            if (index == 39) {
                sample_index = index;
                sample_local = pairCenter(pairs.front());
                sample_full = sample_local + cv::Point2f(
                    static_cast<float>(vehicle_roi.x),
                    static_cast<float>(vehicle_roi.y));
                sample_frame = frame.clone();
                for (int k = 0; k < 4; ++k) {
                    const cv::Point2f a =
                        pairs.front().corners[k] +
                        cv::Point2f(static_cast<float>(vehicle_roi.x),
                                    static_cast<float>(vehicle_roi.y));
                    const cv::Point2f b =
                        pairs.front().corners[(k + 1) % 4] +
                        cv::Point2f(static_cast<float>(vehicle_roi.x),
                                    static_cast<float>(vehicle_roi.y));
                    cv::line(sample_frame, cv::Point(cvRound(a.x), cvRound(a.y)),
                             cv::Point(cvRound(b.x), cvRound(b.y)),
                             cv::Scalar(40, 220, 40), 2, cv::LINE_AA);
                }
                cv::rectangle(sample_frame, vehicle_roi,
                              cv::Scalar(40, 180, 255), 2, cv::LINE_AA);
            }
        }

        const double tick = cv::getTickFrequency();
        gray_ms += (after_gray - start) * 1000.0 / tick;
        mask_ms += (after_mask - after_gray) * 1000.0 / tick;
        contour_ms += (after_contour - after_mask) * 1000.0 / tick;
        pair_ms += (after_pair - after_contour) * 1000.0 / tick;
        total_ms += (after_pair - start) * 1000.0 / tick;
        ++samples;
    }

    std::cout << std::fixed << std::setprecision(3);
    std::cout << "video_frames = " << total << " samples = " << samples
              << " detections = " << detections << '\n';
    std::cout << "params: threshold=" << params.threshold
              << " min_area=" << params.min_area
              << " max_area=" << params.max_area << '\n';
    std::cout << "params: aspect=[" << params.min_aspect << ','
              << params.max_aspect << "] fill=" << params.min_fill << '\n';
    std::cout << "roi = (" << vehicle_roi.x << ", " << vehicle_roi.y << ", "
              << vehicle_roi.width << ", " << vehicle_roi.height << ")\n";
    std::cout << "sample_frame = " << sample_index << '\n';
    std::cout << "local_center = (" << sample_local.x << ", "
              << sample_local.y << ")\n";
    std::cout << "full_center = (" << sample_full.x << ", "
              << sample_full.y << ")\n";
    std::cout << "time gray=" << gray_ms / samples << " ms\n";
    std::cout << "time mask=" << mask_ms / samples << " ms\n";
    std::cout << "time contours=" << contour_ms / samples << " ms\n";
    std::cout << "time pairing=" << pair_ms / samples << " ms\n";
    std::cout << "time total=" << total_ms / samples << " ms\n";
    if (!sample_frame.empty()) {
        cv::putText(sample_frame, "vehicle roi", cv::Point(70, 150),
                    cv::FONT_HERSHEY_SIMPLEX, 0.6, cv::Scalar(40, 180, 255),
                    2, cv::LINE_AA);
        const bool saved = cv::imwrite("../素材/out_armor_roi.png",
                                       sample_frame);
        std::cout << "saved out_armor_roi.png " << sample_frame.cols << "x"
                  << sample_frame.rows << ": " << (saved ? "yes" : "no")
                  << '\n';
    }
    return 0;
}

实拍视频观察

合成视频的光照、颜色与数字都由程序控制，适合逐段核对算法；真实相机 画面不会保持这些条件。环境光偏蓝或偏红、灯条过曝、目标快速运动、 地面与装甲板反光、其他机器人进入画面，都会改变阈值、轮廓与配对的 结果。这一节读取一段 640×480、90 帧每秒、123 秒的实拍视频，抽取 四个时刻的画面，作为参数检查的对照材料。

程序打印的属性为：分辨率 640×480，帧率 90 帧每秒，总帧数 11071，时长约 123.011 秒。高帧率有利于观察快速运动，但每一帧的曝光 时间与运动模糊仍不同；定位画面时按时间或帧号计算，不能按处理耗时 推算视频时间。

例题 · 读取实拍视频

程序读取视频属性，按时间抽取第 25、50、80、105 秒的画面，在每格 左上角标注时刻，拼成 2×2 对照图。抽帧按顺序解码，不依赖关键帧 定位，因此同一份视频在不同机器上取到的是同一批帧。

void put_label(cv::Mat& tile, const std::string& text) {
    cv::putText(tile, text, cv::Point(14, 36), cv::FONT_HERSHEY_SIMPLEX,
                0.9, cv::Scalar(0, 0, 0), 5, cv::LINE_AA);
    cv::putText(tile, text, cv::Point(12, 34), cv::FONT_HERSHEY_SIMPLEX,
                0.9, cv::Scalar(255, 255, 255), 2, cv::LINE_AA);
}

}  // namespace

int main() {
    const std::string path = "../素材/real_armor.mp4";
    cv::VideoCapture cap(path);
    if (!cap.isOpened()) {
        std::cerr << "无法打开 real_armor.mp4\n";
        return 1;
    }

    const double fps = cap.get(cv::CAP_PROP_FPS);
    const double count = cap.get(cv::CAP_PROP_FRAME_COUNT);
    const int width = static_cast<int>(cap.get(cv::CAP_PROP_FRAME_WIDTH));
    const int height = static_cast<int>(cap.get(cv::CAP_PROP_FRAME_HEIGHT));
    if (fps <= 0.0 || count <= 0.0) {
        std::cerr << "视频属性无效\n";
        return 1;
    }

    std::cout << std::fixed << std::setprecision(3);
    std::cout << "size = " << width << 'x' << height << '\n';
    std::cout << "fps = " << fps << '\n';
    std::cout << "frames = " << static_cast<int>(count) << '\n';
    std::cout << "duration = " << count / fps << " s\n";

    const double seconds[] = {25.0, 50.0, 80.0, 105.0};
    std::vector<int> targets;
    for (double s : seconds) {
        targets.push_back(static_cast<int>(std::lround(s * fps)));
    }

    std::vector<cv::Mat> tiles;
    cv::Mat frame;
    std::size_t next = 0;
    for (int index = 0; index <= targets.back() && cap.read(frame); ++index) {
        if (next < targets.size() && index == targets[next]) {
            cv::Mat tile = frame.clone();
            put_label(tile, std::to_string(static_cast<int>(seconds[next])) +
                                 " s");
            tiles.push_back(tile);
            ++next;
        }
    }
    if (tiles.size() != 4) {
        std::cerr << "抽取的帧数不足\n";
        return 1;
    }

    cv::Mat top;
    cv::Mat bottom;
    cv::Mat panel;
    cv::hconcat(tiles[0], tiles[1], top);
    cv::hconcat(tiles[2], tiles[3], bottom);
    cv::vconcat(top, bottom, panel);

    const bool saved = cv::imwrite("../素材/out_armor_real.png", panel);
    std::cout << "saved out_armor_real.png " << panel.cols << 'x'
              << panel.rows << ": " << (saved ? "yes" : "no") << '\n';
    return saved ? 0 : 1;

观察时把现象对应到处理阶段，比直接调参数更有用。下表列出四类常见 差异，以及它们最先影响的那一段。

现象最先影响检查点
环境光色偏 颜色掩码、灰度阈值 灯条局部取色；固定曝光与白平衡，或用通道差

按下面四项记录观察结果；检测程序由读者使用前面的流程自行完成。

  1. 在四个时刻各选一块装甲板，记录灯条颜色、板面数字与灯条的像素高度。
  2. 比较第 50 秒附近的环境光颜色与灯条颜色，说明整块板面的平均色会偏向哪一侧。
  3. 比较第 80 秒与第 105 秒的目标像素高度，判断当前面积下限与配对间距是否仍能覆盖两端。
  4. 选一个时刻，列出会先调整的三个参数，并说明先看哪一张中间图。

合成视频用于建立流程与核对坐标，实拍视频用于暴露边界。两者放在一起 看，才能区分算法错误与素材差异。调整参数时先固定一组实拍帧，记录 灯条候选数、配对候选数与状态变化，再回到整段视频验证；不要只凭一张 画面调参。

检查清单

负宽高与空矩形。Rect 的宽高必须为正；轮廓包围盒 可能为零，除面积或宽高比之前先检查。ROI 越界要在取图前裁剪，不能 假设检测到的框一定落在图像内。

除以零。宽高比、填充率、长度比都要检查分母；灯条宽度为零、 两根灯条长度为零时，直接跳过该候选。浮点除零不会崩溃，但会得到 inf 或 nan，后续比较全部失效。

无效点与坐标层。透视变换的四个点顺序必须一致，点不能在图像 外；ROI 内坐标与全图坐标不能混用。画框、写日志、与真值比较时，统一 使用同一层坐标，并在变量名中注明 local 或 full。

整数累加与时间同步。面积、坐标用浮点累计，避免整数截断；视频 时间用帧号除以帧率，不要用处理耗时累加。丢帧时按时间戳计算间隔， 状态机的帧计数才不会随处理速度变化。

练习 9-6

ROI 原点为 (60,120)，局部中心为 (368.578,157.865)，打印全图中心；同时打印 min_area 的默认值 500，保留三位小数。

预期输出：

roi = (60, 120, 520, 300)
local_center = (368.578, 157.865)
full_center = (428.578, 277.865)
min_area = 500.000
看答案

全图坐标等于局部坐标加 ROI 原点： 368.578+60=428.578， 157.865+120=277.865。这类换算只涉及加法，但坐标层 混用后错误很难从画面看出，变量命名与日志要明确标注。 

#include <iomanip>
#include <iostream>

int main() {
    const int roi_x = 60;
    const int roi_y = 120;
    const double local_x = 368.578;
    const double local_y = 157.865;
    const double full_x = local_x + roi_x;
    const double full_y = local_y + roi_y;

    std::cout << std::fixed << std::setprecision(3);
    std::cout << "roi = (60, 120, 520, 300)\n";
    std::cout << "local_center = (" << local_x << ", " << local_y << ")\n";
    std::cout << "full_center = (" << full_x << ", " << full_y << ")\n";
    std::cout << "min_area = 500.000\n";
    return 0;
}
