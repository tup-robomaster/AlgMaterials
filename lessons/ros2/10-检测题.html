前置

先读过 1.1–1.2、2.1–2.4、3.1–3.3、5.1–5.3、7.1–7.4、8.2 与 9.1–9.4：会写话题、服务与动作，会写 launch 与设置参数，会使用 TF2，会录制与回放 bag，读过巡检流程的四个节点。工作空间位于 $HOME/ros2_ws。

10.1综合检测：多节点数据流

检测环境是一个已经构建好的工作空间。robot_bringup 里的 10.1-inspect.launch.py 启动四个节点：静态坐标广播 static_tf、动作服务端 patrol_server、巡检控制器 patrol_controller 与目标源 target_source。 控制器订阅 /target，发布 /patrol_status， 提供 /set_mode 服务，并作为动作客户端调用 /patrol；服务端提供 /patrol 动作；目标源发布 /target；静态广播发布 /tf_static。

检测环境

launch 文件声明四个可覆盖参数：start_delay_ms 控制目标源 在启动后等待多久再发布，start_server 控制是否启动动作 服务端，server_namespace 改变服务端的命名空间， steps_per_target 控制每个目标分几步完成。检测时把 start_delay_ms 设为 6000，命令行有足够时间查询；默认的 1500 毫秒会在查询完成前结束流程。 

from launch import LaunchDescription
from launch.actions import DeclareLaunchArgument
from launch.conditions import IfCondition
from launch.substitutions import LaunchConfiguration
from launch_ros.actions import Node
from launch_ros.parameter_descriptions import ParameterValue


def generate_launch_description():
    start_server = LaunchConfiguration("start_server")
    server_namespace = LaunchConfiguration("server_namespace")
    steps = LaunchConfiguration("steps_per_target")
    delay = LaunchConfiguration("start_delay_ms")

    static_tf = Node(
        package="robot_nodes",
        executable="static_tf",
        parameters=[
            {
                "parent_frame": "map",
                "child_frame": "base_link",
                "x": 0.0,
                "y": 0.0,
                "z": 0.0,
                "yaw_deg": 0.0,
            }
        ],
    )

    patrol_server = Node(
        package="robot_nodes",
        executable="patrol_server",
        namespace=server_namespace,
        condition=IfCondition(start_server),
    )

    controller = Node(
        package="robot_nodes",
        executable="patrol_controller",
        parameters=[
            {"initial_mode": "patrol"},
            {"steps_per_target": ParameterValue(steps, value_type=int)},
            {"finish_when_empty": True},
        ],
    )

    target_source = Node(
        package="robot_nodes",
        executable="target_source",
        parameters=[
            {"start_delay_ms": ParameterValue(delay, value_type=int)},
            {"max_distance": 0.0},
            {"wait_for_subscriber": True},
        ],
    )

    return LaunchDescription(
        [
            DeclareLaunchArgument("start_server", default_value="true"),
            DeclareLaunchArgument("server_namespace", default_value=""),
            DeclareLaunchArgument("steps_per_target", default_value="1"),
            DeclareLaunchArgument("start_delay_ms", default_value="1500"),
            static_tf,
            patrol_server,
            controller,
            target_source,
        ]
    )

启动命令保持在前台运行，查询放在另一个终端。结束时按 Ctrl+C；控制器在目标处理完后也会自行退出。 

# 当前目录：$HOME/ros2_ws
ros2 launch robot_bringup 10.1-inspect.launch.py start_delay_ms:=6000

节点与接口

四条命令分别查看节点、话题、服务与动作。ros2 topic list 与 ros2 service list 会带上参数事件、日志与每个节点的参数服务； 检测业务接口时先用 grep 去掉这些固定项。 

# 当前目录：$HOME/ros2_ws
ros2 node list | sort
ros2 topic list | grep -v -E '^/(parameter_events|rosout)$' | sort
ros2 service list | grep -v -E 'parameter|type_description' | sort
ros2 action list

节点级对应关系用 ros2 node info。下面的过滤只保留 Subscribers: 与 Publishers: 两节里与业务有关 的两行： 

# 当前目录：$HOME/ros2_ws
ros2 node info /patrol_controller |
  grep -E 'Subscribers:|Publishers:|^    /(target|patrol_status):'
  Subscribers:
    /target: robot_interfaces/msg/Target
  Publishers:
    /patrol_status: robot_interfaces/msg/PatrolStatus

这两行说明数据流的方向：target_source 发布 /target，控制器订阅同一话题；控制器发布 /patrol_status，外部工具订阅它即可看到进度。服务 /set_mode 由控制器提供，动作 /patrol 由服务端 提供、控制器调用。

动作服务端

ros2 action list 只回答“图里有没有这个动作名”。客户端声明 动作客户端后，名字也会出现在列表里，因此列表里有名字不代表服务端存在。 判断动作能否调用要看 ros2 action info 的 Action servers 计数。

把服务端放进 lab 命名空间后，查询结果如下： 

# 当前目录：$HOME/ros2_ws
ros2 launch robot_bringup 10.1-inspect.launch.py \
  server_namespace:=lab start_delay_ms:=6000 &
sleep 3
ros2 action list -t | grep '^/.*patrol' | sort
ros2 action info /patrol
/lab/patrol [robot_interfaces/action/Patrol]
/patrol [robot_interfaces/action/Patrol]
Action: /patrol
Action clients: 1
    /patrol_controller
Action servers: 0

两个名字的类型相同，说明客户端与服务端指向同一个接口，但完整名字不同。 客户端等待 /patrol，服务端注册在 /lab/patrol， 两侧没有匹配。随后控制器打印 action server /patrol not available 并退出。修复方式有两种： 启动时把 server_namespace 设为空，或在客户端一侧做命名空间 或重映射。检测题优先检查启动参数，因为它不需要改源码。

运行默认 launch，列出四个节点及其业务话题，写出数据流中每条边的发布者与订阅者。动作服务端不发布业务话题，单独说明它提供哪个动作。

/patrol_server

看答案

循环对每个节点执行一次 ros2 node info，只保留 Subscribers: 与 Publishers: 两节里的业务行。 控制器订阅 /target、发布 /patrol_status； 目标源发布 /target；静态广播发布 /tf_static； 动作服务端不发布业务话题，它提供 /patrol 动作。 

# 当前目录：$HOME/ros2_ws
ros2 launch robot_bringup 10.1-inspect.launch.py start_delay_ms:=6000 &
sleep 3
for node in $(ros2 node list | sort); do
  echo "$node"
  ros2 node info "$node" | awk '
    /Publishers:/ {sec = "pub"; next}
    /Subscribers:/ {sec = "sub"; next}
    /Service Servers:|Service Clients:|Action Servers:|Action Clients:/ {
      sec = ""; next
    }
    /^[[:space:]]+\// && sec != "" {
      line = $0
      sub(/^[[:space:]]+/, "", line)
      if (line !~ /parameter|rosout/) print "  " sec " " line
    }'
done
/patrol_controller
  sub /target: robot_interfaces/msg/Target
  pub /patrol_status: robot_interfaces/msg/PatrolStatus
/patrol_server
/static_tf
  pub /tf_static: tf2_msgs/msg/TFMessage
/target_source
  pub /target: robot_interfaces/msg/Target

数据流有四条边：目标源发布 /target、控制器订阅 /target；控制器发布 /patrol_status；静态广播 发布 /tf_static；控制器作为动作客户端调用 /patrol，服务端提供同一动作。动作不经过业务话题，因此 不会出现在前三条话题边里。

练习 10-3

定义 Reading.msg（string sensor、float64 value、int32 sequence）与 Scale.srv（请求 float64 factor，响应 float64 value 与 bool ok）。写发布者每 300 毫秒发布三条读数，服务端保存最新一条；收到请求时按 factor 换算，没有读数时返回 ok=false。在发布结束后用 ros2 service call 请求 factor=2.0。

[INFO] [reading_publisher]: publish: left 1.5 #1
[INFO] [reading_publisher]: publish: left 2.0 #2
[INFO] [reading_publisher]: publish: right 3.5 #3
[INFO] [scale_server]: latest: right 3.5 #3
[INFO] [scale_server]: scale: right 3.5 * 2.0 = 7.0 ok=true
看答案

Reading 有三个字段，Scale 的请求是系数、响应 是换算结果与是否成功。发布者在构造时等待订阅者出现，随后每 300 毫秒 发布一条读数；服务端在订阅回调里保存最新读数，收到请求时按 factor 换算。 

#include <chrono>
#include <memory>
#include <string>
#include <thread>

#include "answer_interfaces/msg/reading.hpp"
#include "rclcpp/rclcpp.hpp"

using namespace std::chrono_literals;

class ReadingPublisher : public rclcpp::Node
{
public:
  ReadingPublisher()
  : Node("reading_publisher"), index_(0)
  {
    const bool wait = declare_parameter<bool>("wait_for_subscriber", true);
    publisher_ = create_publisher<answer_interfaces::msg::Reading>("reading", 10);

    if (wait) {
      for (int i = 0; i < 60 && publisher_->get_subscription_count() == 0; ++i) {
        std::this_thread::sleep_for(50ms);
      }
    }

    timer_ = create_wall_timer(300ms, [this]() { publish_one(); });
  }

private:
  void publish_one()
  {
    static const char * sensors[] = {"left", "left", "right"};
    static const double values[] = {1.5, 2.0, 3.5};

    answer_interfaces::msg::Reading reading;
    reading.sensor = sensors[index_];
    reading.value = values[index_];
    reading.sequence = index_ + 1;
    publisher_->publish(reading);
    RCLCPP_INFO(
      get_logger(), "publish: %s %.1f #%d",
      reading.sensor.c_str(), reading.value, reading.sequence);

    ++index_;
    if (index_ == 3) {
      rclcpp::shutdown();
    }
  }

  int index_;
  rclcpp::Publisher<answer_interfaces::msg::Reading>::SharedPtr publisher_;
  rclcpp::TimerBase::SharedPtr timer_;
};

int main(int argc, char ** argv)
{
  rclcpp::init(argc, argv);
  rclcpp::spin(std::make_shared<ReadingPublisher>());
  rclcpp::shutdown();
  return 0;
}
#include <memory>
#include <string>

#include "answer_interfaces/msg/reading.hpp"
#include "answer_interfaces/srv/scale.hpp"
#include "rclcpp/rclcpp.hpp"

class ScaleServer : public rclcpp::Node
{
public:
  ScaleServer()
  : Node("scale_server"), has_reading_(false)
  {
    subscription_ = create_subscription<answer_interfaces::msg::Reading>(
      "reading", 10,
      [this](const answer_interfaces::msg::Reading::SharedPtr message) {
        latest_ = *message;
        has_reading_ = true;
        RCLCPP_INFO(
          get_logger(), "latest: %s %.1f #%d",
          latest_.sensor.c_str(), latest_.value, latest_.sequence);
      });

    service_ = create_service<answer_interfaces::srv::Scale>(
      "scale",
      [this](
        const std::shared_ptr<answer_interfaces::srv::Scale::Request> request,
        std::shared_ptr<answer_interfaces::srv::Scale::Response> response) {
        if (!has_reading_) {
          response->ok = false;
          RCLCPP_INFO(get_logger(), "scale: no reading yet");
          return;
        }
        response->value = latest_.value * request->factor;
        response->ok = true;
        RCLCPP_INFO(
          get_logger(), "scale: %s %.1f * %.1f = %.1f ok=true",
          latest_.sensor.c_str(), latest_.value, request->factor,
          response->value);
      });
  }

private:
  bool has_reading_;
  answer_interfaces::msg::Reading latest_;
  rclcpp::Subscription<answer_interfaces::msg::Reading>::SharedPtr subscription_;
  rclcpp::Service<answer_interfaces::srv::Scale>::SharedPtr service_;
};

int main(int argc, char ** argv)
{
  rclcpp::init(argc, argv);
  rclcpp::spin(std::make_shared<ScaleServer>());
  rclcpp::shutdown();
  return 0;
}

看答案

动作服务端在目标回调里检查 count，正数才接受；执行线程 每隔 200 毫秒发布一次反馈，remaining 从 count-1 递减到 0，最后用 succeed 返回 total=count。客户端等待服务端出现后发送 count=3， 分别在目标响应、反馈与结果回调里打印。 

#include <chrono>
#include <memory>
#include <thread>

#include "answer_interfaces/action/countdown.hpp"
#include "rclcpp/rclcpp.hpp"
#include "rclcpp_action/rclcpp_action.hpp"

using namespace std::chrono_literals;

class CountdownServer : public rclcpp::Node
{
public:
  using Countdown = answer_interfaces::action::Countdown;
  using GoalHandle = rclcpp_action::ServerGoalHandle<Countdown>;

  CountdownServer()
  : Node("countdown_server")
  {
    server_ = rclcpp_action::create_server<Countdown>(
      this,
      "countdown",
      [this](
        const rclcpp_action::GoalUUID &,
        std::shared_ptr<const Countdown::Goal> goal) {
        if (goal->count <= 0) {
          RCLCPP_INFO(get_logger(), "goal rejected: count=%d", goal->count);
          return rclcpp_action::GoalResponse::REJECT;
        }
        RCLCPP_INFO(get_logger(), "goal accepted: count=%d", goal->count);
        return rclcpp_action::GoalResponse::ACCEPT_AND_EXECUTE;
      },
      [](const std::shared_ptr<GoalHandle>) {
        return rclcpp_action::CancelResponse::ACCEPT;
      },
      [this](const std::shared_ptr<GoalHandle> goal_handle) {
        std::thread{&CountdownServer::execute, this, goal_handle}.detach();
      });
  }

private:
  void execute(const std::shared_ptr<GoalHandle> goal_handle)
  {
    const auto goal = goal_handle->get_goal();
    auto feedback = std::make_shared<Countdown::Feedback>();
    auto result = std::make_shared<Countdown::Result>();

    for (int32_t remaining = goal->count; remaining > 0; --remaining) {
      std::this_thread::sleep_for(200ms);
      feedback->remaining = remaining - 1;
      goal_handle->publish_feedback(feedback);
      RCLCPP_INFO(
        get_logger(), "feedback: remaining=%d", feedback->remaining);
    }

    result->total = goal->count;
    goal_handle->succeed(result);
    RCLCPP_INFO(get_logger(), "result: total=%d", result->total);
  }

  rclcpp_action::Server<Countdown>::SharedPtr server_;
};

int main(int argc, char ** argv)
{
  rclcpp::init(argc, argv);
  rclcpp::spin(std::make_shared<CountdownServer>());
  rclcpp::shutdown();
  return 0;
}
#include <chrono>

class CountdownClient : public rclcpp::Node
{
public:
  using Countdown = answer_interfaces::action::Countdown;

  CountdownClient()
  : Node("countdown_client")
  {
    client_ = rclcpp_action::create_client<Countdown>(this, "countdown");
    if (!client_->wait_for_action_server(5s)) {
      RCLCPP_ERROR(get_logger(), "action server /countdown not available");
      rclcpp::shutdown();
    }
  }

  bool ready() const { return rclcpp::ok(); }

  void send()
  {
    Countdown::Goal goal;
    goal.count = 3;

    auto options = rclcpp_action::Client<Countdown>::SendGoalOptions();
    options.goal_response_callback =
      [this](const GoalHandle::SharedPtr & goal_handle) {
        if (!goal_handle) {
          RCLCPP_INFO(get_logger(), "goal rejected");
          return;
        }
        RCLCPP_INFO(get_logger(), "goal accepted");
      };
    options.feedback_callback =
      [this](
        GoalHandle::SharedPtr,
        const std::shared_ptr<const Countdown::Feedback> feedback) {
        RCLCPP_INFO(
          get_logger(), "feedback: remaining=%d", feedback->remaining);
      };
    options.result_callback =
      [this](const GoalHandle::WrappedResult & result) {
        const bool success =
          result.code == rclcpp_action::ResultCode::SUCCEEDED;
        RCLCPP_INFO(
          get_logger(), "result: total=%d success=%s",
          result.result->total, success ? "true" : "false");
        rclcpp::shutdown();
      };
    client_->async_send_goal(goal, options);
  }

private:
  using GoalHandle = rclcpp_action::ClientGoalHandle<Countdown>;
  rclcpp_action::Client<Countdown>::SharedPtr client_;
};

int main(int argc, char ** argv)
{
  rclcpp::init(argc, argv);
  auto node = std::make_shared<CountdownClient>();
  if (node->ready()) {
    node->send();
    rclcpp::spin(node);
  }
  rclcpp::shutdown();
  return 0;
}

using namespace std::chrono_literals;

class TfPointListener : public rclcpp::Node
{
public:
  TfPointListener()
  : Node("tf_point_listener")
  {
    buffer_ = std::make_shared<tf2_ros::Buffer>(get_clock());
  }

  void start()
  {
    listener_ = std::make_shared<tf2_ros::TransformListener>(
      *buffer_, shared_from_this(), false);
    started_at_ = now();
    timer_ = create_wall_timer(100ms, [this]() { try_transform(); });
  }

private:
  void try_transform()
  {
    if (!buffer_->canTransform("map", "sensor", tf2::TimePointZero)) {
      if ((now() - started_at_).seconds() > 5.0) {
        std::cout << "lookup failed: map -> sensor not available\n";
        rclcpp::shutdown();
      }
      return;
    }

    const auto transform = buffer_->lookupTransform(
      "map", "sensor", tf2::TimePointZero);

    geometry_msgs::msg::PointStamped point;
    point.header.frame_id = "sensor";
    point.header.stamp = now();
    point.point.x = 0.2;

    geometry_msgs::msg::PointStamped converted;
    tf2::doTransform(point, converted, transform);
    std::cout << "point in map: (" << std::fixed << std::setprecision(3)
              << converted.point.x << ", " << converted.point.y << ", "
              << converted.point.z << ")\n";
    rclcpp::shutdown();
  }

  rclcpp::Time started_at_;
  std::shared_ptr<tf2_ros::Buffer> buffer_;
  std::shared_ptr<tf2_ros::TransformListener> listener_;
  rclcpp::TimerBase::SharedPtr timer_;
};

int main(int argc, char ** argv)
{
  rclcpp::init(argc, argv);
  auto node = std::make_shared<TfPointListener>();
  node->start();
  rclcpp::spin(node);
  rclcpp::shutdown();
  return 0;
}
