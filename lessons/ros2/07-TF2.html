第 7 部分

TF2

机器人上的传感器、底盘与地图各自使用不同的坐标系。TF2 把这些坐标系 之间的平移与旋转组织成一棵变换树，节点广播变换，其他节点按时间查询 变换，再把点、向量或位姿从一个坐标系换到另一个坐标系。这一部分先讲 坐标系与四元数，再写静态与动态广播，最后监听变换并处理时间异常。

7.1坐标系与四元数

坐标变换（coordinate transform）描述两个坐标系之间的相对位置与姿态。 TF2 用父子关系把它们连成一棵树：每个坐标系只有一个父坐标系，变换的 方向从父到子。查询时给出目标坐标系（target frame）与源坐标系 （source frame），得到把源坐标系中的坐标换到目标坐标系的变换。

坐标系

机器人常用的坐标系有 map、odom、 base_link 与传感器坐标系。map 是全局地图， odom 是里程计累积的局部坐标，base_link 固定在 底盘中心，激光雷达、相机等传感器各有自己的坐标系。变换树把 map 连到 odom，再连到 base_link， 最后连到各个传感器。

平移用三个分量 x、y、z 表示， 旋转用四元数表示。坐标系的轴向按右手定则：x 向前， y 向左，z 向上；绕 z 轴正方向 旋转，从上方看是逆时针。

四元数

四元数（quaternion）用四个数 x、y、z、 w 表示三维旋转。它没有欧拉角的万向节锁问题，插值也平滑， 因此 TF2 的消息统一使用四元数。代价是四个分量不直观，手工计算容易出错， 通常用库函数在欧拉角与四元数之间转换。

tf2::Quaternion 的 setRPY(roll, pitch, yaw) 按弧度设置旋转，tf2::getYaw(q) 从四元数取回绕 z 轴的偏航角。四元数相乘表示旋转的复合：q1 * q2 表示先施加 q2，再施加 q1；绕同一轴的旋转可以 交换顺序。

yaw 与四元数

平面机器人只绕 z 轴旋转，偏航角（yaw）为 θ 时，四元数是 (0, 0, sin(θ/2), cos(θ/2))。偏航角 90° 对应 z=0.707107、w=0.707107；偏航角 180° 对应 z=1、w=0。反算时 tf2::getYaw 返回的角在 -π 到 π 之间。 

#include <cmath>
#include <iomanip>
#include <iostream>
#include <vector>

#include "tf2/LinearMath/Quaternion.h"
#include "tf2/utils.h"

namespace
{
constexpr double kPi = 3.14159265358979323846;

void print_yaw(double degrees)
{
  tf2::Quaternion q;
  q.setRPY(0.0, 0.0, degrees * kPi / 180.0);

  std::cout << "yaw " << std::defaultfloat << degrees << "°: x=" << std::fixed
            << std::setprecision(6) << q.x() << " y=" << q.y() << " z=" << q.z()
            << " w=" << q.w() << "\n";
  std::cout << "getYaw: " << tf2::getYaw(q) * 180.0 / kPi << "°\n";
}
}  // namespace

int main(int argc, char ** argv)
{
  std::vector<double> angles;
  for (int i = 1; i < argc; ++i) {
    angles.push_back(std::stod(argv[i]));
  }
  if (angles.empty()) {
    angles = {90.0, 180.0};
  }
  for (const double angle : angles) {
    print_yaw(angle);
  }
  return 0;
}
例题 · yaw 转四元数

程序不带参数时打印 90° 与 180° 两个例子。每段先输出四元数的四个分量， 再用 tf2::getYaw 换回角度，确认转换可逆。 

# 当前目录：$HOME/ros2_ws
ros2 run robot_nodes yaw_to_quaternion
yaw 90°: x=0.000000 y=0.000000 z=0.707107 w=0.707107
getYaw: 90.000000°
yaw 180°: x=0.000000 y=0.000000 z=1.000000 w=0.000000
getYaw: 180.000000°

getYaw 的输出与输入角度一致，说明四元数没有写错。注意 180° 时 w 为 0，z 为 1；这是单位四元数， 平方和仍为 1。

看答案

把 30° 与 60° 两个绕 z 轴的旋转相乘，打印乘积的四个分量、乘积的偏航角，以及单位化后的模长。

7.2静态坐标广播

传感器在底盘上的安装位置固定不变，对应的变换适合用静态坐标广播 （static transform broadcast）。广播者把变换发布到 /tf_static，只发送一次；新加入的监听者仍能收到，因为 静态话题使用保留历史的 QoS 设置。

变换消息

一条变换是 geometry_msgs/msg/TransformStamped。头部的 frame_id 写父坐标系，child_frame_id 写子坐标系； transform.translation 是子坐标系原点在父坐标系中的位置， transform.rotation 是子坐标系相对父坐标系的旋转。时间戳 在静态变换里不参与插值，但仍要填写。

静态广播者

tf2_ros::StaticTransformBroadcaster 在构造时绑定节点， 调用 sendTransform 发布。它内部使用 /tf_static 话题与静态 QoS；同一个父坐标系下可以有多个 子坐标系，但同一个子坐标系只能有一个父坐标系。 

#include <cmath>
#include <memory>
#include <string>

#include "geometry_msgs/msg/transform_stamped.hpp"
#include "rclcpp/rclcpp.hpp"
#include "tf2/LinearMath/Quaternion.h"
#include "tf2_ros/static_transform_broadcaster.h"

namespace
{
constexpr double kPi = 3.14159265358979323846;
}

class StaticTf : public rclcpp::Node
{
public:
  StaticTf()
  : Node("static_tf")
  {
    const auto parent = declare_parameter<std::string>("parent_frame", "base_link");
    const auto child = declare_parameter<std::string>("child_frame", "laser_link");
    const auto x = declare_parameter<double>("x", 0.2);
    const auto y = declare_parameter<double>("y", 0.0);
    const auto z = declare_parameter<double>("z", 0.3);
    const auto yaw_deg = declare_parameter<double>("yaw_deg", 45.0);

    tf2::Quaternion q;
    q.setRPY(0.0, 0.0, yaw_deg * kPi / 180.0);

    geometry_msgs::msg::TransformStamped transform;
    transform.header.stamp = now();
    transform.header.frame_id = parent;
    transform.child_frame_id = child;
    transform.transform.translation.x = x;
    transform.transform.translation.y = y;
    transform.transform.translation.z = z;
    transform.transform.rotation.x = q.x();
    transform.transform.rotation.y = q.y();
    transform.transform.rotation.z = q.z();
    transform.transform.rotation.w = q.w();

    broadcaster_ = std::make_shared<tf2_ros::StaticTransformBroadcaster>(*this);
    broadcaster_->sendTransform(transform);
    RCLCPP_INFO(
      get_logger(), "static transform %s -> %s", parent.c_str(), child.c_str());
  }

private:
  std::shared_ptr<tf2_ros::StaticTransformBroadcaster> broadcaster_;
};

int main(int argc, char ** argv)
{
  rclcpp::init(argc, argv);
  rclcpp::spin(std::make_shared<StaticTf>());
  rclcpp::shutdown();
  return 0;
}

7.3动态坐标广播

底盘相对里程计的位置会变化，对应的变换需要持续广播。动态坐标广播 （dynamic transform broadcast）使用 tf2_ros::TransformBroadcaster，按固定周期把最新位姿发布到 /tf。监听者按时间戳在缓存中查找，因此每一帧都要写当前时间。

定时广播

广播者在构造函数中创建，定时器周期由参数给出。定时器回调里组装 TransformStamped，写父坐标系、子坐标系、平移与旋转，再调用 sendTransform。下面的程序沿 x 轴每次前进 step 米，走完 steps 步后保持最后一个位姿， 并用新的时间戳继续广播，方便晚加入的监听者。

时间戳

header.stamp 用 now() 取当前时刻。不要复用 上一帧的时间戳，也不要把时间戳写成 0；时间戳决定这一帧在缓存中的位置， 写错会让查询得到旧数据或插值失败。仿真时节点通常使用 use_sim_time，时间来自 /clock 话题而不是系统时钟。 

#include <chrono>
#include <memory>
#include <string>

#include "geometry_msgs/msg/transform_stamped.hpp"
#include "rclcpp/rclcpp.hpp"
#include "tf2/LinearMath/Quaternion.h"
#include "tf2_ros/transform_broadcaster.h"

class DynamicTf : public rclcpp::Node
{
public:
  DynamicTf()
  : Node("dynamic_tf")
  {
    parent_ = declare_parameter<std::string>("parent_frame", "odom");
    child_ = declare_parameter<std::string>("child_frame", "base_link");
    steps_ = declare_parameter<int>("steps", 5);
    step_ = declare_parameter<double>("step", 0.5);
    const auto period_ms = declare_parameter<int>("period_ms", 500);

    broadcaster_ = std::make_unique<tf2_ros::TransformBroadcaster>(*this);
    timer_ = create_wall_timer(
      std::chrono::milliseconds(period_ms), [this]() { publish_step(); });
  }

private:
  void publish_step()
  {
    const int shown = index_ < steps_ ? index_ : steps_ - 1;

    geometry_msgs::msg::TransformStamped transform;
    transform.header.stamp = now();
    transform.header.frame_id = parent_;
    transform.child_frame_id = child_;
    transform.transform.translation.x = shown * step_;
    transform.transform.rotation.w = 1.0;
    broadcaster_->sendTransform(transform);
    if (index_ < steps_) {
      RCLCPP_INFO(get_logger(), "step %d: x=%.3f", shown, shown * step_);
      ++index_;
    }
  }

  std::string parent_;
  std::string child_;
  int steps_;
  double step_;
  int index_ = 0;
  std::unique_ptr<tf2_ros::TransformBroadcaster> broadcaster_;
  rclcpp::TimerBase::SharedPtr timer_;
};

int main(int argc, char ** argv)
{
  rclcpp::init(argc, argv);
  rclcpp::spin(std::make_shared<DynamicTf>());
  rclcpp::shutdown();
  return 0;
}

7.4监听与点变换

广播者只负责发布变换，使用变换的节点需要监听。TF2 的监听由 tf2_ros::Buffer 与 tf2_ros::TransformListener 组成：监听者订阅 /tf 与 /tf_static，把收到的 变换按时间存进缓冲区；查询时从缓冲区里取。

Buffer 与 Listener

Buffer 在构造时接收节点时钟，缓存一段时间的变换。 TransformListener 在构造时绑定缓冲区与节点，并启动订阅。 监听者应在节点开始自旋前创建；本课的程序在 start() 中创建， 再用定时器反复尝试查询，直到缓存里出现所需变换。

lookupTransform

lookupTransform(target, source, time) 返回把 source 坐标系中的坐标换到 target 坐标系的变换。 第三个参数用 tf2::TimePointZero 表示取最新可用的变换； 指定具体时间时，缓冲区会找最近的两帧并插值。 canTransform 先检查能否查询，避免直接抛异常。

doTransform

tf2::doTransform 把一个带坐标系与时间戳的点、向量或位姿 按变换转换。输入点的 header.frame_id 必须写源坐标系， 输出点的坐标系由变换决定。转换只改变坐标数值，不改变点的物理位置。 

#include <chrono>
#include <cmath>
#include <iomanip>
#include <memory>
#include <string>

#include "geometry_msgs/msg/point_stamped.hpp"
#include "rclcpp/rclcpp.hpp"
#include "tf2_geometry_msgs/tf2_geometry_msgs.hpp"
#include "tf2_ros/buffer.h"
#include "tf2_ros/transform_listener.h"

using namespace std::chrono_literals;

class TfListener : public rclcpp::Node
{
public:
  TfListener()
  : Node("tf_listener")
  {
    target_ = declare_parameter<std::string>("target_frame", "base_link");
    source_ = declare_parameter<std::string>("source_frame", "laser_link");
    px_ = declare_parameter<double>("px", 0.1);
    py_ = declare_parameter<double>("py", 0.2);
    pz_ = declare_parameter<double>("pz", 0.0);
    timeout_ms_ = declare_parameter<int>("timeout_ms", 3000);
    buffer_ = std::make_shared<tf2_ros::Buffer>(get_clock());
  }

  void start()
  {
    listener_ = std::make_shared<tf2_ros::TransformListener>(
      *buffer_, shared_from_this(), false);
    started_at_ = now();
    timer_ = create_wall_timer(200ms, [this]() { try_transform(); });
  }

private:
  void try_transform()
  {
    std::string error;
    if (buffer_->canTransform(target_, source_, tf2::TimePointZero, &error)) {
      try {
        const auto transform = buffer_->lookupTransform(
          target_, source_, tf2::TimePointZero);
        geometry_msgs::msg::PointStamped point;
        point.header.frame_id = source_;
        point.header.stamp = now();
        point.point.x = px_;
        point.point.y = py_;
        point.point.z = pz_;

        geometry_msgs::msg::PointStamped converted;
        tf2::doTransform(point, converted, transform);
        std::cout << "point (" << std::fixed << std::setprecision(3)
                  << px_ << ", " << py_ << ", " << pz_ << ") in " << target_
                  << ": (" << converted.point.x << ", " << converted.point.y
                  << ", " << converted.point.z << ")\n";
      } catch (const tf2::TransformException & exception) {
        std::cout << "lookup failed: " << exception.what() << "\n";
      }
      rclcpp::shutdown();
      return;
    }

    if ((now() - started_at_).seconds() * 1000.0 > timeout_ms_) {
      std::cout << "lookup failed: " << error << "\n";
      rclcpp::shutdown();
    }
  }

  std::string target_;
  std::string source_;
  double px_;
  double py_;
  double pz_;
  int timeout_ms_;
  rclcpp::Time started_at_;
  std::shared_ptr<tf2_ros::Buffer> buffer_;
  std::shared_ptr<tf2_ros::TransformListener> listener_;
  rclcpp::TimerBase::SharedPtr timer_;
};

int main(int argc, char ** argv)
{
  rclcpp::init(argc, argv);
  auto node = std::make_shared<TfListener>();
  node->start();
  rclcpp::spin(node);
  rclcpp::shutdown();
  return 0;
}

终端一用默认参数启动静态广播：base_link 到 laser_link，平移 (0.2, 0.0, 0.3)，偏航角 45°。终端二把一个激光点 (0.1, 0.2, 0.0) 换到 base_link。

7.5时间与异常

TF2 的缓冲区按时间保存变换，查询时刻决定取哪一帧。最新查询用 tf2::TimePointZero，指定时刻用 tf2::timeFromSec 构造时间点。缓存里没有刚好对应时刻的 两帧时，查询会插值；超出缓存范围时，查询抛出 tf2::TransformException。

时间点

tf2::TimePointZero 是一个特殊时间点，表示“取最新可用”。 指定时刻时，时间点与变换的时间戳使用同一时间基准；仿真时间与系统时间 不能混用。查询失败时异常文本会给出请求时刻、最早数据时刻与涉及的两个 坐标系，便于判断是数据没到还是时刻写错。

插值

缓存里有 100 秒与 102 秒两帧，平移分别是 1 与 3。查询 101 秒时， 缓冲区按时间比例插值，得到平移 2。插值只对平移与旋转做线性或球面 插值，不推断机器人的运动模型；两帧之间如果发生突变或跳变，插值结果 不代表真实轨迹。

异常

查询 80 秒时，缓存中最早的数据在 100 秒，缓冲区无法向过去外推，抛出 Lookup would require extrapolation into the past。查询晚于 最新数据太多时，会得到未来的外推错误。程序应捕获 tf2::TransformException，打印原因并决定重试或退出，不要 让异常穿过回调导致进程终止。 

#include <iomanip>
#include <iostream>
#include <memory>
#include <string>

#include "geometry_msgs/msg/transform_stamped.hpp"
#include "rclcpp/rclcpp.hpp"
#include "tf2/exceptions.h"
#include "tf2/time.h"
#include "tf2_ros/buffer.h"

namespace
{
geometry_msgs::msg::TransformStamped make_transform(double seconds, double x)
{
  geometry_msgs::msg::TransformStamped transform;
  transform.header.stamp = rclcpp::Time(static_cast<int64_t>(seconds), 0);
  transform.header.frame_id = "base_link";
  transform.child_frame_id = "marker";
  transform.transform.translation.x = x;
  transform.transform.rotation.w = 1.0;
  return transform;
}

double x_of(const tf2_ros::Buffer & buffer, double seconds)
{
  const auto transform = buffer.lookupTransform(
    "base_link", "marker", tf2::timeFromSec(seconds));
  return transform.transform.translation.x;
}
}  // namespace

int main(int argc, char ** argv)
{
  rclcpp::init(argc, argv);
  auto clock = std::make_shared<rclcpp::Clock>(RCL_ROS_TIME);
  tf2_ros::Buffer buffer(clock);
  buffer.setTransform(make_transform(100.0, 1.0), "course");
  buffer.setTransform(make_transform(102.0, 3.0), "course");

  const std::string mode = argc > 1 ? argv[1] : "all";
  if (mode == "all" || mode == "latest") {
    const auto latest = buffer.lookupTransform(
      "base_link", "marker", tf2::TimePointZero);
    std::cout << "latest: x=" << std::fixed << std::setprecision(3)
              << latest.transform.translation.x << "\n";
  }
  if (mode == "all" || mode == "interp") {
    std::cout << "interpolated at 101s: x=" << std::fixed << std::setprecision(3)
              << x_of(buffer, 101.0) << "\n";
  }
  if (mode == "all" || mode == "outside") {
    try {
      x_of(buffer, 80.0);
      std::cout << "outside: unexpectedly succeeded\n";
    } catch (const tf2::TransformException & exception) {
      std::cout << "outside: " << exception.what() << "\n";
    }
  }
  rclcpp::shutdown();
  return 0;
}
例题 · 缓存查询

程序向缓冲区写入 100 秒与 102 秒两帧，然后分别查询最新、101 秒与 80 秒。第三种查询在缓存范围之外，异常文本被捕获并打印。 

# 当前目录：$HOME/ros2_ws
ros2 run robot_nodes tf_time all
latest: x=3.000
interpolated at 101s: x=2.000
outside: Lookup would require extrapolation into the past.  Requested time 80.000000 but the earliest data is at time 100.000000, when looking up transform from frame [marker] to frame [base_link]

最新查询取 102 秒的 x=3；101 秒位于两帧之间，插值得到 x=2；80 秒早于最早数据，查询失败。异常文本里的两个空格 位于句号之后，是 TF2 自己的格式。

练习 7-9

只查询缓冲区中最新的变换，打印平移的 x。

latest: x=3.000
看答案

tf_time latest 只执行最新查询。 tf2::TimePointZero 让缓冲区取时间戳最大的那一帧， 也就是 102 秒、x=3 的变换。 

# 当前目录：$HOME/ros2_ws
ros2 run robot_nodes tf_time latest
latest: x=3.000
练习 7-10

查询 80 秒处的变换。该时刻早于缓存中最早的数据，捕获异常并打印原因。

outside: Lookup would require extrapolation into the past.  Requested time 80.000000 but the earliest data is at time 100.000000, when looking up transform from frame [marker] to frame [base_link]
看答案

tf_time outside 查询 80 秒。缓存最早的数据在 100 秒， 缓冲区不能向过去外推，抛出 tf2::TransformException； 程序捕获后打印 outside: 与异常文本。 

# 当前目录：$HOME/ros2_ws
ros2 run robot_nodes tf_time outside
outside: Lookup would require extrapolation into the past.  Requested time 80.000000 but the earliest data is at time 100.000000, when looking up transform from frame [marker] to frame [base_link]

异常文本较长，输出块按阅读栏宽度折行；折行只改变排版，不改变异常 文本的内容。

你现在能写什么：按最新时刻或指定时刻查询 TF2 缓存，解释插值与外推的差别，并捕获 TransformException 打印失败原因。
