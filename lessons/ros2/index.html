ROS 2 机器人软件基础

这门课讲怎样用 C++ 在 ROS 2 中组织机器人软件：从工作空间与功能包开始， 依次写节点、话题、服务、参数与动作，再进入执行器、launch、生命周期、 坐标变换、数据记录与测试，最后完成一条可运行的合成巡检流程。

怎么读这门课

全课 11 个部分、51 课，分三档要求。第 0–1 部分是基础， 建议按顺序读完，并亲手构建、运行、修改例子。第 2–8 部分按需阅读： 每一部分开头先列前置课，读完前置再按当前任务选读； 第 6 部分整体选学，可以整部分跳过。 第 9–10 部分是综合练习，建议在读完相关必读课之后再做。

档次部分读到什么程度
基础 第 0–1 部分 按顺序读；每个例子都要构建并运行，参数要能改，输出要能解释
按需 第 2–8 部分 先读该部分列出的前置课，再按任务选读；不要求从头到尾
综合 第 9–10 部分 独立完成一条多节点流程与一组检测题

具体到每一课，用四个词标注要求。会用指能运行、能改参数、能解释输出； 掌握指能独立写出完整节点或配置文件并定位常见错误；看懂指能读懂 代码与参数，不要求独立实现；了解指知道概念、流程与适用场景。

全课有七课标为选学：0.6、5.5、8.3，以及第 6 部分的 6.1–6.4。 选学课可以跳过，也不进入任何部分的前置；第 6 部分整体选学， 可整部分跳过。0.6 需要图形界面，没有图形界面时直接跳过。

环境与工作空间

课程在测试机上使用 Ubuntu 24.04、ROS 2 Jazzy、C++17、colcon 与 ament_cmake。测试机上已装好下列功能包：rclcpp、 std_msgs、example_interfaces、tf2_ros、 rclcpp_components、rclcpp_lifecycle、 rosbag2、turtlesim 与 rqt。 读者的 ROS 2 发行版与安装路径 可能不同，命令中的 /opt/ros/jazzy 要按实际安装位置替换。

$HOME 是当前登录用户主目录（home directory）的环境变量。 若登录用户名为 用户名，$HOME 通常是 /home/用户名；命令里的 $HOME/ros2_ws 就是该目录 下的 ros2_ws。

ROS 2 的接口生成步骤按路径拼接构建目标，工作空间路径里出现中文等非 ASCII 字符时，rosidl_generate_interfaces 会报目标不存在。课程把示例 工作空间复制到 $HOME/ros2_ws 再构建；这个路径只含 ASCII 字符， 所有命令与页面输出都以它为准。源码仍然随课程放在 示例代码/ros2_ws/，复制一次即可。 

# 当前目录：课程目录
mkdir -p $HOME/ros2_ws
cp -r 示例代码/ros2_ws/src $HOME/ros2_ws/
cp 示例代码/ros2_ws/clean.sh $HOME/ros2_ws/
# 进入工作空间
cd $HOME/ros2_ws
source /opt/ros/jazzy/setup.bash
colcon build --symlink-install
source install/setup.bash

需要清理构建产物时，在 $HOME/ros2_ws 中执行下面的命令： 

# 当前目录：$HOME/ros2_ws
bash clean.sh

脚本只删除 build/、install/ 与 log/，删除前会列出目录大小并询问确认。

每开一个新终端，都要先 source /opt/ros/jazzy/setup.bash， 再 source $HOME/ros2_ws/install/setup.bash。前一条提供 ROS 2 本身，后一条提供课程的功能包；两组路径都会保留在当前终端的环境里。

课程统一在独立域中运行，避免与测试机上的其它节点混在一起。两条 环境变量只影响当前终端： 

# 当前目录：任意目录
export ROS_DOMAIN_ID=42
export RCUTILS_CONSOLE_OUTPUT_FORMAT='[{severity}] [{name}]: {message}'

第一条把节点放进 42 号域；第二条去掉日志里的时间戳，页面上的输出才能逐行 对照。格式串只改变显示，不改变日志级别与内容；需要时间戳时去掉它即可。

每页怎么读

课里的 C++ 例子都是完整程序，代码块后紧跟真实输出；涉及多个终端的例子 会写明哪个终端先启动。练习先自己写，卡住了再展开答案。答案里的程序与 页面上的代码逐行一致，输出由脚本重新运行得到。练习的判据是逐字符一致， 差一个空格也算不同。

示例与答案

示例源码在 示例代码/ros2_ws/src/，按功能包分成三部分： robot_interfaces 放消息与服务定义，robot_nodes 放 C++ 节点，robot_bringup 放启动文件与配置。 练习答案在 示例代码/答案/，每个练习一个目录， 目录里的脚本会构建并运行该练习的答案。

第 0–1 部分除 0.6 外只使用终端输出，不需要图形界面。0.6 观察小海龟时 会出现图形窗口；没有图形界面时跳过这一课，后续必读课不依赖它。 所有输出都在 ROS_DOMAIN_ID=42 与去掉时间戳的日志格式下取得， 路径中的个人目录在页面上写成 $HOME 或 $WORKSPACE。

关于输出里的数字

带有 data-label="真实输出" 的块来自一次实际运行。 计时、发现与频率数值会随机器负载变化，页面会在块前说明哪几位不固定； 标为“预期输出”的练习结果则要求逐字符一致。

第 0 部分 · 开始

基础，6 课，无前置。只要求能读懂 C++ 基本语句与类。 这一部分把工作空间、第一个节点、命名、功能包与命令行工具走通； 0.6 为选学的小海龟观察。

  • 0.1 课程地图与工作空间 课程目录；src/build/install/log；colcon build；域号与日志格式
  • 0.2 第一个节点 rclcpp::init、spin、shutdown；定时器；日志；自行停止
  • 0.3 节点名、命名空间与重映射 完全限定名；__node、__ns；ros2 node list/info
  • 0.4 功能包、依赖与构建 package.xml；CMakeLists.txt；接口包的构建顺序
  • 0.5 命令行工具与运行观察 ros2 pkg、ros2 run、ros2 node、ros2 interface
  • 0.6 小海龟：观察现成节点（选学） turtlesim 的话题、服务与动作；读一次位姿

第 1 部分 · 话题

基础，6 课，前置 0.1–0.5。这一部分从发布者与订阅者开始， 讲清自定义消息、QoS、多节点通信与话题诊断；读完能写一个 由多个节点组成的小型话题系统。

  • 1.1 发布者 create_publisher；消息字段；定时发布与停止
  • 1.2 订阅者 create_subscription；共享指针参数；启动顺序
  • 1.3 自定义消息 msg/Target.msg；rosidl_generate_interfaces；生成头文件
  • 1.4 QoS 可靠性、历史、持久性；兼容性；topic info --verbose
  • 1.5 多发布者、多订阅者与消息筛选 命名空间；端点计数；按字段与前缀筛选
  • 1.6 话题诊断 list -t、info、echo、hz；排查顺序

第 2 部分 · 服务与参数

按需，5 课，前置 1.1–1.3。这一部分从一次请求与响应开始， 讲清自定义服务、参数与参数文件；读完能写服务端与客户端， 并用参数文件和命令行控制节点行为。

  • 2.1 服务端 create_service；请求与响应；回调参数
  • 2.2 客户端 create_client；wait_for_service；async_send_request
  • 2.3 自定义服务 .srv；rosidl_generate_interfaces；输入校验
  • 2.4 参数 declare_parameter；ros2 param；设置回调
  • 2.5 参数文件与动态修改 YAML 层级；--params-file；命令行覆盖；dump

第 3 部分 · 动作

按需，5 课，前置 2.1–2.3。这一部分定义动作接口，写服务端与客户端， 处理取消与超时，最后用命令行观察目标、反馈与结果。

  • 3.1 动作接口与目标、反馈、结果 .action 三段；生成类型；interface show
  • 3.2 动作服务端 create_server；三个回调；反馈；最终结果
  • 3.3 动作客户端 async_send_goal；反馈回调；async_get_result
  • 3.4 取消、超时与抢占 async_cancel_goal；is_canceling；新目标策略
  • 3.5 动作诊断 action list/info/send_goal；排查顺序

第 4 部分 · 执行器与回调

按需，4 课，前置 1.1–1.2、2.2。回调队列、单线程与多线程执行器、 回调组与耗时任务。

  • 4.1 执行器与回调队列 执行器；回调队列；一个执行器里的两个节点
  • 4.2 单线程与多线程执行器 SingleThreadedExecutor、MultiThreadedExecutor；回调组的影响；重叠测量
  • 4.3 回调组与并发 互斥组；可重入组；怎样选组
  • 4.4 耗时任务与执行器 阻塞回调；工作线程；边界

第 5 部分 · Launch 与组合
