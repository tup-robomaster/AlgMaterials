其他基础

这门课教的是程序之外、每天都要用到的基础： 在 Linux 里找文件、用 Git 记录改动、读懂项目里的配置文件、 用线性代数描述坐标与变换、配置相机、把数据接到网络服务上。

怎么用这份材料

这门课不要求按顺序阅读。八个部分按主题分开，每一部分尽量自成一页。 可以按当前任务跳读：今天要配相机，就先读相机那一部分； 今天要提交代码，就先读 Git 那一部分。第 0 部分只需要读一遍， 知道每一部分讲什么、哪些内容只要看懂即可。

第一次接触这些内容时，建议按 0 → 1 → 2 → 3 → 4 → 5 → 6 → 7 的顺序走一遍； 已经会用 Linux 和 Git 的读者，可以直接跳到需要的部分。 第 7 部分放在最后，是把前面几部分串起来的综合操作。

要求分层

不是每一部分都要背下来。每一部分开头都会写明要求，按下面四档理解：

要求部分读到什么程度
会用 第 1、2 部分 跟着做一遍，知道命令和流程怎么用；不要求背参数表
看懂 第 3、5 部分 能读懂项目里的文件、能判断相机参数的含义；不要求在没有硬件时动手配置
了解 第 6 部分、模型文件 知道它是什么、由哪些部分组成、通常怎么用；给最小示例，跑通并读懂即可
掌握 + 练习 第 4 部分 会算、会用；每课 3 道练习，这是全课唯一安排成体系练习的部分
跟做 第 7 部分 按步骤完成两组小任务；不设答案
关于「了解」

标为「了解」的内容不是不重要，而是不要求独立搭建或深入实现。 例如网络服务部分，读者需要能跑通一个最小示例、读懂它由哪几段组成， 但不要求从零写出一个完整的服务端。等实际任务需要时，再按那时的文档深入。

每页怎么读

第 1、2 部分用「跟着做」的方式写：先给一组命令，再给这台机器上运行出来的真实输出； 第 3 部分起以读懂为主，例子仍然可以运行，但不要求逐条输入。 练习目录的准备、终端输出的对照方法与示例代码的位置，见 0.2 环境与用法。

拓展内容

下面这些内容与算法组的日常工作有关，但不在这门课的范围里。 需要时自行搜索学习，课里不放外部链接：

  • 多线程与并发——一个程序同时做几件事，以及共享数据的保护。
  • 互斥锁——多个线程共享数据时，保证同一时刻只有一个线程修改它，避免结果互相覆盖。
  • gdb 调试——让程序停下来，逐行查看变量与调用栈。
  • 正则表达式——用模式匹配文本，写日志过滤与批量替换时常用。
  • Docker——把程序和它的运行环境一起打包，换一台机器也能运行。
  • 计算机组成原理——指令、寄存器、缓存与内存层次，理解程序为什么快或慢。

这些内容不影响阅读本课。读到相关句子时知道有这件事、需要时能搜索到入口即可。

第 0 部分 · 开始

不教具体命令。说清楚这门课讲什么、怎么读，以及练习环境怎么准备。

  • 0.1 这门课讲什么 六类基础各自的用途、本课用的语言、与学校课程的关系
  • 0.2 环境与用法 检查 python3、git、g++；准备练习目录；第一次运行自检脚本

第 1 部分 · Linux 文件结构与基础命令

七个部分里最先要用到的一门。目标是用会，不是背命令。

  • 1.1 Linux 的目录结构 从根目录开始，认清 /home、/etc、/dev 这些目录各放什么；绝对路径与相对路径
  • 1.2 路径与文件操作 pwd、ls、cd、mkdir、cp、mv、rm、ln；隐藏文件、通配符、带空格的文件名
  • 1.3 查看、搜索与统计 cat、less、head、tail、grep、find、which、file、wc、sort、uniq
  • 1.4 权限、用户与 sudo ls -l 每一列的含义；读、写、执行权限；chmod 的两种写法；脚本为什么需要执行权限
  • 1.5 进程、前后台与信号 ps、top、kill；Ctrl+C、Ctrl+Z、jobs、bg、fg、&、nohup
  • 1.6 管道、重定向与环境变量 |、>、>>、<、2>、2>&1、tee；PATH 与退出码
  • 1.7 软件安装、压缩包与远程连接 apt、tar、zip、ssh、scp、rsync 的常见用法

第 2 部分 · Git 基础命令及规范

从仓库与提交讲到分支、远端和冲突处理，最后落到团队规范。要求是会用。

  • 2.1 仓库、暂存区与提交 git init、status、add、commit、log、diff、show；工作区、暂存区与本地仓库
  • 2.2 分支与合并 branch、switch、merge；快进与三方合并；删除分支；log --graph
  • 2.3 远程仓库与 SSH remote、clone、fetch、pull、push；origin；SSH 密钥生成与登记
  • 2.4 冲突、回退与撤销 冲突标记与解决；restore、reset --soft/--mixed/--hard、revert、stash；哪些操作会丢内容
  • 2.5 提交信息规范 一次提交只做一件事；标题写做什么、正文写为什么；常见类型前缀；提交前自查
  • 2.6 分支规范与 .gitignore 主分支、功能分支、修复分支；合并请求与代码评审；忽略构建产物、日志、模型权重与密钥；误提交后的处理

第 3 部分 · 常见文件

项目里每天读写的几种文件。要求是看懂：知道格式、能查错、出问题时先看哪里。

  • 3.1 文本与编码 字节与字符；ASCII、UTF-8、GBK；BOM、CRLF；file、od、iconv
  • 3.2 JSON 对象、数组、字符串、数字、布尔值与 null；嵌套配置；json.load；json.tool 查错
  • 3.3 YAML 用缩进表示层级；映射、列表、注释、字面块；与 JSON 的对应关系；常见解析差异
  • 3.4 Markdown 标题、段落、列表、强调、链接、代码块与表格；README 的常见结构
  • 3.5 Shell 脚本 shebang 与执行权限；变量、位置参数、引号；条件、循环与退出码；写脚本的习惯
  • 3.6 模型文件 .pt、.onnx、.engine 的用途与转换链；engine 的环境绑定；反序列化的风险
  • 3.7 日志 一行日志的组成；级别；tail、grep、sed、awk 定位问题；轮转与长期保存

第 4 部分 · 线性代数基础

算法组日常用到的线性代数。八课，每课 3 道练习，共 24 道；例题与答案都用 C++ 写成，另附 Python 版代码。

  • 4.1 向量与矩阵★ 有动画 向量与分量、加法与数乘、内积与长度、矩阵乘法、单位矩阵、乘法顺序
  • 4.2 行列式★ 有动画 2×2 与 3×3 的算法、面积与体积的几何意义、行列式为 0 与不可逆、三角形面积
  • 4.3 秩 线性组合与张成、线性相关与无关、高斯消元与主元、秩与方程组的解
  • 4.4 转置与逆 转置的性质、逆矩阵、2×2 逆公式、高斯—约当求逆、正交矩阵与旋转
  • 4.5 坐标变换★ 有动画 坐标系与基、旋转、平移与齐次坐标、变换的复合顺序与逆变换
  • 4.6 特征值与特征向量★ 有动画 定义、2×2 的求法、特征向量、对称矩阵的对角化、幂迭代
  • 4.7 最小二乘★ 有动画 超定方程组与残差、正规方程、直线拟合、过原点拟合与预测、数值注意
  • 4.8 奇异值分解（选学）★ 有动画 定义与几何意义、与 AᵀA 的关系、2×2 的算法、低秩近似、伪逆与条件数

第 6 部分 · 网络服务

以了解为主。六课各有一个只用 Python 标准库的示例，只绑定回环地址，不连接外部网络，不打开真实串口。要求是跑通并读懂 6.4 与 6.5 的两个本地服务，其余例子能对照输出理解。

  • 6.1 IP 与端口 回环地址、端口与监听、连接由四元组确定、一次本机连接
  • 6.2 TCP 与 UDP TCP 的字节流、消息边界、UDP 数据报、协议选择、两个例子
  • 6.3 HTTP 与 JSON 请求与响应、方法与状态码、首部、JSON、服务端检查、GET 与 POST
  • 6.4 本地服务 常驻服务、并发上限与超时、错误处理与安全首部、运行与查看
  • 6.5 串口到网页 串口与伪终端、按行读取、校验与网页显示、停止时的清理
  • 6.6 排错 连接被拒绝、端口占用、接收超时、HTTP 状态与 JSON 错误、五种错误
