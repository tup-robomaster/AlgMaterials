第 0 部分

开始

这一部分不教具体命令。它回答三个问题：这门课讲什么、应该怎么读、 练习环境怎么准备。读完这一部分，读者应当知道每一部分解决什么问题， 哪些内容需要动手，哪些只需要看懂。

0.1这门课讲什么

这门课的主体是下面六类基础，分别对应第 1–6 部分；第 0 部分说明读法， 第 7 部分是综合操作。各部分的课表、要求与阅读顺序见 课程首页。

一个算法组的成员在写代码之前和写代码之后，都会反复用到下面六类内容。 这些内容不涉及语言语法本身，而是程序之外、每天都要用到的基础。

六类基础

  1. Linux 文件结构与基础命令。代码放在哪个目录、怎么找文件、 怎么复制和删除、怎么查看权限和进程、怎么把几条命令接起来。 这些操作每天都要用，不熟会直接影响效率。
  2. Git 基础命令及规范。怎样把改动记录成一次提交、怎样开分支、 怎样和远程仓库同步、冲突了怎么处理、提交信息怎么写。 这一部分不仅讲命令，也讲团队协作时的规范。
  3. 常见文件。JSON、YAML、Markdown、Shell 脚本、日志， 以及 PyTorch 的 .pt、ONNX 的 .onnx、 TensorRT 的 .engine 这三类模型文件。 目标是能读懂项目里的配置文件、能改简单的脚本、知道模型文件怎么转换。
  4. 线性代数基础。向量、矩阵、行列式、秩、转置与逆、坐标变换、 特征值与最小二乘、奇异值分解。相机投影、机器人位姿、点云配准、 标定，背后都是这些内容。这是全课唯一安排成体系练习的部分。
  5. 相机配置。成像原理、传感器、镜头、曝光、像素格式与接口、 采集流程、标定。目标是看懂相机参数表、能按拍摄范围选镜头、 能判断图像为什么过曝或丢帧。
  6. 网络服务。IP 与端口、TCP/UDP、HTTP 与 JSON、本地服务， 以及把串口收到的数据接到网页或 TCP 端口上。
与学校课程的关系

本课按算法组的实际使用进行组织，内容的选取范围、先后顺序、符号习惯与讲解方式 都可能与学校课程不同，也不覆盖学校课程的全部内容。学校课程有明确要求时， 以学校课程为准；本课作为动手与查阅的参考。

本课用的语言

这门课不展开语言语法。第 4 部分的例子与练习答案用 C++ 写成；其余需要写 程序的地方多数用 Python 标准库或 Shell 脚本，因为它们短、可以直接在终端里 运行；相机 SDK 部分只讲调用流程，不要求安装 SDK。遇到不认识的写法， 查阅相应的语言资料即可，能知道它在做什么就可以继续往下读。

0.2环境与用法

这一课把练习环境准备好。后面的「跟着做」都从同一个练习目录出发， 不会碰到读者自己的文件。

确认工具

本课按 Ubuntu 24.04 写。其他常见 Linux 发行版的命令基本一致； Windows 的路径与终端不同，需要先准备一个 Linux 环境。 先确认四样工具都在： 

python3 --version
git --version
g++ --version
bash --version

这台机器上的输出如下。版本号可能和读者的不同，不同是正常的； 只要没有出现「未找到命令」，就可以继续。 

Python 3.12.3
git version 2.43.0
g++ (Ubuntu 13.3.0-6ubuntu2~24.04.1) 13.3.0
Copyright (C) 2023 Free Software Foundation, Inc.
GNU bash，版本 5.2.21(1)-release (x86_64-pc-linux-gnu)

四样工具分别负责：Python 用来跑第 4 部分以外的示例；Git 用来做版本管理； g++ 用来编译第 4 部分的 C++ 例子与练习答案；Bash 是终端里 执行命令的 shell。本课不要求安装新软件；g++ 在 C++ 课里已经 用过，如果那门课还没有配置好，先按 C++ 课第 0 部分的方法确认编译器。

准备练习目录

打开终端，进入这一页所在的文件夹（也就是 lessons/other_basics）， 依次执行下面三行： 

rm -rf /tmp/other-basics
mkdir -p /tmp/other-basics
cp -r 示例代码 /tmp/other-basics/

然后进入练习目录，确认当前位置： 

cd /tmp/other-basics/示例代码
pwd
/tmp/other-basics/示例代码

这三行命令做的是：删除上一次留下的练习副本、新建一个空目录、 把课程里的示例文件复制进去。之后所有「跟着做」都在 /tmp/other-basics/示例代码 下面进行。

注意 rm -rf

第一行会删除 /tmp/other-basics 整个目录，不会询问确认。 这条命令只对练习副本使用；不要把路径改成自己的代码目录、 主目录或者任何含有重要文件的位置。rm -rf 删除的文件不进回收站， 删掉之后无法从终端恢复。

如果后面哪一课把练习目录改乱了，或者重启过电脑（/tmp 里的内容可能被清空），回到这一页重新执行这三行，再重新进入练习目录即可。 课程文件夹里的原始示例不会被改动。

怎么看「跟着做」

第 1、2 部分的每一课都有若干组「跟着做」；第 3 部分的例子也可以运行， 但不要求逐条输入。每组先给一段命令，再给这台机器上运行出来的输出： 

cd /tmp/other-basics/示例代码/1.2-路径与文件
ls -1
data
notes.txt

读者输入第一段命令，屏幕上应当出现第二段的内容。命令块里一行一条命令， 不需要输入提示符；输出块里的空格、空行、标点都与终端一致。

有三类内容每次都会不同，课里会单独说明：

  • 版本号，例如 Python 3.12.3 中的 3.12.3；
  • 进程号，例如 ps 输出里的 PID 一列；
  • 用户名、主机名、日期与时间。

其余内容按原样对照。输出对不上时，先看当前目录是不是正确： pwd 应当显示 /tmp/other-basics/示例代码 下面的某一个课目录。

第一次运行

练习目录里有一个自检脚本。它把第 1–7 部分的示例再跑一遍， 逐项对照课里写的输出： 

cd /tmp/other-basics/示例代码
bash 验证.sh

完整输出有一百多行，每一项都以 [通过] 开头。 最后两行应当是： 

════════════════════════════════════════════
 汇总：179 项通过，0 项不对

出现 [不对] 时，脚本会把「预期」和「实际」并排打印出来。 先检查练习目录是不是从这一页重新复制出来的； 如果仍然不对，说明课程里的示例与读者机器上的工具版本有差异， 把那一项的实际输出记下来，后面的课会讲怎样判断这类差异。

脚本只读课程里的示例，所有改动都发生在 /tmp 下临时建出的副本里， 跑完会把这个临时目录删掉；它不联网，也不需要 sudo。

你现在能做什么：确认四样工具都在、准备好练习目录、 运行自检脚本并看懂结果。从下一部分起按主题读具体的文件与命令。
