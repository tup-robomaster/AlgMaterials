5.1成像原理

相机把三维场景记录成二维像素阵列，第一步是投影。投影决定三维点落在 哪个像素、视场有多大，也决定为什么单张图像无法直接给出距离。这一课 先说明工业相机与常见单反相机的区别，再建立针孔模型，说明内参、 视场角与尺度不确定。

工业相机与常见单反相机的区别

工业相机面向测量、检测与自动化，常见单反相机面向摄影。两者都能 成像，但设计目标不同：前者优先保证每次采集的结果一致、数据可追溯、 能被程序精确控制；后者优先保证单张照片的观感与操作便利。

小孔与针孔模型

暗箱的一侧开一个小孔，光线沿直线穿过小孔，在后壁形成倒立的像，这是 小孔成像。孔太大时，来自物体不同位置的光在小孔处混合，像会模糊； 孔太小时，进入的光很少，衍射又会限制清晰度。实际相机用镜头汇聚光线， 用光圈限制通光口径，用传感器记录像。

分析成像时，常把镜头简化成一个点，叫光心（optical center），并假设 所有光线都经过光心，像平面在光心后方距离 f 处。 这个简化模型叫针孔模型（pinhole model），f 是焦距 （focal length）。经过光心并垂直于像平面的直线叫光轴（optical axis）； 光轴与像平面的交点叫主点（principal point）。真实镜头有厚度、有畸变， 针孔模型只是一个近似；标定之后，可以用针孔模型加畸变项来描述。

下图是针孔模型的侧视示意图。物高 H 固定为 100 毫米，物距 Z 固定为 2000 毫米；滑块改变焦距 f，像高 h 与像素高随之改变。图中纵向尺寸与 横向距离都经过压缩，具体数值以读数为准。

四个坐标系

描述投影要区分四个坐标系。世界坐标系（world coordinates）是场景的 参考系，单位可以是毫米或米。相机坐标系（camera coordinates）的原点在 光心，Z 轴沿光轴指向场景，X 轴与 Y 轴平行于像平面。图像平面坐标系 （image coordinates）是像平面上的二维坐标，原点在光轴与像平面的交点， 单位是毫米。像素坐标系（pixel coordinates）的原点在图像左上角， u 轴向右，v 轴向下，单位是像素。

本课采用 X 向右、Y 向下、Z 向前的相机坐标系，像素原点在左上角。 不同文档与程序库可能采用 Y 向上或其他约定，投影公式的符号会随之改变。 读参数表、调用接口或对照别人的代码时，先确认坐标约定，再代入公式。

世界坐标系到相机坐标系的变换由旋转 R 与平移 t 组成，叫外参（extrinsic parameters）。相机坐标系到像素坐标系的变换由 焦距、主点与像元尺寸决定，叫内参（intrinsic parameters）。外参与内参 都在标定一课展开，这里先建立名字与作用。

投影公式与内参

设相机坐标系中一个点的坐标为 (X, Y, Z)，且 Z > 0。由相似三角形，它在像平面上的物理坐标为 x = f X / Z、y = f Y / Z。若像元的物理宽度为 p_x、高度为 p_y，主点的像素坐标为 (c_x, c_y)，则像素坐标为

u = f X / (p_x Z) + c_x = f_x X / Z + c_x， v = f Y / (p_y Z) + c_y = f_y Y / Z + c_y。

其中 f_x = f / p_x、f_y = f / p_y 是以像素为 单位的焦距。两个方向通常接近相等；像元不是正方形或制造有偏差时会有 少量差异。把上式写成矩阵： 

K = [ f_x   0   c_x ]
    [  0   f_y  c_y ]
    [  0    0    1  ]

[u, v, 1]ᵀ ~ K [X, Y, Z]ᵀ

符号 ~ 表示两边相差一个非零倍数；把右边的结果除以第三个 分量 Z，就得到像素坐标。矩阵 K 叫内参矩阵 （intrinsic matrix）。这里用到了齐次坐标：给向量补一个 1，把缩放、 平移与投影写成矩阵乘法；线性代数部分讲过这种写法。

以本课反复使用的相机 A 为例：分辨率为 1280×1024，像元为 10 微米， 焦距为 8 毫米，主点在图像中心。像元宽度 p_x = 0.010 毫米， 所以 f_x = 8 / 0.010 = 800 像素；c_x = 640、 c_y = 512。若点落在光轴后方或 Z = 0， 投影没有意义，程序里要先检查 Z > 0。

下图把同一个点依次放在世界、相机、图像、像素四个坐标系里，用 「下一步」切换。相机坐标系采用 X 向右、Y 向下、Z 向前；像素坐标系 的原点在图像左上角，u 向右，v 向下。例子取点 (300, −200, 2000) 毫米，f_x = f_y = 800、 c_x = 640、c_y = 512，最后得到像素坐标 (760, 432)。

在 OpenCV 中，图像数组的第一行第一列（下标 [0][0]）就是 左上角的像素；像素坐标 (u, v) 通常指该像素的中心。 不同库的坐标约定可能不同，代入公式前先确认。

视场角与视场范围

视场角（field of view，FOV）是相机能看到的角范围。传感器某个方向的 物理尺寸为 s，焦距为 f，该方向的视场角为

θ = 2 arctan(s / (2 f))。

水平方向用传感器宽度，垂直方向用高度，对角线方向用对角线长度。 焦距越长，视场角越小；传感器越大，视场角越大。视场角描述的是角度， 不是某个距离上的宽度。

在距离光心 d 处、与光轴垂直的平面上，视场范围的宽度为 W = 2 d tan(θ / 2)。当 d 远大于 f 时，可以近似为 W = s d / f。这个近似式在选镜头时很常用： 已知传感器宽度、工作距离与要求的拍摄宽度，就能估算所需焦距。

相机 A 的传感器宽 12.8 毫米、高 10.24 毫米，焦距 8 毫米，水平视场角 约为 77.32°，垂直视场角约为 65.24°。在 2 米处，水平视场范围约为 3200 毫米；这与 12.8 × 2000 / 8 = 3200 一致。

下图用滑块改变焦距 f 与距离 Z，显示水平视场角与距离 Z 处的视场宽度。 传感器宽度固定为 12.8 毫米；图中横向距离经过压缩，角度与宽度以读数为准。

单张图的尺度不确定

投影把三维点压到二维像素，深度信息丢失。沿同一条从光心出发的射线， 所有点都落在同一个像素上：距离 2 米、大小 300 毫米的物体，与距离 4 米、大小 600 毫米的物体，在图像上占据的像素数相同。仅凭一张图像， 无法判断物体是近而小，还是远而大。这叫尺度不确定（scale ambiguity）。

要恢复尺寸或距离，需要额外的信息：已知物体所在平面到相机的距离、 已知物体尺寸、双目或多目视觉、结构光或飞行时间测距，或者让相机运动。 在固定工作距离、物体位于与光轴垂直的平面上的测量任务中，可以用 Z / f_x 毫米每像素把像素差换算成毫米差；距离一变， 这个比例也随之改变。

真实镜头还会让直线在图像中弯曲，这叫畸变（distortion）。针孔模型 投影出的直线仍然是直线；有畸变的图像要先校正，再做测量或标定。 畸变的描述与校正放在标定一课。

例子：投影与视场

下面这段程序用相机 A 的内参，把三个相机坐标系中的点投影到像素坐标， 再按传感器尺寸计算水平与垂直视场角。三个点中，第一个与第三个都在 光轴上，只是距离不同；第二个偏离光轴。 

cd /tmp/other-basics/示例代码/5.1-成像原理
python3 projection.py
# 针孔模型：把相机坐标系里的三维点投影到像素坐标。
import math

fx = 800.0
fy = 800.0
cx = 640.0
cy = 512.0
sensor_w = 12.8
sensor_h = 10.24
focal = 8.0

points = [
    (0.0, 0.0, 2000.0),
    (300.0, -200.0, 2000.0),
    (0.0, 0.0, 4000.0),
]

for x, y, z in points:
    u = fx * x / z + cx
    v = fy * y / z + cy
    print(f"({x:.0f}, {y:.0f}, {z:.0f}) mm -> 像素 ({u:.3f}, {v:.3f})")

fov_x = 2.0 * math.degrees(math.atan(sensor_w / (2.0 * focal)))
fov_y = 2.0 * math.degrees(math.atan(sensor_h / (2.0 * focal)))
print(f"水平视场角 = {fov_x:.3f}°")
print(f"垂直视场角 = {fov_y:.3f}°")
(0, 0, 2000) mm -> 像素 (640.000, 512.000)
(300, -200, 2000) mm -> 像素 (760.000, 432.000)
(0, 0, 4000) mm -> 像素 (640.000, 512.000)
水平视场角 = 77.320°
垂直视场角 = 65.238°

第一个点 (0, 0, 2000) 在光轴上，落在主点 (640, 512)；第三个点 (0, 0, 4000) 也在光轴上， 距离更远，仍落在同一个像素。这两个结果直接显示了尺度不确定： 仅看像素坐标，无法区分 2 米与 4 米。

第二个点的 X = 300、Z = 2000，所以 u = 800 × 300 / 2000 + 640 = 760；Y = -200 使 v = 800 × (-200) / 2000 + 512 = 432。负的 Y 在图像上方， 因为本课的 v 轴向下。视场角由 12.8 毫米与 8 毫米算出，水平约 77.32°， 垂直约 65.24°。

你现在能做什么：写出针孔模型的投影公式，说明内参矩阵各元素的 含义，由传感器尺寸与焦距计算视场角，由工作距离与焦距估算视场范围， 并解释为什么单张图像不能直接给出距离。

5.2传感器

传感器把落在像平面上的光变成电信号，再变成数字图像。参数表上的 分辨率、像元尺寸、靶面、快门与位深，决定了图像能分辨多小的细节、 在暗处是否够用、运动物体是否会变形，以及每帧要传多少数据。

光到电

传感器的基本单元是像素。像素中的光电二极管吸收光子，产生电子—空穴对； 在曝光时间内，电荷不断累积，累积量与光强和曝光时间的乘积近似成正比。 读出电路把电荷转换成电压，模数转换器（ADC）再把电压转换成数字值。 像素值在饱和之前与曝光量近似线性；达到满阱容量（full well capacity） 之后，再多的光也不会让数值继续增加。

CMOS 传感器在每个像素内集成放大与读出电路，可以逐像素或逐行读出； CCD 传感器把电荷逐行转移到一个输出放大器再读出。工业相机目前以 CMOS 为主，全局快门的 CMOS 常用于运动物体与测量。量子效率、满阱容量、 读出噪声与暗电流是评价传感器的重要指标；温度升高时暗电流增大， 长时间曝光或低光场合会使用制冷相机。

分辨率与像元尺寸

分辨率是图像的像素数，写成宽×高，例如 1280×1024；总像素数除以一百万 就是常说的百万像素。分辨率还可以通过感兴趣区域（region of interest， ROI）、像素合并（binning）与降采样（decimation）改变。ROI 只读出 图像的一部分，能提高帧率；像素合并把相邻像素的电荷合在一起，能提高 灵敏度，但降低空间分辨率。

像元尺寸（pixel pitch）是相邻像素中心的距离，常用微米表示。像元越小， 同样靶面上能排下更多像素，空间分辨率越高；但每个像素接收的光更少， 满阱容量更小，噪声相对更大，对镜头的分辨能力要求也更高。像元小于 镜头能分辨的细节时，继续增加像素不会带来更多有效信息，只会增加数据量。

靶面尺寸

靶面（sensor format）是传感器的感光区域，物理尺寸等于分辨率乘以像元 尺寸。参数表常写 1/1.8 英寸、2/3 英寸、1 英寸这类格式名。这些名称 来自早期的摄像管尺寸，并不等于传感器实际对角线的长度；不同厂商的 同一格式名，实际宽高也可能不同。选镜头与算视场时，必须以参数表给出的 宽度、高度或对角线为准，不能只按格式名推算。

镜头有一个成像圆（image circle），其直径必须覆盖传感器的对角线。 成像圆小于传感器对角线时，图像四角会变暗，甚至没有成像。相机 A 的 靶面为 12.8×10.24 毫米，对角线约 16.39 毫米；相机 B 的靶面为 8.446×7.066 毫米，对角线约 11.01 毫米。选镜头时要让镜头的成像圆 至少达到这个数值。

快门

全局快门（global shutter）让所有像素在同一段时间内曝光，曝光结束后 再统一读出。运动物体在图像中不会因为逐行曝光而产生倾斜。卷帘快门 （rolling shutter）逐行开始曝光、逐行读出，同一帧的不同行对应不同时刻； 拍摄运动物体时，竖直边会倾斜，快速闪烁的光源会形成明暗条纹。

卷帘快门结构简单、成本低，静态场景可以使用；测量运动物体、使用频闪 光源或需要多相机同步时，应选择全局快门。无论哪种快门，曝光时间与读出 时间之和都不能超过帧周期，否则实际帧率会下降。

彩色、位深与动态范围

黑白相机每个像素只记录亮度，灵敏度高，数据量小，适合测量与检测。 彩色相机在像素上覆盖拜耳滤色阵列（Bayer color filter array）， 常见排列为 RGGB；每个像素只得到红、绿、蓝中的一种颜色，主机再通过 去马赛克（demosaicing）插值出三通道图像。彩色处理会降低有效分辨率 与灵敏度，数据量也更大；需要颜色判断时用彩色，只测形状与位置时用黑白。

位深是每个像素数值的二进制位数，常见 8、10、12、16 位。8 位图像的 数值范围是 0 到 255，10 位是 0 到 1023。位深越高，能记录的明暗层次 越多。动态范围是传感器能同时记录的最亮与最暗信号之比，通常用分贝 或档表示；它受满阱容量与读出噪声限制。像素值在饱和后会被截断， 过曝区域的高光细节无法恢复。

5.3镜头

镜头把场景成像到传感器上。焦距决定视场，接口决定能否装上，光圈决定 进光量与景深，景深决定多大距离范围内的物体能保持清晰。这一课按选型的 顺序说明这些参数，并给出一个完整的选镜头算例。

焦距与视场

焦距是镜头对无穷远物体对焦时，光心到像平面的距离。拍摄有限距离的 物体时，像平面要向后移动，移动由对焦环完成。焦距越长，视场越窄， 同样距离上的物体成像越大；焦距越短，视场越宽。视场角与视场范围的 公式在成像原理一课已经给出，这里直接使用。

放大倍率（magnification）是像的大小与物的大小之比。薄透镜近似下， m = f / (d - f)，其中 d 是物距；当 d 远大于 f 时，m ≈ f / d。 也可以用传感器宽度除以视场宽度估算。放大倍率决定每像素对应多少毫米： 视场宽度 / 像素数。

接口与法兰距

镜头接口决定镜头能否装在相机上，以及传感器到镜头安装面的距离。 C 口的法兰距为 17.526 毫米，CS 口为 12.5 毫米。C 口镜头装到 CS 口 相机上，需要加 5 毫米接圈；CS 口镜头装到 C 口相机上，无法对无穷远 对焦，强行安装还可能碰到传感器。选型时要同时确认接口类型与法兰距。

常见的接口还有 M12、M42、F 口等。M12 板载镜头体积小，常用于嵌入式 设备；F 口多见于较大靶面的工业相机。除了接口，还要确认镜头的成像圆 能覆盖传感器对角线、镜头分辨率能满足像元尺寸、锁紧方式适合现场振动。 接口不对时，不要用转接环强行改变法兰距，除非转接环明确补偿了距离。

光圈

光圈是镜头内可调的通光孔径。光圈值用 F 数表示：F = f / D， 其中 D 是孔径的直径。常见档位为 1.4、2、2.8、4、5.6、8、 11、16；每增大一档，F 数乘以约 1.414，孔径面积减半，进光量减半。 F 数越小，光圈越大，进光越多，景深越浅；F 数越大，光圈越小，进光越少， 景深越深。

光圈还会影响成像质量。光圈全开时，像差与暗角较明显；光圈收得太小， 衍射又会让图像变软。多数镜头在中等光圈（例如 F4 到 F8）附近分辨率 较好。标定与测量期间应固定光圈，避免景深、畸变与亮度发生变化。

景深

景深（depth of field）是物体前后能保持可接受清晰度的距离范围。 「可接受」用一个允许的弥散圆（circle of confusion，CoC）衡量： 物点没有精确对焦时，在像平面上形成一个圆斑，圆斑小于允许直径时， 人眼或算法仍认为它清晰。CoC 常按像元尺寸选取，例如 1 到 2 个像元； 测量任务要求越高，CoC 应越小。

设焦距为 f、光圈值为 F、对焦距离为 s、允许弥散圆为 c，单位统一为毫米。 超焦距（hyperfocal distance）为

H = f² / (F c) + f。

景深近界与远界分别为 s_near = H s / (H + (s - f))、 s_far = H s / (H - (s - f))。当 s 达到 超焦距时，远界为无穷远。景深随光圈收小（F 增大）、焦距缩短、工作距离 增大而变深；这些公式基于薄透镜与对称光圈，实际镜头会有偏差，用于 估算与比较。

选镜头的步骤

选镜头可以按下面的顺序进行。先确定拍摄范围：需要看到的最小宽度与高度， 以及镜头到物体的工作距离。再查相机的传感器宽度、高度与对角线。对水平 与垂直两个方向分别计算允许的最大焦距 f_max = 传感器尺寸 × 工作距离 / 要求视场，取两者中较小的 一个。然后在标准焦距序列中选不大于 f_max 的最大值，这样 实际视场不会小于要求。

选定焦距后，计算实际视场、每像素对应的毫米数、放大倍率与景深。检查 镜头的成像圆是否覆盖传感器对角线、接口与法兰距是否匹配、镜头分辨率 是否满足像元尺寸。最后确认工作距离有调整余量、景深覆盖物体前后范围、 照明与光圈能满足曝光要求。若景深不足，可以收小光圈、缩短焦距或增大 工作距离，但这三者都会改变视场或进光量，需要一起权衡。

5.4曝光

曝光决定图像的亮度与运动物体是否清晰。相机上可调的三项是光圈、 曝光时间与增益；光源的频率还会影响图像是否出现明暗条纹。这一课说明 三者的关系、等价曝光的换算、运动模糊的估算，以及过曝与欠曝的判断。

曝光三要素

到达传感器的光量，近似与光圈孔径面积的平方、曝光时间成正比。孔径面积 与 1 / F² 成正比，所以曝光量与 t / F² 成正比， 其中 t 是曝光时间。光圈开大一档（F 数除以 1.414），进光量 加倍；曝光时间加倍，进光量也加倍。

增益（gain）在信号读出后放大电压或数字值。模拟增益在模数转换前放大， 数字增益在转换后乘以系数。增益能提高图像亮度，但不会增加进入传感器的 光，也不会改善信噪比；放大信号的同时也放大噪声。参数表常用分贝表示增益， 约 6 dB 对应电压或数字值的 2 倍，相当于一档。不同厂商的标定方式可能 不同，换算时以参数表或接口说明为准。

档与等价曝光

「档」（stop）是曝光量的相对单位。曝光量加倍叫增加一档，减半叫减少 一档。光圈、曝光时间与增益都可以按档调整：光圈从 F4 开到 F2.8 增加 一档，曝光时间从 10 毫秒减到 5 毫秒减少一档，增益从 0 dB 加到 6 dB 增加一档。总曝光量不变的一组设置叫等价曝光。

等价曝光不等于等价图像。开大光圈会增加进光量，同时减小景深；延长 曝光时间会增加运动模糊；提高增益会增加噪声。调整时先确定哪一项是 约束：测量任务优先保证景深与模糊，亮度不足时优先增加照明或开大光圈， 最后才提高增益。

运动模糊

物体相对相机运动时，曝光期间像点在传感器上移动，形成运动模糊。 设物体速度为 v，镜头焦距为 f，工作距离为 d，且运动方向与光轴垂直、d 远大于 f，像点速度为 v f / d。曝光时间为 t 时，模糊长度为 v f t / d；除以像元尺寸， 得到模糊占多少个像素。

模糊超过一个像素时，边缘开始变软；测量边缘位置或尺寸时，通常希望 模糊小于一个像素，必要时小于半个像素。要缩短曝光时间，就要用更大的 光圈、更强的照明或更高的增益来补足亮度。若相机是卷帘快门，运动还会 带来倾斜与变形，此时应优先换全局快门相机。

过曝与欠曝

过曝是像素值达到上限后被截断。8 位图像的像素值到 255 后不再增加， 高光区域的细节丢失，无法通过后期处理恢复。欠曝是像素值过小，暗部 细节被噪声淹没。判断曝光是否合适，不能只看平均亮度：要看直方图， 看有多少像素接近上限，也要看关心区域的最小值与最大值。

自动曝光（auto exposure）通常以图像的平均亮度或某个百分位为目标， 调整曝光时间或增益。背景很亮或很暗时，平均亮度会被背景拉偏；可以 把测光区域限制在感兴趣区域，或改用固定曝光。检测与测量任务通常使用 固定曝光，避免帧与帧之间亮度变化影响阈值；需要自动曝光时，应确认 收敛稳定后再采集。

光源频闪

使用交流电供电的灯，亮度会随电压周期性变化。50 Hz 市电下，亮度波动 频率为 100 Hz，周期 10 毫秒；60 Hz 市电下为 120 Hz，周期约 8.333 毫秒。曝光时间不是波动周期的整数倍时，不同帧或同一帧的不同行接收到 的光量不同，会出现明暗条纹（banding）。

避免条纹的方法有三种：使用直流供电或高频驱动的光源；让曝光时间等于 波动周期的整数倍，例如 50 Hz 下取 10 毫秒、20 毫秒；用相机的频闪 同步输出触发光源，使曝光与光源脉冲对齐。LED 灯具的驱动方式差异很大， 参数表未写明时，应实际拍摄并检查条纹。

5.5接口

接口决定相机与主机之间的数据传输方式与速度。分辨率、像素格式与帧率 共同决定每秒钟要传多少数据；接口带宽不足时，相机会丢帧或降低帧率。 这一课先算单帧大小，再比较常见接口，最后说明触发、同步与丢帧的原因。

像素格式与单帧大小

像素格式（pixel format）规定每个像素在传输时占多少位、如何排列。 Mono8 每个像素 1 字节；Mono10 与 Mono12 可以按 10 位或 12 位紧凑打包， 分别占 1.25 与 1.5 字节，也可以放在 16 位容器里各占 2 字节。彩色相机 常输出 BayerRG8，每个像素 1 字节，主机再去马赛克；RGB8 每个像素 3 字节； YUV422 平均每个像素 2 字节。

单帧数据量等于宽 × 高 × 每像素字节数，再加上协议开销。相机参数表 写的像素格式与实际传输格式必须一致：同样标为 Mono12，紧凑打包与 16 位容器的数据量相差三分之一，带宽计算结果也不同。选型时先确认 相机实际输出的格式，再按字节数计算。

常见接口

USB 3.0 的理论速率为 5 Gbit/s，折合 625 MB/s；USB 3.1 与 USB 3.2 还有 10 Gbit/s、20 Gbit/s 等版本。USB3 Vision 是建立在 USB 3 上的 相机标准。实际可用带宽低于理论值，主机控制器、线缆、供电与同时接入的 设备都会影响；多台相机接在同一个控制器上时，带宽需要相加。

GigE Vision 使用千兆以太网，理论速率 1 Gbit/s，折合 125 MB/s；实际 可用通常在 110 到 118 MB/s 之间，取决于网卡、巨帧设置与协议开销。 10GigE 的理论速率为 1250 MB/s。以太网线缆长、可供电（PoE），适合 多相机与远距离布线；使用独立网卡、开启巨帧、避免与办公网络混用， 可以减少丢包。

Camera Link 需要专用采集卡，按 Base、Medium、Full 等配置提供不同 带宽，延迟稳定，常见于高速工业场合。CoaXPress 使用同轴线缆，速率高， 同样需要采集卡。MIPI CSI-2 常用于嵌入式设备，直接连接到处理器， 线缆短，适合板载相机。USB 2.0 的理论速率为 480 Mbit/s，折合 60 MB/s， 实际可用更低，不适合高分辨率高帧率相机。

接口不止这几种，用到时自行查找

上面只列了课程例子会用到的几种接口。接口标准与版本更新较快，实际 项目还会遇到其他工业接口、厂商扩展与转接方案。读到不熟悉的接口名时， 自行在网上搜索该接口的名称加上「规格」或「白皮书」，核对理论速率、 实际可用带宽、线缆长度、供电方式与连接器类型，再以相机、采集卡与 线缆的参数表为准。本课不放外部链接，也不要求安装厂商软件。

带宽计算

每秒数据量等于单帧字节数乘以帧率。把结果换算成 MB/s 后，与接口的 可用带宽比较。计算时留出余量：协议开销、重传、主机处理都会占用带宽， 按理论值的七成到八成规划比较稳妥。若计算值接近或超过可用带宽， 相机会自动降帧，或在缓冲区满后丢帧。

除接口带宽外，还要检查曝光时间与读出时间之和是否超过帧周期。即使 接口带宽足够，曝光 20 毫秒、读出 15 毫秒的相机也无法达到 30 帧每秒， 因为一帧至少需要 35 毫秒。带宽与帧周期是两个独立的上限，实际帧率 取两者中较低的一个。

触发与同步

相机可以自由运行（free run），按设定帧率连续曝光；也可以由软件触发 或硬件触发。软件触发由主机发送命令，延迟与操作系统调度有关；硬件触发 由外部信号直接驱动，延迟小、抖动小，适合传送带编码器、光电开关与 多相机同步。触发信号可以指定上升沿或下降沿、延时与去抖时间。

多相机同步有两种常见方式：用同一路硬件信号同时触发所有相机；或使用 支持 IEEE 1588 精确时间协议（PTP）的相机，让各相机的时钟对齐。 同步不仅要求曝光时刻一致，还要求时间戳可比较。做双目、多视角或运动 分析时，先确认同步方式与时间戳来源。

丢帧的常见原因

丢帧指相机产生了帧，但主机没有收到或没有及时取走。常见原因包括： 接口带宽不足；曝光与读出时间超过帧周期；主机处理或写盘太慢，缓冲区 满；多台相机共享一个 USB 控制器或网卡；网线、接插件或供电不稳定； 驱动或 SDK 的缓冲区设置过小。现象可能是帧率下降、帧号不连续、时间戳 间隔变大，或图像出现撕裂与不完整。

排查时先看相机端的帧计数与主机的接收计数，确认丢帧发生在传输前还是 传输后；再看接口利用率、缓冲区占用与主机 CPU、磁盘占用。把分辨率、 像素格式与帧率代入带宽公式，能快速判断是不是带宽问题。逐项排除比 直接更换硬件更有效。

5.6采集流程

采集流程把相机、驱动、缓冲区、处理与保存串在一起。多数丢帧与超时 不是相机本身的问题，而是流程中的某一环没有跟上。这一课按实际顺序 说明从打开设备到关闭设备的步骤，并解释缓冲区、触发、保存与异常处理。

从打开到关闭

一个完整的采集流程通常包含这些步骤：枚举设备并确认型号与序列号； 打开设备；读取固件版本与支持的功能；设置分辨率、像素格式、曝光、 增益、触发方式与 ROI；分配缓冲区并设置队列长度；开始采集；循环取帧， 设置超时；检查帧状态、帧号与时间戳；处理或保存；停止采集；释放缓冲区； 关闭设备。需要保留设置时，把它们保存到相机的用户配置组，下次上电 直接加载。

不同厂商的 SDK 函数名与参数组织方式不同，但流程基本一致。基于 GenICam 标准的相机用功能树（feature tree）描述参数，节点有类型、 取值范围与读写权限。写参数前先读当前值，写入后读回确认；有些参数 只能在停止采集时修改，有些修改后会触发相机重新初始化，需要等待。

缓冲区与丢帧

相机与主机之间通常有一个缓冲队列。采集线程把收到的帧放入队列，处理 线程从队列取走。队列能吸收短时的处理波动，但不能弥补长期的速度差： 如果处理一帧的时间大于相机产生一帧的周期，队列迟早会满，满了之后 新到的帧只能丢弃。增大队列只能推迟丢帧的时间，不能提高处理速度。

设计时要让处理速度留有余量，或降低帧率、缩小 ROI、把处理移到另一台 机器。采集线程应尽量只做拷贝与入队，避免在采集回调里做耗时处理； 处理线程可以并行，但要注意内存与顺序。队列长度、当前占用与丢帧计数 应写入日志，便于判断瓶颈。

触发、帧号与时间戳

帧号（frame ID）由相机递增分配，正常情况下连续。主机收到的帧号出现 跳变，说明中间的帧没有到达。时间戳记录帧的采集时刻，可能来自相机 内部时钟，也可能由主机在收到帧时打上；两者含义不同，比较多相机数据 时要统一来源。相机时间戳更接近曝光时刻，主机时间戳包含传输与调度延迟。

触发模式下，帧率由外部信号决定，曝光时间仍受帧周期限制。触发信号 抖动、去抖设置不当或信号频率超过相机能力，都会造成漏触发或多触发。 传送带应用常用编码器输出触发，使每次触发对应相同的位移；多相机应用 用同一路信号或 PTP 对齐时间。

保存与命名

用于测量与检测的图像应保存为无损格式，例如 PNG、TIFF 或相机原始 格式；JPEG 适合预览，不适合需要精确像素值的场合。文件名应包含日期、 时间、相机编号与帧号，避免覆盖；目录按日期或批次分层。写入时先写 临时文件，完成后再改名，防止程序中断留下半个文件。

高帧率下逐帧写盘可能超过磁盘速度。先估算数据量：单帧字节数乘以帧率， 再与磁盘持续写入速度比较。必要时只保存关心的帧、降低帧率、先写入 内存再异步落盘，或使用更快的固态盘。保存时同时记录曝光、增益、像素 格式、标定文件版本与触发信息，事后才能复现。

异常与日志

采集过程中可能出现取帧超时、相机断连、帧不完整、数据校验失败、磁盘 写满等情况。程序应对每种情况给出明确处理：超时后重试或跳过，断连后 重新枚举并打开，写盘失败时停止采集并保留现场。不要忽略接口返回码， 也不要在异常后继续使用已经失效的缓冲区。

日志应记录时间、相机标识、帧号、错误码与重试次数；正常运行时也要 记录开始、停止、参数变更与丢帧统计。日志轮转与级别在常见文件一部分 讲过。出现问题时，先看日志中的第一处错误，再看它前后的帧号与时间戳， 通常能定位到带宽、缓冲、触发还是磁盘。

5.7标定

标定（calibration）求相机的内参、畸变系数与外参，使像素坐标能与 空间中的方向或点对应。没有标定，像素只能表示图像上的位置；标定之后， 才能做尺寸测量、三维重建、手眼配合与多相机对齐。这一课先区分内参标定 与外参标定，介绍常见标定方案，再说明本课的内参标定流程、重投影误差与 结果的使用。

标定分为内参标定与外参标定两类。内参标定求相机自身的参数，包括内参 矩阵与畸变系数，与相机安装在什么位置无关；分辨率、焦距与光圈不变的 条件下，标定一次就可以重复使用。外参标定求相机坐标系与世界坐标系 之间的旋转与平移，相机移动或重新安装后必须重做。多台相机之间的相对 位姿、相机与机器人末端之间的手眼关系，也属于外参标定的范围。两类标定 的目标与使用方式不同，结果不能互相替代。

常见的内参标定方案中，平面标定板最常用：拍摄棋盘格或圆点阵列在不同 位置、不同倾角下的多张图像，由已知的方格尺寸与检测到的角点求内参与 畸变。它只需要一块平整、尺寸准确的标定板，操作简单，本课按这一方案 讲解。视场较大或精度要求较高时，会使用三维标定场或已知坐标的控制点， 让标定点覆盖整个测量空间。双目、结构光与深度相机通常有各自的标定 流程，往往同时求内参与各部件之间的相对位姿；鱼眼与广角镜头需要选用 对应的畸变模型。外参标定常用已知世界坐标的标定物或控制点，求相机相对 工作坐标系的位姿；多相机系统也可以让各相机观测同一标定物，把结果 统一到同一坐标系。本课的重点是内参标定，外参标定只说明概念与使用 场合，不展开求解步骤。

内参与畸变

内参矩阵包含 f_x、f_y、c_x、 c_y 四个主要参数，单位都是像素；有些模型还包含倾斜 （skew）项，通常接近 0。内参描述相机自身的投影关系，与相机在空间中 的位置无关。分辨率、ROI 或像元合并改变后，内参不能直接沿用；缩放或 裁剪图像时，f_x、f_y、c_x、 c_y 要按比例变换，或者重新标定。

畸变描述实际镜头与针孔模型的偏差。径向畸变使点沿半径方向偏移， 常用 k1、k2、k3 表示； k1 为负时图像向外鼓，叫桶形畸变，为正时向内收，叫枕形 畸变。切向畸变由镜头与传感器不平行引起，常用 p1、 p2 表示。广角与鱼眼镜头可能需要更多参数或单独的模型； 使用标定结果前，要确认畸变模型与求解时一致。

外参

外参描述世界坐标系到相机坐标系的刚体变换，由旋转矩阵 R 与平移向量 t 组成，共 6 个自由度： X_cam = R X_world + t。反过来，世界坐标中的相机位置为 -Rᵀ t，相机姿态为 Rᵀ。外参随相机或场景的 安装位置变化，移动相机后必须重新确定。

多相机系统中，每台相机都有自己的内参与外参；把多台相机的数据统一到 同一坐标系，需要知道它们之间的相对变换。相机固定在机器人末端时， 还需要手眼标定（hand-eye calibration）求相机与机器人末端之间的变换； 手眼标定与相机内参标定是两件事，不能互相替代。

内参标定流程

内参标定通常使用平面标定板，常见的是棋盘格或圆点阵列，方格边长或点 间距已知且精确。标定板应平整、刚性固定，印刷或加工精度要高于需要的 测量精度；纸张容易翘曲，高精度场合使用陶瓷、玻璃或金属标定板。拍摄时 让标定板出现在画面的不同位置与不同倾角，覆盖中心与四角，数量通常 十几到几十张。

拍摄过程中保持镜头焦距、光圈与对焦不变，避免运动模糊与反光过曝； 标定板不能太远，否则角点像素误差会被放大。先检测角点，再用内参 初值与多视图几何求解，最后做非线性优化，使重投影误差最小。查看每张 图的误差，剔除明显偏大的图，再重新求解；用未参与标定的图像做验证。 每张图像对应一个标定板相对相机的位姿，求解时作为该图的临时外参一起 估计；标定完成后保留的是内参与畸变系数，这些外参只对当时的拍摄位置 有效，不用于其他场景。

重投影误差

重投影误差（reprojection error）是把标定板上的三维点按求得的内参、 外参与畸变投影回图像，与检测到的角点比较，二者在像素上的距离。 对所有点求均方根，得到 RMS 重投影误差。它衡量标定结果与观测数据的 一致程度，单位是像素。

误差小不代表标定一定准确：标定板不平、方格尺寸写错、角点检测有 系统偏差，都可能得到很小的重投影误差，却给出错误的三维尺度。应同时 检查每张图的误差分布、参数是否合理，并用已知长度的物体做独立验证。 工业测量中常希望 RMS 小于 0.5 像素，但具体阈值取决于镜头、分辨率与 测量精度要求。

使用标定结果

标定结果常用于三件事：去畸变，把图像校正成针孔模型下的图像；投影， 把三维点换算成像素坐标；反投影或三角测量，把像素与已知平面、已知 视差或其他相机结合，得到空间点。使用时要保证图像分辨率、ROI、镜头 焦距与标定时一致；改变对焦、变焦或光圈后，内参与畸变可能变化， 应重新标定或至少重新验证。

标定文件应记录相机型号、序列号、分辨率、镜头焦距、光圈、标定日期、 畸变模型与 RMS 误差，并与图像一起保存版本号。现场更换相机、镜头或 调整安装后，更新标定文件并通知使用方。不要把不同分辨率下的内参 混用，也不要把鱼眼模型的结果套到针孔模型上。

例子：投影与重投影误差

下面这段程序使用相机 A 的内参 f_x = f_y = 800、 c_x = 640、c_y = 512，以及径向畸变系数 k1 = -0.12、k2 = 0.05，把三个三维点投影 到像素坐标，再与给定的观测点比较，计算每个点的误差与 RMS。

# 由内参与畸变系数投影三维点，并计算与观测点的重投影误差。
import math

fx, fy = 800.0, 800.0
cx, cy = 640.0, 512.0
k1, k2 = -0.12, 0.05

points = [
    (0.0, 0.0, 2000.0),
    (100.0, -50.0, 2000.0),
    (-150.0, 80.0, 2500.0),
]
observed = [
    (640.4, 511.7),
    (680.3, 491.8),
    (591.7, 537.9),
]


def project(x, y, z):
    xn = x / z
    yn = y / z
    r2 = xn * xn + yn * yn
    radial = 1.0 + k1 * r2 + k2 * r2 * r2
    xd = xn * radial
    yd = yn * radial
    return fx * xd + cx, fy * yd + cy


print(f"内参：fx = {fx:.3f}, fy = {fy:.3f}, cx = {cx:.3f}, cy = {cy:.3f}")
print(f"畸变：k1 = {k1:.3f}, k2 = {k2:.3f}")

total = 0.0
for i, ((x, y, z), (ou, ov)) in enumerate(zip(points, observed), 1):
    u, v = project(x, y, z)
    err = math.hypot(u - ou, v - ov)
    total += err * err
    print(f"点 {i}：投影 ({u:.3f}, {v:.3f})，观测 ({ou:.3f}, {ov:.3f})，"
          f"误差 {err:.3f} 像素")

rms = math.sqrt(total / len(points))
print(f"重投影误差 RMS = {rms:.3f} 像素")

点 3：投影 (592.027, 537.586)，观测 (591.700, 537.900)，误差 0.453 像素

第一个点落在主点上，径向距离为 0，畸变不改变它的位置；观测点与投影 点相差 0.5 像素。第二个与第三个点偏离主点，径向畸变使它们的像素位置 相对针孔投影有少量移动。三个点的误差分别为 0.500、0.377 与 0.453 像素，RMS 为 0.446 像素。这个数值只说明给定参数与给定观测的一致程度； 实际标定要用多张图像与更多角点，并做独立验证。
