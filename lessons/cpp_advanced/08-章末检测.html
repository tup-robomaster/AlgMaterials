8.1例题 · 训练日志汇总

这一课不给新语法。它把一道题从头做到尾，每一步都告诉你这一步是从第几部分来的。 下面五道题照着这个走法做——它们只是换了个样子，底下的东西是一样的。

题目

输入文件 records.txt，每行三个字段：日期、编号、分数。

输出场次、总分、平均分（保留一位小数）、最高分（连同日期和编号）， 再按编号汇总，把结果写进 report.txt。

文件打不开、某一行格式不对、文件为空时，打印固定的中文提示， 不要继续算下去。

样例输入：

2026-10-01 1 87
2026-10-01 2 76
2026-10-02 1 91
2026-10-02 2 68
2026-10-03 1 79
2026-10-03 2 95

先拆题：一份日志派了九件事

题目只有三句话，派下来的活是九件。先把它们一件一件摆出来：

要干的事在哪一课学的
打开文件，逐行读入 6.1 的 std::ifstream 与 >>
把多条记录存下来 3.1 的 std::vector、3.2 的 std::string
按编号汇总 3.4 的 std::map
找最高分 第 4 部分的遍历与比较
平均分保留一位小数 第 1 部分的整数运算；本课用「乘 10、四舍五入、再拆开」的办法
写报告文件 6.2 的 std::ofstream
文件自动关闭，报告对象不可拷贝 5.3 的 RAII 与 = delete
文件打不开、行格式不对、文件为空 6.3 的 throw / try / catch、6.4 的 std::runtime_error
拆成多个文件，用 CMake 构建 第 1 部分的头文件与多文件、第 2 部分的 CMakeLists.txt

九件事，分散在第 1 到第 6 部分。第 7 部分的内容留给最后一道检测题。

第一版：九件事都做了

第一版没有拆文件，所有事情都在 main 里。它先把功能做出来： 

// 第一版：所有事情都写在 main 里，没有错误处理。只用于和最后的工程对照。
// 它不参与 CMakeLists.txt 的构建。

#include <fstream>
#include <iostream>
#include <map>
#include <string>
#include <vector>

struct Record {
    std::string date;
    int id;
    int score;
};

int main() {
    std::ifstream in("records.txt");
    std::vector<Record> records;
    Record r;
    while (in >> r.date >> r.id >> r.score) {
        records.push_back(r);
    }

    int total = 0;
    for (const Record& x : records) {
        total += x.score;
    }
    double average = total * 1.0 / records.size();

    const Record* best = &records[0];
    for (const Record& x : records) {
        if (x.score > best->score) {
            best = &x;
        }
    }

    std::map<int, int> by_id;
    for (const Record& x : records) {
        by_id[x.id] += x.score;
    }

    int tenths = static_cast<int>(average * 10.0 + 0.5);
    std::cout << "训练日志汇总\n";
    std::cout << "场次：" << records.size() << "\n";
    std::cout << "总分：" << total << "\n";
    std::cout << "平均：" << tenths / 10 << "." << tenths % 10 << "\n";
    std::cout << "最高：" << best->score << "（" << best->date
              << "，编号 " << best->id << "）\n";
    for (const auto& item : by_id) {
        std::cout << "编号 " << item.first << "：" << item.second << " 分\n";
    }

    std::ofstream out("report.txt");
    out << "训练报告\n";
    out << "场次：" << records.size() << "\n";
    out << "总分：" << total << "\n";
    out << "平均：" << tenths / 10 << "." << tenths % 10 << "\n";
    out << "最高：" << best->score << "\n";
    for (const auto& item : by_id) {
        out << "编号 " << item.first << "：" << item.second << " 分\n";
    }

    std::cout << "已写入 report.txt\n";
    return 0;
}

最高：95（2026-10-03，编号 2）

例题 · 它打的，和你要的

把 records.txt 的第二行改成一个坏行： 

2026-10-01 1 87
2026-10-02 2 坏

第一版打印的是： 

训练日志汇总
场次：1
总分：87
平均：87.0
最高：87（2026-10-01，编号 1）
编号 1：87 分
已写入 report.txt

而你要的是： 

处理失败：记录文件格式错误

两边的差别不在数字算错，而在第一版不知道文件已经坏了。 它读到第二行的 坏 时，>> 取分数失败，循环停下来； 它把「停下来」理解成「读完了」，于是拿已经读到的第一条记录当成全部。

病根：坏行被当成了结尾

根在循环的条件上： 

while (in >> r.date >> r.id >> r.score) {
    records.push_back(r);
}

>> 返回的是流本身；放在条件里，流会被转成「成功还是失败」。 失败时循环结束，但代码没有问一句「为什么结束」——是读到文件末尾， 还是有一个字段没读进来。6.1 讲读取时说过：循环结束之后要检查流的状态。 第一版省掉了这一步。

同一个省法还有两处后果：文件打不开时，循环一次也不执行， records 是空的，后面 &records[0] 会访问不存在的元素； 文件为空时也一样。第一版在这两种情况下都不会给出提示。

改法一：把读取单独拿出来

先只改读取。把「打开、逐行取三个字段、判断结束原因」写成一个函数： 

std::vector<Record> read_records(const std::string& path) {
    std::ifstream in(path);
    if (!in) {
        throw std::runtime_error("打不开记录文件");
    }

    std::vector<Record> records;
    while (true) {
        Record r;
        if (!(in >> r.date)) {
            break;
        }
        if (!(in >> r.id >> r.score)) {
            throw std::runtime_error("记录文件格式错误");
        }
        records.push_back(r);
    }
    if (!in.eof()) {
        throw std::runtime_error("记录文件格式错误");
    }
    if (records.empty()) {
        throw std::runtime_error("记录文件是空的");
    }
    return records;
}

四处检查对应四种情况：

  • if (!in)：文件没有打开。可能是路径写错，也可能是没有读权限。
  • 读日期成功、读编号或分数失败：这一行不完整。这里不把已经读到的半边记录留下， 直接抛异常。若写成 while (in >> ...)，最后一行只写了两个字段时， 第三个字段读到文件末尾，循环同样会停，而且 eof() 为真， 事后检查不出来。所以这里把三个字段分开读。
  • 循环结束后 !in.eof()：结束的原因不是文件末尾，而是别的流错误。
  • records.empty()：文件打开了，但一条记录也没有。 空文件无法算平均分，也无法找最高分。

这些情况都抛 std::runtime_error，构造时把固定的中文说明传进去。 调用者只需要接住异常，打印 e.what()，不用在每个函数里各写一遍错误提示。

改法二：拆成三个文件

读取单独拿出来之后，剩下的工作也各归各位。最后的工程有四个文件： report.h 放声明，report.cpp 放定义， main.cpp 只负责把流程串起来，CMakeLists.txt 负责构建。

report.h

#pragma once

#include <fstream>
#include <map>
#include <string>
#include <vector>

struct Record {
    std::string date;
    int id;
    int score;
};

// 管理报告文件：构造时打开，析构时关闭；不允许拷贝。
// 两个对象同时写一份文件，写出来的行会交错，所以拷贝必须被禁止。
class ReportWriter {
public:
    explicit ReportWriter(const std::string& path);
    ~ReportWriter();

    ReportWriter(const ReportWriter&) = delete;
    ReportWriter& operator=(const ReportWriter&) = delete;

    std::ofstream& out();

private:
    std::ofstream out_;
};

std::vector<Record> read_records(const std::string& path);
const Record& best_record(const std::vector<Record>& records);
std::map<int, int> group_totals(const std::vector<Record>& records);

void write_report(const std::string& path, const std::vector<Record>& records,
                  int total, double average, const Record& best,
                  const std::map<int, int>& by_id);

#pragma once 让同一个头文件在一次编译里只展开一次， 作用与第 1 部分讲的包含卫士相同。Record 是三条字段的组合； ReportWriter 的声明里只写「有构造、有析构、拷贝被删除、能交出流」， 函数体在 report.cpp。

report.cpp

#include "report.h"

#include <stdexcept>

ReportWriter::ReportWriter(const std::string& path) : out_(path) {
    if (!out_) {
        throw std::runtime_error("打不开报告文件");
    }
}

ReportWriter::~ReportWriter() {
    out_.close();
}

std::ofstream& ReportWriter::out() {
    return out_;
}

std::vector<Record> read_records(const std::string& path) {
    std::ifstream in(path);
    if (!in) {
        throw std::runtime_error("打不开记录文件");
    }

    std::vector<Record> records;
    while (true) {
        Record r;
        if (!(in >> r.date)) {
            break;
        }
        if (!(in >> r.id >> r.score)) {
            throw std::runtime_error("记录文件格式错误");
        }
        records.push_back(r);
    }
    if (!in.eof()) {
        throw std::runtime_error("记录文件格式错误");
    }
    if (records.empty()) {
        throw std::runtime_error("记录文件是空的");
    }
    return records;
}

const Record& best_record(const std::vector<Record>& records) {
    if (records.empty()) {
        throw std::runtime_error("没有记录");
    }
    const Record* best = &records[0];
    for (const Record& r : records) {
        if (r.score > best->score) {
            best = &r;
        }
    }
    return *best;
}

std::map<int, int> group_totals(const std::vector<Record>& records) {
    std::map<int, int> totals;
    for (const Record& r : records) {
        totals[r.id] += r.score;
    }
    return totals;
}

void write_report(const std::string& path, const std::vector<Record>& records,
                  int total, double average, const Record& best,
                  const std::map<int, int>& by_id) {
    ReportWriter writer(path);
    std::ofstream& out = writer.out();

    int tenths = static_cast<int>(average * 10.0 + 0.5);
    out << "训练报告\n";
    out << "场次：" << records.size() << "\n";
    out << "总分：" << total << "\n";
    out << "平均：" << tenths / 10 << "." << tenths % 10 << "\n";
    out << "最高：" << best.score << "\n";
    for (const auto& item : by_id) {
        out << "编号 " << item.first << "：" << item.second << " 分\n";
    }
}

文件开头三件事：

  • ReportWriter 的构造函数打开文件，打开失败就抛 std::runtime_error；析构函数关闭文件。对象离开作用域时， 关闭自动发生——这就是 5.3 的 RAII。
  • 拷贝构造和拷贝赋值都被 = delete 删除。两个 ReportWriter 同时写一份文件，输出会交错；禁止拷贝把这个可能 从类型上去掉。
  • out() 把内部的 std::ofstream& 交出来， 写入仍然用 6.2 的 <<。类负责打开、关闭和禁止拷贝， 写什么由调用者决定。

write_report 里的平均分保留一位小数，用的是整数运算： 先乘 10，加 0.5 后取整，再拆成整数部分和小数部分。 这样不依赖 printf 的格式符，写屏幕和写文件可以用同一套算法。

main.cpp

#include "report.h"

#include <exception>
#include <iostream>
#include <map>
#include <string>
#include <vector>

int main(int argc, char* argv[]) {
    std::string path = "records.txt";
    if (argc > 1) {
        path = argv[1];
    }

    try {
        std::vector<Record> records = read_records(path);

        int total = 0;
        for (const Record& r : records) {
            total += r.score;
        }
        double average = total * 1.0 / records.size();
        const Record& best = best_record(records);
        std::map<int, int> by_id = group_totals(records);

        int tenths = static_cast<int>(average * 10.0 + 0.5);
        std::cout << "训练日志汇总\n";
        std::cout << "场次：" << records.size() << "\n";
        std::cout << "总分：" << total << "\n";
        std::cout << "平均：" << tenths / 10 << "." << tenths % 10 << "\n";
        std::cout << "最高：" << best.score << "（" << best.date
                  << "，编号 " << best.id << "）\n";
        for (const auto& item : by_id) {
            std::cout << "编号 " << item.first << "：" << item.second << " 分\n";
        }

        write_report("report.txt", records, total, average, best, by_id);
        std::cout << "已写入 report.txt\n";
    } catch (const std::exception& e) {
        std::cout << "处理失败：" << e.what() << "\n";
        return 1;
    }
    return 0;
}

main 只做四件事：决定读哪个文件、调用 read_records、 把统计结果打印出来、调用 write_report。读取和写入的具体做法都在别的文件里； main 不再出现 ifstream、循环和错误提示。

argc 与 argv 在第 7 部分的联调程序里已经出现过： argc 是参数个数，argv[1] 是第一个参数。 这里只用它换一个文件名，不展开其他用法。

练习 8-1（拆成三个文件）

读入一个整数 n，再读入 n 个分数（n 至少为 1）。 打印三行：及格人数（分数不低于 60 的人数）、平均分（保留一位小数）、最高分。

程序要拆成三个文件：

  • stats.h 放三个函数的声明；
  • stats.cpp 放三个函数的定义；
  • main.cpp 只负责读入、调用和打印。

三个函数的声明如下，名字与参数不能改： 

int pass_count(const std::vector<int>& scores, int pass);
double average(const std::vector<int>& scores);
int max_score(const std::vector<int>& scores);

再写一份 CMakeLists.txt，生成的可执行文件叫 demo。 输入从标准输入读，不经过文件。

用到：第 1 部分的函数声明与定义、第 2 部分的 CMake、 3.1 的 std::vector、第 1 部分的整数除法。 

5
55 72 88 96 61
及格人数：4
平均分：74.4
最高分：96

把四个文件放好之后，再展开答案对照。

看答案

这道题交的是四个文件。先看它们各自负责什么，再看拼起来怎么运行。 

cmake_minimum_required(VERSION 3.16)
project(分段统计 LANGUAGES CXX)

set(CMAKE_CXX_STANDARD 17)

add_executable(demo main.cpp stats.cpp)

add_executable 的第一个参数是程序名，后面只列 .cpp。stats.h 不列在这里，它由 main.cpp 与 stats.cpp 里的 #include "stats.h" 找到。 

#pragma once

#include <vector>

int pass_count(const std::vector<int>& scores, int pass);
double average(const std::vector<int>& scores);
int max_score(const std::vector<int>& scores);

头文件里只放声明：函数叫什么、收什么、返回什么。三个函数都接收 const std::vector<int>&，表示只读，不复制整个容器。 #pragma once 让这个头文件在一次编译里只展开一次。 

#include "stats.h"

int pass_count(const std::vector<int>& scores, int pass) {
    int count = 0;
    for (int s : scores) {
        if (s >= pass) {
            count++;
        }
    }
    return count;
}

double average(const std::vector<int>& scores) {
    int sum = 0;
    for (int s : scores) {
        sum += s;
    }
    return sum * 1.0 / scores.size();
}

int max_score(const std::vector<int>& scores) {
    int best = scores[0];
    for (int s : scores) {
        if (s > best) {
            best = s;
        }
    }
    return best;
}

定义放在这里。pass_count 逐个比较，达到 pass 就加一；average 先求和，再乘 1.0 转成小数除法；max_score 用第一个元素 作为当前最高分，逐个比较。题目保证 n 至少为 1， 所以 scores[0] 一定存在。 

#include "stats.h"

#include <iostream>
#include <vector>

int main() {
    int n;
    std::cin >> n;

    std::vector<int> scores(n);
    for (int i = 0; i < n; i++) {
        std::cin >> scores[i];
    }

    int tenths = static_cast<int>(average(scores) * 10.0 + 0.5);
    std::cout << "及格人数：" << pass_count(scores, 60) << "\n";

    return 0;
}

练习 8-2（词频统计）

从标准输入读入若干个单词，单词之间用空白分隔，读到文件末尾为止。 统计每个单词出现的次数，然后按次数从多到少打印； 次数相同的，按单词的字典序从小到大打印。

每个单词一行，格式是「单词 次数」，中间一个空格。

用到：3.4 的 std::map、4.4 的 std::sort、 4.5 的 lambda、3.1 的 std::vector、3.2 的 std::string。

样例故意把最后两个 green 换到第二行：换行和空格一样，都属于 空白；std::cin >> word 会一直读到输入结束，不会在行尾 停下，所以这几个词是当成一串词统计的，不按行分开处理。

排序规则写对之后，再展开答案。

看答案

先数词，再排序。std::map 负责计数，并且按单词的字典序 保存；std::vector 把键值对取出来，std::sort 再按次数重排。 

#include <algorithm>
#include <iostream>
#include <map>
#include <string>
#include <utility>
#include <vector>

int main() {
    std::map<std::string, int> counts;
    std::string word;
    while (std::cin >> word) {
        counts[word]++;
    }

    std::vector<std::pair<std::string, int>> items(counts.begin(), counts.end());
    std::sort(items.begin(), items.end(),
              [](const std::pair<std::string, int>& a,
                 const std::pair<std::string, int>& b) {
                  if (a.second != b.second) {
                      return a.second > b.second;
                  }
                  return a.first < b.first;
              });

    for (const auto& item : items) {
        std::cout << item.first << " " << item.second << "\n";
    }
    return 0;
}

一、计数。while (std::cin >> word) 一直读到 文件末尾；counts[word]++ 里，如果这个单词还没有出现过， operator[] 会先插入一个值为 0 的项，再自增。

二、为什么先搬到 vector。std::map 的顺序由键决定， 不能按值重排。把每个 pair 复制进 std::vector，排序规则就可以自己写。

三、比较函数。先比 second（次数），次数不同时， 次数大的排前面；次数相同时，再比 first（单词）， 字典序小的排前面。两个分支都要有返回值，否则排序的行为不确定。

输入里 green 与 red 都是 3 次， 按字典序 green 在前；blue 是 2 次，排在最后。

练习 8-3（只可移动的缓冲区）

写一个 Buffer 类：

  • 构造时用 new[] 申请 n 个 int，并全部置 0；
  • 析构时用 delete[] 释放；
  • 拷贝构造和拷贝赋值都用 = delete 删除；
  • 写一个移动构造函数，把指针和长度接过来，再把源对象置空；
  • 提供 size()、empty()、at(i)。

在 main 里创建 4 个元素的 Buffer，依次填入 10、20、30、40，用 std::move 移动给另一个 Buffer， 打印移动前后的长度、源对象是否为空、新对象的和。

本题不需要标准输入，数据直接写在 main 里。

用到：5.1 的栈和堆、5.2 的 new / delete、 5.3 的 RAII 与 = delete、5.5 的 std::move。 

移动前 a：4
移动后 a：0
移动后 a 为空：是
移动后 b：4
b 的和：100

移动前后的长度都打印出来，再展开答案。

看答案

这一题写一个只可移动的 Buffer：它自己申请一块内存， 析构时释放；拷贝被 = delete 关掉；移动构造函数把指针 接过来，再把源对象置空。 

#include <iostream>
#include <utility>

class Buffer {
public:
    explicit Buffer(int n) : size_(n), data_(new int[n]) {
        for (int i = 0; i < size_; i++) {
            data_[i] = 0;
        }
    }

    ~Buffer() {
        delete[] data_;
    }

    Buffer(const Buffer&) = delete;
    Buffer& operator=(const Buffer&) = delete;

    Buffer(Buffer&& other)
        : size_(other.size_), data_(other.data_) {
        other.size_ = 0;
        other.data_ = nullptr;
    }

    int size() const {
        return size_;
    }

    bool empty() const {
        return data_ == nullptr;
    }

    int& at(int i) {
        return data_[i];
    }

    const int& at(int i) const {
        return data_[i];
    }

private:
    int size_;
    int* data_;
};

int main() {
    Buffer a(4);
    for (int i = 0; i < a.size(); i++) {
        a.at(i) = (i + 1) * 10;
    }

    std::cout << "移动前 a：" << a.size() << "\n";

    Buffer b(std::move(a));

    std::cout << "移动后 a：" << a.size() << "\n";
    std::cout << "移动后 a 为空：" << (a.empty() ? "是" : "否") << "\n";
    std::cout << "移动后 b：" << b.size() << "\n";

    int sum = 0;
    for (int i = 0; i < b.size(); i++) {
        sum += b.at(i);
    }
    std::cout << "b 的和：" << sum << "\n";
    return 0;
}

一、构造与析构。构造函数用 new int[n] 申请一块 连续内存，并把每个元素置 0；析构函数用 delete[] 释放。 申请与释放成对出现，而且都写在类里——5.3 的 RAII。

二、拷贝被删除。如果允许拷贝，两个 Buffer 会保存 同一个指针，析构时同一块内存被释放两次。删除拷贝构造和拷贝赋值， 这个错误在编译期就被挡住。

三、移动构造函数。Buffer(Buffer&& other) 的参数是右值引用，&& 表示它接收一个准备交出去的 对象。函数体把 other 的指针和长度接过来，再把 other.data_ 置为 nullptr、 other.size_ 置为 0。源对象之后析构时， delete[] nullptr 什么也不做。 std::move(a) 不移动任何字节，它只是把 a 转成右值，让编译器选中这个构造函数。

实际工程里常在移动构造函数后面加 noexcept，告诉标准库 这个函数不会抛异常，容器扩容时更愿意使用它。本课不展开， 需要时可以搜索「C++ noexcept 移动构造函数」。

移动之后 a 的长度是 0，指针为空；b 接管了 原来的四个元素，和是 10 + 20 + 30 + 40 = 100。

看答案

这一题把文件读取和异常接在一起：read_config 只负责读， 出错就抛；main 只负责接住并打印。 

#include <exception>
#include <fstream>
#include <iostream>
#include <stdexcept>
#include <string>

void read_config(const std::string& path) {
    std::ifstream in(path);
    if (!in) {
        throw std::runtime_error("打不开配置文件");
    }

    std::string line;
    while (std::getline(in, line)) {
        auto pos = line.find('=');
        if (pos == std::string::npos) {
            throw std::runtime_error("配置行格式错误");
        }
        std::string key = line.substr(0, pos);
        std::string value = line.substr(pos + 1);
        std::cout << key << " = " << value << "\n";
    }
}

int main(int argc, char* argv[]) {
    std::string path = "config.txt";
    if (argc > 1) {
        path = argv[1];
    }

    try {
        read_config(path);
    } catch (const std::exception& e) {
        std::cout << "配置读取失败：" << e.what() << "\n";
    }
    return 0;
}

一、打开文件。std::ifstream in(path) 之后立刻 检查 if (!in)；文件不存在或没有读权限时，抛 std::runtime_error("打不开配置文件")。

二、逐行读。std::getline(in, line) 读到换行符为止， 行内的空格会保留。每一行用 find('=') 找等号； 找不到时返回 std::string::npos，这时抛 std::runtime_error("配置行格式错误")。

三、拆开键和值。substr(0, pos) 取等号前的部分， substr(pos + 1) 取等号后的部分。等号本身不进入任何一边。

四、接住异常。main 里 try 包住 read_config，catch (const std::exception& e) 接住所有标准异常，打印 e.what()。这里接住之后返回 0， 程序正常结束；如果这是一个要交给脚本调用的工具，也可以返回 1， 让调用者知道这次没有成功。

先读 config.txt，两行都正常，打印两行「键 = 值」； 再读 bad.txt，第二行没有等号，第一行已经打印出来， 第二行抛出异常，main 打印错误说明。

练习 8-5（从字节流里取帧）

从标准输入读入一串十六进制字节（每个字节写成两位十六进制，用空白分隔）， 按第 7 部分的 A5 帧格式解析：先找帧头，验 CRC8，读长度， 等收齐，再验 CRC16。坏帧丢一个字节继续找。

为了模拟串口一次读到的字节数不固定，把输入按每 3 个字节一块 交给解析器。每取出一帧，打印它的序号、命令和数据；最后打印好帧数与坏帧数。

用到：7.1 的十六进制与字节、7.6 的帧格式、7.7 的 CRC8 与 CRC16、 7.8 的粘包与半包、7.9 的收包循环、3.1 的 std::vector。

样例输入（开头有两个无效字节，末尾有一帧的 CRC16 被改坏）：

00 FF A5 02 00 00 8C 01 00 12 34 D9 34
A5 02 00 01 D2 02 00 56 78 8B A8
A5 02 00 02 30 03 00 9A BC 01 66
A5 02 00 00 8C 01 00 12 34 D9 35
取出第 1 帧：seq=0 命令=0x0001 数据=12 34
取出第 2 帧：seq=1 命令=0x0002 数据=56 78
取出第 3 帧：seq=2 命令=0x0003 数据=9A BC
好帧：3
坏帧：1

好帧和坏帧的数目都对上，再展开答案。

看答案

这一题把第 7 部分的收包过程装进一个类：feed 接收一块 字节，内部循环取帧；main 每次只喂 3 个字节，模拟串口 一次读到的字节数不固定。 

#include <cstdint>
#include <cstdio>
#include <iostream>
#include <vector>

std::uint8_t crc8(const std::vector<unsigned char>& data, int count) {
    unsigned char crc = 0xFF;
    for (int i = 0; i < count; i++) {
        crc = static_cast<unsigned char>(crc ^ data[i]);
        for (int bit = 0; bit < 8; bit++) {
            if ((crc & 0x01) != 0) {
                crc = static_cast<unsigned char>((crc >> 1) ^ 0x8C);
            } else {
                crc = static_cast<unsigned char>(crc >> 1);
            }
        }
    }
    return crc;
}

std::uint16_t crc16(const std::vector<unsigned char>& data, int count) {
    std::uint16_t crc = 0xFFFF;
    for (int i = 0; i < count; i++) {
        crc = static_cast<std::uint16_t>(crc ^ data[i]);
        for (int bit = 0; bit < 8; bit++) {
            if ((crc & 0x0001) != 0) {
                crc = static_cast<std::uint16_t>((crc >> 1) ^ 0x8408);
            } else {
                crc = static_cast<std::uint16_t>(crc >> 1);
            }
        }
    }
    return crc;
}

struct Frame {
    unsigned char seq;
    std::uint16_t cmd;
    std::vector<unsigned char> data;
};

class Parser {
public:
    int good = 0;
    int bad = 0;

    void feed(const std::vector<unsigned char>& chunk) {
        buf_.insert(buf_.end(), chunk.begin(), chunk.end());
        while (take_one()) {
        }
    }

private:
    std::vector<unsigned char> buf_;

    bool take_one() {
        while (!buf_.empty()) {
            if (buf_[0] != 0xA5) {
                buf_.erase(buf_.begin());
                continue;
            }
            if (buf_.size() < 5) {
                return false;
            }
            if (crc8(buf_, 4) != buf_[4]) {
                bad++;
                buf_.erase(buf_.begin());
                continue;
            }

            int len = buf_[1] | (buf_[2] << 8);
            int total = len + 9;
            if (total > 100) {
                bad++;
                buf_.erase(buf_.begin());
                continue;
            }
            if (static_cast<int>(buf_.size()) < total) {
                return false;
            }

            std::uint16_t check =
                static_cast<std::uint16_t>(buf_[total - 2] |
                                           (buf_[total - 1] << 8));
            if (crc16(buf_, total - 2) != check) {
                bad++;
                buf_.erase(buf_.begin());
                continue;
            }

            Frame f;
            f.seq = buf_[3];
            f.cmd = static_cast<std::uint16_t>(buf_[5] | (buf_[6] << 8));
            f.data.assign(buf_.begin() + 7, buf_.begin() + 7 + len);
            buf_.erase(buf_.begin(), buf_.begin() + total);
            good++;
            print_frame(f);
            return true;
        }
        return false;
    }

    void print_frame(const Frame& f) const {
        printf("取出第 %d 帧：seq=%d 命令=0x%04X 数据=", good, f.seq,
               static_cast<unsigned int>(f.cmd));
        for (int i = 0; i < static_cast<int>(f.data.size()); i++) {
            if (i > 0) {
                printf(" ");
            }
            printf("%02X", f.data[i]);
        }
        printf("\n");
    }
};

int main() {
    std::vector<unsigned char> bytes;
    unsigned int value;
    std::cin >> std::hex;
    while (std::cin >> value) {
        bytes.push_back(static_cast<unsigned char>(value));
    }

    Parser parser;
    for (int i = 0; i < static_cast<int>(bytes.size()); i += 3) {
        int end = i + 3;
        if (end > static_cast<int>(bytes.size())) {
            end = static_cast<int>(bytes.size());
        }
        std::vector<unsigned char> chunk(bytes.begin() + i, bytes.begin() + end);
        parser.feed(chunk);
    }

    printf("好帧：%d\n", parser.good);
    printf("坏帧：%d\n", parser.bad);
    return 0;
}

一、两段校验。crc8 校验前 4 个字节， crc16 校验从帧头到数据末尾的全部字节。两个函数与 7.7 的逐位算法相同；std::uint8_t 与 std::uint16_t 来自 <cstdint>，分别保存 8 位和 16 位的无符号值。

二、缓冲区。feed 把新字节接到 buf_ 的尾部，然后反复调用 take_one。取不出完整帧时， take_one 返回 false，已有字节留在缓冲区里， 等下一块数据。

三、取帧的顺序。先跳过不是 0xA5 的字节； 不足 5 个字节时等待；CRC8 不过就丢掉一个字节；读到长度后算出 整帧长度 len + 9，超过 100 字节按坏帧处理；字节不够时 继续等；CRC16 不过也丢掉一个字节。只有两段校验都通过，才取出一帧。

四、为什么只丢一个字节。坏帧的数据里也可能出现 0xA5。如果把整帧一起丢掉，后面真正的帧头可能被跳过； 每次只丢一个字节，再从头找帧头，最多多扫几个字节，不会漏掉后面的帧。

输入开头有两个无效字节，被逐个跳过；帧 A、B、C 依次通过校验； 最后一帧的 CRC16 被改坏，计为 1 个坏帧。按 3 个字节一块喂进去， 半包时 take_one 返回 false，下一块接上后 继续，所以最终仍然是 3 个好帧、1 个坏帧。

你现在能写什么：这五道题要是自己能写出来，进阶课就上完了。 把一份文件读进来、把数据放进容器、按规则排序、让对象自己管理内存、 在出错时抛出并接住、最后从一串字节里取出完整的帧—— 这些就是前面七部分的内容。真正写程序时，题目不会按部分分开； 能拆开，就能一件一件做下去。
