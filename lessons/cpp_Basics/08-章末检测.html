第 8 部分

章末检测

前七部分讲完了。这一部分不教新东西——一道例题，五道题， 每一道都要你把前面学过的好几样东西同时用上。 考的不是记性，是你拆不拆得动一道题。

8.1例题 · 一张成绩单

这一课不给新语法。它把一道题从头做到尾，每一步都告诉你这一步是从第几部分来的。 下面五道题照着这个走法做——它们只是换了个样子，底下的东西是一样的。

题目

输入：第一行一个整数 n，是人数（n 不超过 20）。 第二行 n 个整数，是每个人的分数。

输出三行——最高分、最低分、平均分（保留一位小数）。

样例输入：

5
80 91 76 66 65

先拆题：三行输出派了六件事

题目一共两句话，可它派下来的活是六件。先把它们一件一件摆出来：

要干的事在哪一课学的
把 n 和后面那串数读进来 1.5 的 std::cin，加 2.4 的 for 转着读
把这串数存下来——一个盒子装不下 4.1 的数组
找出最大的、找出最小的 4.3 的打擂台
把 n 个数加起来 2.3、2.4 那个累加
总数除以人数，得到平均分 1.3——这一件事最容易翻车
平均分要一位小数 1.6 的 printf

六件事，六种手艺，分散在第 1、2、4 部分里。 这五道检测题要练的就是这个动作：拿到题先不动手，先在纸上数一数是几件事。 数清楚了，写起来就是一件一件往下落。

第一版：六件事都做了

例题 · 第一版，和它打出来的

六件事各就各位，写出来是这样： 

#include <cstdio>
#include <iostream>

int main() {
    int n;
    int a[20];

    std::cin >> n;
    for (int i = 0; i < n; i++) {
        std::cin >> a[i];
    }

    int mx = a[0];
    int mn = a[0];
    int sum = 0;

    for (int i = 0; i < n; i++) {
        if (a[i] > mx) {
            mx = a[i];
        }
        if (a[i] < mn) {
            mn = a[i];
        }
        sum = sum + a[i];
    }

    double avg = sum / n;

    std::cout << "最高：" << mx << std::endl;
    std::cout << "最低：" << mn << std::endl;
    printf("平均：%.1f\n", avg);

    return 0;
}

它编译一声没吭，跑起来也好好的。打出来是这样： 

最高：91
最低：65
平均：75.0

而你要的是： 

最高：91
最低：65
平均：75.6

两行对上了，第三行差一位小数。80、91、76、66、65 加起来是 378， 378 除以 5 是 75.6——不是 75.0。这个 0.6 是真的丢了，不是四舍五入掉的。

病根在那一行

按 7.1 的三步走：第一处不一样的地方是第三行。往回走一步， 问一句「平均分是谁算出来的」——走到这一行： 

double avg = sum / n;

这一行看着挺对：盒子是 double 的，小数怎么会丢？ 丢的地方在等号右边，而且发生在放进盒子之前。

1.1 讲过那句话：先算右边，再放进左边。右边是 sum / n——sum 和 n 两个都是 int，两个整数相除，商在算出来的那一刻就已经是整数了， 378 / 5 得到 75。等号再把 75 变成 75.0 放进 avg—— 0.6 是在右边那一格里丢的，跟左边那个 double 一点关系都没有。

1.3 里 7 / 2 得 3 得的就是这一条。那一课里它是你要的效果 （250 分钟要的就是 4 小时）；这一课里它是个坑。 同一个规矩，用在两处，一处是帮手一处是敌人——这就是它值得单独学一课的原因。

改法只动一个位置： 

double avg = sum * 1.0 / n;

sum * 1.0 先乘出一个小数，除法再遇上它，就按小数除了。 1.3 说的「只要有一个是小数，结果就是小数」。

顺序不能换

写成 sum / n * 1.0 是白改：除法先算，75 已经出来了， 后面那个 1.0 乘上去得 75.0，0.6 早没了。

乘除从左往右算——1.3 那张运算顺序表上写着这一条， 今天这一次错在分母这边。

改完那一行，程序是这样（其余每一行原封不动）： 

#include <cstdio>
#include <iostream>

int main() {
    int n;
    int a[20];

    std::cin >> n;
    for (int i = 0; i < n; i++) {
        std::cin >> a[i];
    }

    int mx = a[0];
    int mn = a[0];
    int sum = 0;

    for (int i = 0; i < n; i++) {
        if (a[i] > mx) {
            mx = a[i];
        }
        if (a[i] < mn) {
            mn = a[i];
        }
        sum = sum + a[i];
    }

    double avg = sum * 1.0 / n;

    std::cout << "最高：" << mx << std::endl;
    std::cout << "最低：" << mn << std::endl;
    printf("平均：%.1f\n", avg);

    return 0;
}
最高：91
最低：65
平均：75.6

回头看一眼：这一遍用了什么

把刚才那一遍拆开，每一步都标上它是从哪一课来的：

写下的那几行手艺出处
#include、int main、编译、运行 骨架第 0 部分
int n; + std::cin >> n; 读数1.5
int a[20]; 配一个 for 转着读 数组 + 循环4.1、2.4
mx、mn 两个擂台 找最值4.3
sum = sum + a[i]; 累加2.3、2.4
sum * 1.0 / n 整数除法、类型1.3、1.2
printf("平均：%.1f\n", avg); 格式输出1.6
输出不对 → 比输出 → 往回走 → 找到那一行 找错三步第 7 部分

八行，跨了七个部分。 真正要写的东西，没有一道是只用一课的。

还剩一件事：这么长的程序，一步写不出来的。 上面那一版也不是一口气写完的——是先把六件事数出来，一件一件落， 落完跑一遍，发现在哪儿断的，再回头。 下面五道，照着这个来。

8.2五道检测题

五道题，一道一道做。每题底下写着「用到」——那是给你卡住的时候用的： 卡住了，照着那几个编号回去翻，翻完再回来。

这一部分不给提示。但 7.1 那三步还在手边，你自己就能给自己提示： 比输出、砍半、一次只改一处。答案在每题最底下收着，做完了再对。

练习 8-1（算式）

读一行进来，形如 7 / 2：一个整数、一个运算符、一个整数。 运算符是 + - * / 四个里的一个。

打印一行，把算式和结果打全： 

7 / 2 = 3

要是除法碰上了 0——运算符是 /、右边那个数也是 0—— 别算，打一句 除数不能是 0。

要求：真正算数的那几行装进一个函数，main 只管读和打。 函数长这样：int calc(int a, char op, int b)。

用到：第 1 部分的 char 和整数除法、第 2 部分的 if、 第 3 部分的函数。 

7 / 2
7 / 2 = 3
看答案

这份是写好的：

#include <iostream>

int calc(int a, char op, int b) {
    if (op == '+') {
        return a + b;
    } else if (op == '-') {
        return a - b;
    } else if (op == '*') {
        return a * b;
    } else {
        return a / b;
    }
}

int main() {
    int a;
    int b;
    char op;

    std::cin >> a >> op >> b;

    if (op == '/' && b == 0) {
        std::cout << "除数不能是 0" << std::endl;
        return 0;
    }

    std::cout << a << " " << op << " " << b
              << " = " << calc(a, op, b) << std::endl;

    return 0;
}

先说那个 char。std::cin >> op 读一个字符，读到的是那个符号本身——输进来的 / 到盒子里就是一个 /，不是它的编号。 所以 op == '+' 问的就是「这个字符是不是加号」， 1.2 讲 char 的时候那句话在这儿用上了。

再说除以 0 那一支：它必须写在算之前。 写成先算、算完再看结果，是来不及的——1.3 讲过， 整数除以 0 程序当场就被系统打死（浮点异常）， 后面那句「除数不能是 0」根本轮不到打。 要拦，就得拦在做那件事之前，这是 if 的用法里 最容易写反的一处。

最后一句打印，四个东西拼起来： a、op、b 原样打出来， 再加上算出来的结果，中间拿 " = " 隔着。 打出来就是 7 / 2 = 3——算式那半边是照抄输入，不是算出来的， 算出来的只有等号后面那个 3。

至于 7 / 2 为什么得 3——两个 int 相除， 小数当场砍掉，1.3 那条规矩，第 8.1 节的例题刚刚才踩过一次。

练习 8-2（最大的那个在第几个）

第一行一个整数 n，是这排数有几个（不超过 20）。 第二行 n 个整数。

打印三行：最大的数是几、它在第几个格子、这排数里有几个比平均值大。

「第几个」打的是下标，从 0 数起——4.2 讲的就是这个数法。

用到：第 4 部分的数组、遍历、打擂台，第 2 部分的 for， 第 1 部分的整数除法。平均值那一行跟上面例题里踩过的坑是同一个。 

6
12 45 7 30 33 8
最大：45
位置：1
比平均高：3
看答案

这份是写好的：

#include <cstdio>
#include <iostream>

int main() {
    int n;
    int a[20];

    std::cin >> n;
    for (int i = 0; i < n; i++) {
        std::cin >> a[i];
    }

    int mx = a[0];
    int mxIdx = 0;
    int sum = 0;

    for (int i = 0; i < n; i++) {
        if (a[i] > mx) {
            mx = a[i];
            mxIdx = i;
        }
        sum = sum + a[i];
    }

    double avg = sum * 1.0 / n;

    int above = 0;
    for (int i = 0; i < n; i++) {
        if (a[i] > avg) {
            above++;
        }
    }

    std::cout << "最大：" << mx << std::endl;
    std::cout << "位置：" << mxIdx << std::endl;
    std::cout << "比平均高：" << above << std::endl;

    return 0;
}

擂台上有两样东西：一个值，一个编号。 mx 记「现在最大的是几」，mxIdx 记 「它是第几个」。这两个必须一起换——4.3 那句 「比分数，记编号」说的就是这件事：只换值不换编号， 打完擂台下场的还是第 0 个。

平均值那两行是这一题最容易翻车的地方。 第 8.1 节的例题刚讲过：sum / n 两个 int 相除， 小数当场就没了——得先乘出一个小数，写成 sum * 1.0 / n，顺序还不能换。

数比平均高的，必须另起一个循环。 因为「比平均高」这句话里那个平均分，得等分数全加完、 除完了才知道。前一个循环跑到一半，avg 里还没有值， 那会儿拿它去比，比的是个空盒子。 凡是要拿一个「算完才知道的数」去比，就得等它算完再走第二遍。

位置打的是下标，从 0 数起——这排数里 45 是第二个， 编号就是 1。4.2 讲的就是这个数法。

练习 8-3（矩形和正方形）

写两个类：

  • Shape（形状）：两个 int 宽和高，藏起来不给外面看； 构造函数收两个数填进去；成员函数 name() 返回文字 矩形；成员函数 area() 返回宽乘高。
  • Square（正方形），基于 Shape： 构造函数只收一个数（边长），把它当宽也当高用； name() 返回文字 正方形。

再写一个函数 void printShape(Shape& s)，打印一行： 名字、一个空格、面积。

main 里造一个 3×4 的矩形、一个边长 5 的正方形， 用同一个 printShape 各打一行。

用到：第 5 部分的 class、private、构造函数、继承， 以及继承里那两个词；第 3 部分的函数和引用。 

矩形 12
正方形 25
看答案

这份是写好的：

#include <iostream>
#include <string>

class Shape {
private:
    int w;
    int h;

public:
    Shape(int a, int b) {
        w = a;
        h = b;
    }

    virtual std::string name() {
        return "矩形";
    }

    int area() {
        return w * h;
    }
};

class Square : public Shape {
public:
    Square(int side) : Shape(side, side) {}

    std::string name() override {
        return "正方形";
    }
};

void printShape(Shape& s) {
    std::cout << s.name() << " " << s.area() << std::endl;
}

int main() {
    Shape rect(3, 4);
    Square sq(5);

    printShape(rect);
    printShape(sq);

    return 0;
}

先看 Square 那行冒号： Square(int side) : Shape(side, side) {}。 它收一个边长，交给父类的时候一份当两份用—— 宽是它，高也是它，正方形就是这么来的（5.4 学的）。 Shape 里头那两个 private 的盒子， Square 自己碰不到，只能从构造函数这条路递进去。

再看那两个词。父类 name() 前面那个 virtual、子类那份后面的 override—— 一个都不能少。少了它们，下面 printShape 收的是 Shape&，就会照签名的字面去叫父类那一份， 两行都打「矩形」，第二行那个 25 也跟着变成 12。 5.4 拿两份程序摆在一起讲的就是这一件事（no-virtual 和 virtual 那一对）。

最后那个函数收的是 Shape&，这是 5.4 的关键： 一个函数写一次，矩形和正方形都能交给它—— 而且交给它的是本人不是抄件（第 6 部分的引用）， 所以它叫 name() 的时候，叫到的是各自那一份。 这就是「同一句话，不同的东西自己说自己的」。

练习 8-4（倒过来）

第一行一个整数 n，第二行 n 个整数。

先把这排数原样打一行，数之间用一个空格隔开； 然后把这排数倒过来，再打一行。

三个动作各写成一个函数，都要用上：

  • void swap2(int& x, int& y)——交换两个数
  • void reverse(int a[], int n)——把整排数倒过来，里面调 swap2
  • void printAll(int a[], int n)——打一行，两行用的是同一个函数

用到：第 6 部分的引用传递和数组参数，第 4 部分的数组和交换， 第 3 部分的函数，第 2 部分的 for。 

5
3 1 4 1 5
3 1 4 1 5
5 1 4 1 3
看答案

这份是写好的：

#include <iostream>

void swap2(int& x, int& y) {
    int t = x;
    x = y;
    y = t;
}

void reverse(int a[], int n) {
    for (int i = 0; i < n / 2; i++) {
        swap2(a[i], a[n - 1 - i]);
    }
}

void printAll(int a[], int n) {
    std::cout << a[0];
    for (int i = 1; i < n; i++) {
        std::cout << " " << a[i];
    }
    std::cout << std::endl;
}

int main() {
    int n;
    int a[20];

    std::cin >> n;
    for (int i = 0; i < n; i++) {
        std::cin >> a[i];
    }

    printAll(a, n);
    reverse(a, n);
    printAll(a, n);

    return 0;
}

参数表上那两个 &，一个都不能掉。 void swap2(int& x, int& y)——写成 int x, int y 就变成「换了两份抄件」，函数里忙活半天，main 这边 一点动静都没有。3.4 和 6.2 讲过这件事：要改的是本人， 参数表上就得写 &。

reverse 里那个 i < n / 2 是这一题的关键： 走到一半就该停。走满 n 圈会把刚换好的又换回去—— 看起来「什么都没发生」，其实是换了两次等于没换。 两个下标一个从前往后（i），一个从后往前 （n - 1 - i），碰头的地方正好是一半。

那种「前面一半对、后面一半错」的结果，是折返点写错的典型样子。 n 是奇数的时候中间那个自己跟自己换， 换不换都一样，不用为它单开一条路。

两行输出用的是同一个 printAll—— 第一行打原样，倒完再打一遍。函数写一次用两次， 3.x 一直在练的就是这个。

练习 8-5（人数少了一个）

下面这份程序，编译一声没吭，跑起来也正常。可它打出来的人数少了一个。 

#include <iostream>

int countPass(int a[], int n) {
    int c = 0;
    for (int i = 1; i < n; i++) {
        if (a[i] >= 60) {
            c++;
        }
    }
    return c;
}

int main() {
    int n;
    int a[20];

    std::cin >> n;
    for (int i = 0; i < n; i++) {
        std::cin >> a[i];
    }

    int mx = a[0];
    for (int i = 0; i < n; i++) {
        if (a[i] > mx) {
            mx = a[i];
        }
    }

    std::cout << "最高：" << mx << std::endl;
    std::cout << "及格：" << countPass(a, n) << std::endl;

它现在打的是： 

最高：90
及格：2

先别编译。按 7.1 那三步走一遍： 比输出、找第一处不一样的地方、往回走。 说清楚病根在哪一行、为什么，该怎么改。

用到：第 7 部分的找错三步，第 4 部分的数组和下标， 第 3 部分的函数，第 2 部分的循环。 

6
65 30 59 88 40 90
最高：90
及格：3
看答案

改好的版本是这样（只动了一处）：

#include <iostream>

病根是那一行：

for (int i = 1; i < n; i++) {

这个 1 该是 0。 它把 a[0] 整个跳过去了——第一个格子里的 65 从头到尾没人看过一眼。

65 是及格的（65 >= 60），它本该算进去， 所以真答案是 3：65、88、90。程序报 2，少的正是这一个。 4.2 说下标从 0 开始数，这一题就是那句话的反面： 从 1 开始数，等于当第一个数不存在。

按 7.1 那三步走一遍，是这么走过来的：

第一步，比输出。它打 及格：2，你要的是 及格：3——第一处不一样的地方就是这一行。

第二步，往回走一步，问「这个数是谁算出来的」。 那行打印上是 countPass(a, n)，答案就走到这个函数里。 这是这一题最要紧的一步：不对劲的那一行打印， 本身往往一个字都没错——它只是把别人给它的数原样打了出来。 7.1 那句「第一处不一样的地方，不等于病根」说的就是这种时候。

第三步，在函数里找那一处。整个函数就五行， 一眼看完：有一行是这个 for (int i = 1; i < n; i++)。 起手是 1，不是 0——改掉它，输出就对了。

为什么编译器一声没吭？因为「从 1 开始数」是个完全合法的写法， 语法上一点毛病都没有——它没有越界、没有漏分号。 它只是和你心里想的那件事不一样，而这种事只有你能看出来。 第 7 部分整部分讲的就是这个。

最后提一句：最高分那一行是对的，而且它是对的不奇怪—— 它是 main 里另一个循环算的，跟 countPass 一点关系都没有。一个地方坏，不一定带着后面全坏； 这一题就是只坏了一行。所以「哪里不对」永远得拿输出去对， 不能靠猜。

你现在能写什么：这五道题要是自己能写出来，这门课就上完了。 从键盘收数、把数放进盒子、用循环走一遍、把一件事包成函数、 用数组装一排、用类把自己造的东西也变成一个盒子， 最后程序不对的时候，你也知道去哪儿找问题。
