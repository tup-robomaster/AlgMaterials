这个文件夹里，是课里出现过的每一个程序。每个都是真的 .cpp 文件，
可以自己编译、自己跑，输出和课里写的「预期输出」一个字都不差。

文件名前面是课号：
  0.1-hello.cpp            0.1 那个 Hello, C++!
  0.2-skeleton.cpp         0.2 的骨架（0.2 例题用的就是这个）
  0.2-noreturn.cpp         0.2 讲的：不写 return 0; 也能跑
  1.1-boxes.cpp            1.1 那个程序，数据流动画用的就是它
  1.2-types.cpp 等         1.2 的四种类型、double 精度、char 编号、int 溢出
  1.3-arith.cpp 等         1.3 的五个运算符、整数除法、取余、除以 0

四点要注意：

一、名字里带 example 的，是那一课「例题」里的程序。
    例题是写给你看的，一般不用你敲。

二、名字里带 err 的，是 0.3 故意写错的程序。
    它们一定编译不过——课里贴的那些报错，就是从这几个文件真跑出来的。
    **这是故意的，不要把它们「修好」**，不然课里的报错就对不上了。

三、名字里带 fail 的，是「编译得过、跑得动，就是结果不对」的程序
    （3.4、3.5 各一份）。课里拿它们讲「为什么函数里改了、外面没变」，
    也别急着把它改对——自己看出错在哪一步，比直接看对的管用。

四、答案/ 这个子文件夹里，是每一道练习的答案，文件名就是练习号
    （练习1-9.cpp 就是练习 1-9 的答案）。课里每个练习下面那个
    「看答案」折起来的东西，里面贴的程序和这些文件是同一份。
    做不出来再看，别一上来就翻——自己卡一次，比看十遍答案管用。

想一次把所有程序都编译一遍、看看真实输出，在终端里跑：

    bash verify.sh
