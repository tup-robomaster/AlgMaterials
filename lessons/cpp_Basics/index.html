C++ 基础课

这是一门课，不是一份资料。每一课都假设你把代码真的敲进去跑过。 全部 9 个部分、42 课，按顺序从第 0 部分开始。

怎么用这份材料

一、按顺序，不要跳。后面的课默认你已经会了前面所有的东西。 第 3 部分讲函数时，会用第 2 部分的循环举例；第 6 部分讲指针时， 会默认你记得第 4 部分数组在内存里是怎么排的。

二、每段代码都自己敲一遍、跑一遍。看别人写代码和看别人打球一样， 看再多也不会长在自己手上。课里的代码都在 示例代码/ 文件夹里， 但你先自己敲，敲不出来或者跑不对的时候再去对。

三、每个练习都给了「预期输出」。你的程序跑出来的东西要和它逐字符一致—— 差一个空格也是差。这是你自己就能判断对错的方式。

四、卡住了，按这个顺序自己找。这份材料是照着「不用问任何人」写的：

  1. 报错看不懂——从最上面那条 error 读起，看到 note 就停下来读。 第 0.3 课整课都在教这个。
  2. 结果不对——把你的实际输出和课里的「预期输出」并排摆着，一个字符一个字符比。 差在哪，通常一眼就看出来了。
  3. 还是不对——把代码砍到最小：删掉一半，看还对不对； 一直删到只剩十几行还能重现问题，问题本身一般就露出来了。

这三步是第 7 部分要展开讲的。现在先照着做——等到你开始自己发现问题， 这门课就算上道了。

第 0 部分 · 开始

不教语法，只解决一件事：让你的屏幕亮起来。

  • 0.1 让第一个程序跑起来 建文件、编译、运行，以及分清「编译不过」和「结果不对」
  • 0.2 程序的骨架 那五行固定搭配分别是什么；程序是一行一行往下跑的
  • 0.3 报错怎么读 报错的格式、先看哪个、为什么行号会指偏。第 0 部分最重要的一课

第 1 部分 · 数字和字

怎么把数放进程序里，怎么让它算。

  • 1.1 变量：给一个盒子起名字★ 有动画 变量是内存里的一个盒子；= 不是「等于」，是「放进去」
  • 1.2 类型：int、double、char、bool 为什么有的盒子只能放整数，有的能放小数
  • 1.3 运算：加减乘除、取余 整数除法那个坑：7 / 2 为什么等于 3
  • 1.4 输出：std::cout 怎么把东西打到屏幕上 空格得自己打、引号里和引号外不是一回事、std::cout 是怎么判断该打什么的
  • 1.5 输入：std::cin 读进来的是什么 程序第一次停下来等你。敲进去 3.7，为什么盒子里留下的是 3
  • 1.6 格式输出：printf 与 %d、%f、%2d 小数点怎么对齐。这里最容易写歪

第 2 部分 · 让程序做判断和重复

程序不再从头走到尾，开始有岔路和回头路。

  • 2.1 判断：让程序选一条路走 if 是岔路口。条件成立走这一支，不成立走那一支
  • 2.2 条件怎么写 == != < && ||，和把 == 写成 = 的坑
  • 2.3 循环：让程序把同一件事做很多遍 while 怎么转起来，以及怎么一不小心写出死循环
  • 2.4 for：把三件事写在头上★ 有动画 起点、条件、步进，三个格子；以及它们是按什么顺序被走到的
  • 2.5 嵌套循环，和怎么用纸笔跟一遍★ 有动画 跑之前先在纸上把每一轮写出来
  • 2.6 【综合练习一】9×9 乘法表 for 和 while 各写一版。基础铺到这儿，你会发现它不难

第 3 部分 · 把代码拆开

这一部分治的是「所有代码都塞在 main 里」。

  • 3.1 为什么 main 不该太长 一个真实的坏例子，和它坏在哪
  • 3.2 函数：参数和返回值 把一件事打包、起个名字，需要的时候叫它
  • 3.3 变量能活多久：作用域★ 有动画 花括号一结束，里面定义的变量就没了
  • 3.4 传参（上）：值传递★ 有动画 为什么在函数里改了，外面那个变量没变
  • 3.5 传参（下）：引用传递 加一个 &，函数就能改外面的东西了
  • 3.6 动手拆：把乘法表拆成函数 同一个程序重写一遍，main 里只剩三行

第 4 部分 · 一堆数据

一个盒子装不下的时候。

  • 4.1 数组：一排盒子 挨着放，靠编号找
  • 4.2 遍历数组，和下标越界★ 有动画 下标就是「从开头数第几个」；为什么从 0 开始数
  • 4.3 在数组里找最大 / 最小值 摆一个擂台，让每个元素挨个上来打
  • 4.4 交换两个元素★ 有动画 为什么非要第三个盒子；直接互相赋值会怎样
  • 4.5 【综合练习二】找最小值并和最后一个交换 顺带讲清题目里那个「第一个数是长度」的陷阱
  • 4.6 vector：会自己变长的数组 C++ 里更常用的那个，实际代码里全是它

第 5 部分 · 自己造类型

C++ 真正的看家本事：把数据和操作它的函数捆在一起。

  • 5.1 struct：把几个东西捆在一起 一个学生的姓名、学号、成绩，当成一个整体
  • 5.2 class：让盒子自己会干活 从 struct 到 class，差的到底是什么
  • 5.3 构造函数、析构函数、private、this 出生和死亡时自动跑的那两段；怎么把数据藏起来；this 是干嘛的
  • 5.4 继承：让一个类基于另一个类 两个类有一大半是一样的时候不必抄两遍；出生死亡的先后；virtual、override、protected
  • 5.5 【综合练习二·类版】把找最小值装进 MyClass 题目要求用类写。学到这儿你就知道为什么了

第 6 部分 · 指针与引用

很多人觉得这是 C++ 最难的地方。其实它只是「变量住在内存里」这个事实的直接后果。

  • 6.1 变量住在内存里：地址是什么 每个盒子都有一个门牌号；& 是问「你住在哪儿」
  • 6.2 引用：还有三条规矩★ 有动画 3.5 只讲了参数表上那种；写到外面来还要守三条规矩
  • 6.3 指针：自己拿着门牌号★ 有动画 盒子里装的不是数，是另一个盒子的地址；还有空指针
  • 6.4 值传递 / 地址传递 / 引用传递★ 有动画 三种传参摆在一起看。最容易搞混的一处
  • 6.5 数组名、指针、字符串 把第 4 部分欠的账算清：为什么数组传进函数就能被改

第 7 部分 · 自己会发现错

编译器不报错、程序也能跑、但结果就是不对——这种时候怎么办。

  • 7.1 程序不对时，按什么顺序找 一套固定动作，比瞎改代码快十倍
  • 7.2 打印调试：把中间结果打出来看 最土，也最好用。顺手把 1.4 欠的那笔账还了
  • 7.3 读别人的代码：从哪一行开始看 以后你要读的代码，大部分不是你写的

第 8 部分 · 章末检测

不教新东西。一道例题把题拆开给你看，五道检测题跨着考前面七个部分。

  • 8.1 例题 · 一张成绩单 六件事、跨七个部分，最后栽在一行除法上
  • 8.2 五道检测题 每题都写着用到哪几课，答案收在题底下
