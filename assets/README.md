# assets/：各页共用的样式和脚本

课里的每一页都从这一层拿样式和脚本。平常读页面不用管它，浏览器自己去拿；
想改改看（换个字号、改个颜色）才需要打开。

| 文件 | 是什么 |
|---|---|
| `style.css` | 全站样式：颜色、字号、栏宽、代码块、顶栏、目录，都在这一份里 |
| `theme.js` | 顶栏最右边那个换配色的按钮（亮色 / 暗色 / 跟着系统走） |
| `toc.js` | 左边那条目录，读到哪一小节哪一行变蓝 |
| `viz.js` | 讲内存和屏幕的那几块数据流动画：单步、上一步、自动播放 |
| `geo.js` | 几何与坐标的交互图：滑块、步进、读数和 SVG 绘制 |
| `zoom.js` | 正文图片的双击放大：滚轮缩放、拖动平移、Esc 退出 |
| `code.js` | 代码块的外壳：上面的语言标签、复制按钮、左边的行号 |
| `logo.png` | 顶栏左边的队标 |

几条一直没变的原则：

- 手写，没有框架、没有外部字体，**断网也照样看**。
- 整套颜色的三根柱子定在 `:root` 里：暖白（纸面）、近黑（正文）、钢蓝（唯一
  的强调色）。其余都是这三根调出来的灰和浅底。暗色是同一套变量换值，不另写
  一份样式。
- 顶栏高度只有 `--topbar-h` 一处，目录吸在哪、跳转落在哪都跟着它走。

页面里引这一层用的是相对路径（课里的页写 `../../assets/style.css`），
所以整个文件夹一起拷走，样式和脚本照样找得着。
